## 重构的教学取舍

保留十单元、八课每单元和既有文件路径。问题顺序跟随概念依赖：选择→市场→反应→福利→外部性→成本→竞争→分配→消费者→信息与行为。第八课用综合问题串联已学机制，并给可直接讲述的费曼稿。

每课围绕一个主要判断；相关术语为回答问题服务。先给直觉，再定义变量，逐步算清一组数字，最后改变条件检验结论。延伸内容单独标明，避免把10–15分钟短课变成压缩教科书。

约20小时保留为第一轮学习预算，不能精确预测个人阅读和练习速度。八课可以按每课15分钟预留约120分钟；短课未用满的时间可用于复盘，超时则继续，不省略必要推理。额外迁移练习、分享准备和延迟复习独立安排。

## 优先校正的经济学问题

1. 机会成本以可行的最佳替代方案为基准，不能把互斥选项相加或重复扣成本；固定不等于沉没。
2. 区分曲线与曲线上一点、斜率与弹性、区间中点弹性与局部弹性。
3. 单位税明确买方支付价、卖方净收入价和差额；福利计算中税收收入是转移。
4. 生产者剩余与利润分开；外部性存在时矫正税可能提高社会效率。
5. 利润最大化须检查离散增量、可行边界或目标函数；垄断从需求读取价格。
6. 产品和劳动市场的竞争条件决定工资与边际产量价值的关系。
7. 消费者切点条件不是所有偏好下都适用；收入/替代分解需要一个明确的补偿中间点。
8. 信息问题不是道德评判；数据上的群体差异也不能直接代替因果识别。

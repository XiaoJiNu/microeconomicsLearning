# 单元 01｜把一个模糊选择变成可检查的判断

本单元最终要做成一件事：面对“已经投入很多，要不要继续”，能说明真实备选、未来得失和证据边界。学习顺序由概念依赖决定，**约 2 小时是第一轮学习预算，掌握能力才是过关标准**。

你已经会识别一些机会成本和沉没投入，但还需要练习可退款项、边际行动规模及因果证据。本单元直接从完整案例进入；不再先安排冗长诊断。所有数值为自编教学案例，不对应真实投资回报或真实市场数据。

前两课构成决策基础，第 3 课把个人选择连接到市场；第 4–5 课训练模型和读图，第 6–7 课训练证据判断，第 8 课把它们用于同一个决定。每篇核心阅读与即时题约 10–15 分钟；剩余预算用于回看错题、复述及综合练习。不必为了“准时读完”跳过推导。

## 一次短学习怎样结束

先读核心问题，凭当前理解想一句答案；再读机制和数例，自己把关键计算写一次。即时题先独立做，再展开答案。合上材料，用一分钟解释给没学过的人听。如果只能复述结论，回到讲解中找到支持它的假设和因果步骤。

迁移题提供另一个场景，可在下一次学习开始时回忆作答，不要求一口气完成所有内容。第 8 课有独立分享稿，适合先讲一遍再换成自己的例子；分享时间可纳入每天已有的 5 分钟费曼练习。

## 术语和读图约定

专业术语首次出现给中文、原始英文及解释。有常见缩写时明确说明；没有则写“无通用缩写”，不人为创造 SC、CP 或 CFD。数学字母是变量记号，必须解释含义和单位；例如 $P$ 表示价格，不是某个词的首字母缩写练习。

英文记不住时，可以先说中文并解释含义，再回看英文，不需要先背完术语表才开始学习。PPF 图必须先读横轴与纵轴，不能从线条形状直接猜结论。

## 通过与补学

完成第 8 课的 20 分综合案例，建议至少 16 分，且成本分类与方案计算两项各至少 3 分。若未达到，按错误回到对应课，只补缺口，再换数作答。记录可写成：“原判断—漏掉的项或假设—修正后的解释—下次怎样发现”，不用把全部课文重新抄一遍。

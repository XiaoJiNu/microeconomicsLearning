# Unit 01｜经济学思维与模型

- English title：Economic Thinking and Models
- 教材范围：第1～2章
- 总时长：2 小时
- 拆分方式：8 节 × 15 分钟
- 单元目标：建立选择、模型、图形和证据判断的共同语言。

## 使用方法

1. 每次只打开一节，不提前浏览后续答案；
2. 前 2 分钟先写原始判断；
3. 阅读“本节术语”，记住中文、英文和缩写；
4. 完成最小例子或计算；
5. 最后 1 分钟合上资料做费曼复述；
6. 第 8 节完成单元复盘，并把错误写入工作簿。

## 术语要求

本单元所有专业术语首次出现时采用：

> 中文术语（English Term, Abbreviation）

没有公认缩写时写“无通用缩写”。完整术语表见[中英术语表](../../../references/microeconomics_glossary_en_zh.md)。

# 单元 01｜把一个模糊选择变成可检查的判断

本单元最终要做成一件事：面对“已经投入很多，要不要继续”，能说明真实备选、未来得失和证据边界。

**本单元已按 10–15 分钟微课重做（kimi-k3 分支）。** 旧版 8 课每课实际约 30 分钟，内容偏多；现在拆成 12 节微课 + 1 节复习课。总内容没有缩水，只是每片更小：一节只回答一个问题、配一张图、给一道自测题，读完真能控制在 10–15 分钟。

**内容基准（2026-10-14 起）：以曼昆教材原文为准。** 目标是“不看原书也能掌握教材核心内容”——教材的定义、原始例子、公式与图表收录进课文；01-01（原理一·权衡取舍）、01-02（原理二·机会成本）已按此基准重写并换新配图，其余课次待确认样例后推广（见[有效提示词记录](../../00_learning_system/effective_prompts.md)）。

你已经会识别一些机会成本和沉没投入，但还需要练习可退款项、边际行动规模及因果证据。本单元直接从完整案例进入；不再先安排冗长诊断。所有数值为自编教学案例，不对应真实投资回报或真实市场数据。

## 一节课长什么样

每节微课同一副骨架，对齐“路径 → 测试 → 压缩 → 重复”的学习闭环：

1. **一个问题**——问题式标题 + 开头钩子，先知道这节课要解决什么；
2. **一张图**——先看图建立直觉，再读文字（每课一张自编 SVG，英文标注在正文解释）；
3. **一个例子讲透**——以教材原始例子为主线，保证概念对齐学科标准语言；
4. **一道题自测**——主动回忆，答案折叠，先独立做再对照；
5. **接到你的工作**（可选 2 分钟）——把概念挂到算法工作场景（测试车、标注团队、模型评测），加深个人连接；
6. **一分钟复述 + 一句话压缩**——费曼输出 + 便于复习的最小单元。

为什么主例子不用工作场景直接讲概念？因为熟悉场景适合**迁移和锚定**，直接用它学新概念容易把概念和场景绑死；先用教材的标准例子建立规范理解，再用工作例子练迁移，两样都占。

第 1–4 课是决策基础（稀缺→机会成本→沉没成本→边际），第 5–6 课把个人选择连到市场，第 7–10 课训练模型和读图，第 11–12 课训练证据判断，第 13 课把它们用于同一个决定。

## 时间预算

每节微课核心 10–15 分钟，复习课约 15–20 分钟，单元核心合计约 2.5–3 小时。“10–15 分钟”这次是真的：一节的正文和自测就这么多，读不完说明卡住了，卡住就去对应段落，不要压缩阅读速度。可选的“接到你的工作”和迁移讨论不计入核心时间。

每天有 60 分钟可以连学 3–4 课并做 5 分钟分享；只有十几分钟就一次一课，结束时在工作簿留下下一步。

## 术语和读图约定

专业术语首次出现给中文、原始英文及解释。有常见缩写时明确说明；没有则写“无通用缩写”，不人为创造 SC、CP 或 CFD。数学字母是变量记号，必须解释含义和单位。英文记不住时先说中文并解释含义，再回看英文。所有图先看轴，再看线，最后看变化。

## 通过与补学

完成第 13 课的 20 分综合案例，建议至少 16 分，且成本分类与方案计算两项各至少 3 分。若未达到，按错误回到对应微课，只补缺口，再换数作答。记录写成：“原判断—漏掉的项或假设—修正后的解释—下次怎样发现”。

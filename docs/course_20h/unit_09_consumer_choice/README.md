# Unit 09｜消费者选择：从买得起，到为什么这样买

本单元对应《经济学原理·微观经济学分册》第 21 章的消费者选择主题。完成后，你应能独立写预算约束、解释偏好、选择合适的求解方法，并把价格变化分解成两种作用。

**约 2 小时是学习预算，不是通过条件。** 八个小课各围绕一个问题组织，核心学习预计 10–15 分钟。先完成连贯讲解、数例和即时题，再按需要做迁移题或延伸。掌握得快可以提前进入下一课；卡在补偿点或切点条件，应停下来核验，不必追赶计时器。

## 阅读与练习怎样配合

先读每课开头的问题，写一句现有判断，再阅读解释和完整数例。不要提前展开题目的推理答案；自己计算或解释后再对照，保留错误原因。每课末尾有一句复述要求，能不用原文说明因果关系，比记住标题更重要。

术语首次出现配中文、原始英文和常用缩写；无统一通用缩写时明确说明。$U$、$I$、$x$ 等是数学符号，不是英文缩写。MRS 是边际替代率，本单元约定正值；预算线斜率仍为负。已有文件中的 BC、BL 等简写可以识别，但无需当作统一标准强背。

## 通过本单元需要什么

第 08 课提供 10 分评分规则，建议至少 8 分，且补偿中间点和切点条件不能空白。还应能完成以下证据：

- 用完整数例说清“预算描述可行，偏好描述排序”，不把效用当作可跨人相加的幸福量。
- 解释 MRS 与相对价格的单位一致，并指出完全替代、完全互补或边界解不能机械套切点。
- 写出希克斯分解的补偿点，解释保持旧效用和保持旧篮子买得起的区别。
- 给一个模型失效的现实约束，并完成一次自己的费曼复述。

把分析卡与错因存入[工作簿](../workbook.md)。延迟复习只需换一组数字重算最薄弱的题，不必为了满足时长重新阅读全部页面。

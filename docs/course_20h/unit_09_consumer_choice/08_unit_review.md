# 08｜单元复盘：从预算约束到最优选择

- 所属单元：Unit 09
- 建议用时：15 分钟
- 本节只解决：**能否把价格、收入、偏好和消费者选择连成一张图？**
- 导航：[上一节](07_labor_leisure_saving.md) · [返回单元首页](README.md)

## 0～2 分钟：主动回忆

在不查资料的情况下，先写一句你目前的判断。即使答案是“不知道”，也要保留原始想法：

> 能否把价格、收入、偏好和消费者选择连成一张图？

## 本节术语

| 中文术语 | English | 缩写 | 通俗解释 |
|---|---|---|---|
| 预算约束 | Budget Constraint | BC | 给定收入和价格时，消费者可购买组合的边界。 |
| 无差异曲线 | Indifference Curve | IC | 给消费者相同效用的商品组合轨迹。 |
| 边际替代率 | Marginal Rate of Substitution | MRS | 消费者愿意为多一单位某商品放弃多少另一商品。 |
| 收入效应 | Income Effect | IE | 价格变化通过改变实际购买力影响消费。 |
| 替代效应 | Substitution Effect | SE | 价格变化通过改变相对价格影响消费。 |

> 术语使用规则：第一次出现时同时记住“中文（English, 缩写）”。没有公认缩写的术语明确写“无通用缩写”，不要自己编造。

## 2～9 分钟：核心内容

闭卷重建：

```text
收入与价格 → BC/BL
偏好 → IC
IC斜率 → MRS
最高可达IC → 最优选择
价格变化 → SE + IE
商品类别 → 总需求反应
```

分析消费者变化时，先画预算线变化，再判断相对价格和实际购买力，最后结合商品性质。

## 9～12 分钟：最小例子

燃油价格上涨使预算线绕另一截距旋转；燃油相对变贵产生SE，实际购买力下降产生IE。总出行变化还受替代交通和车辆存量限制。

## 12～14 分钟：你来做

15分钟：①画预算线；②画IC和最优点；③判断MRS调整方向；④分解价格变化；⑤解释低档品不等于吉芬品。

## 14～15 分钟：费曼复述

合上本页，用自己的话完成：

> 消费者选择由 ______ 与偏好共同决定；内部最优满足MRS等于 ______；价格效应可分为 ______ 和 ______。

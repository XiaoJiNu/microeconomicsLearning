# 单元03｜弹性与政府政策：从“会变化”到“变化多少”

> 你要建立的能力：面对定价、需求变化或政策干预，先辨认变化原因，再算出价格与数量，并解释谁更难调整。

本单元对应教材第5—6章的主题。八课按问题依赖排列：先学会衡量反应，再讨论收入和供给，最后评价管制与征税。每课核心阅读与即时练习约10–15分钟，八课加必要复盘名义约2小时；时间只是学习预算，掌握一项能力才是进入下一课的依据。可选推导、迁移题和分享稿可单独复习。

## 先带上这些基础

应当能从[单元02复盘](../unit_02_trade_and_market/08_unit_review.md)解释：需求量变化与需求变化不同；均衡是双方计划数量一致；供给曲线描述给定条件下卖方愿意且能够出售多少。若这些还不稳定，先返回对应课，不需要重做全部诊断。

公式里的 $P$ 表示价格，$Q$ 表示数量。先看清单位，再处理百分比。数学基础只需分数、百分比与一元一次方程；点弹性涉及的导数有直觉解释，不要求先修完整微积分。

## 本单元的共同约定

- PED统一使用绝对值；要保留方向时另写带符号的 $e_d$。YED、XED保留正负号。
- 区间比较优先使用中点法；“斜率恒定”和“弹性恒定”是不同结论。
- $P_b$、$P_s$、$Q_s$ 等是数学符号，不是英文缩写。术语表给出原英文和常用缩写，没有通用缩写就明确说明。
- 后半单元用共同教学模型：需求 $Q_d=100-P$、供给 $Q_s=P-20$，基准价格60元、数量40件。它不是现实市场估计。
- 本单元默认竞争市场、其他条件不变；每课另列模型边界。公式计算不能替代现实因果识别。

## 怎样留下学习证据

每次先读问题，自己作一个预测，再阅读机制和完整数例。完成即时练习后才展开答案；答错时保留原计算，写一句“我错在变量、口径、算术还是假设”。迁移题要求把模型带到软件、供应商或企业经营问题，答案重在说明需要哪些信息。

末课综合题达到8/10，且不再把TR当利润、不再把法定缴税人当全部税负承担者，可以进入下一单元。未过关按末课提示只返回相关知识点。把复述与错因记入[课程工作簿](../workbook.md)，次日或几天后重做一个曾答错的问题即可。

# Unit 03｜弹性与政府政策

- English title：Elasticity and Government Policies
- 教材范围：第5～6章
- 总时长：2 小时
- 拆分方式：8 节 × 15 分钟
- 单元目标：掌握弹性计算，并用弹性分析定价、价格控制和税收归宿。
- 配图：`assets/`（手绘白板 sketchnote；每节 1 张主图）

## 使用方法

1. 每次只打开一节；
2. 前 2 分钟先写原始判断；
3. 看术语表与主图，再读核心内容；
4. 完成最小例子；
5. 最后 1 分钟费曼复述；
6. 第 8 节用**同一条主链**复盘，不另开第二套框架。

# Unit 06｜一家公司该不该接单、扩产、停产或退出？

完成本单元后，你应能从**资源的机会成本、投入产出关系、增量成本、市场收入与可避免成本**推导企业决策。教材对应曼昆《经济学原理：微观经济学分册》第 13–14 章。课程采用一张反复使用的成本表，让每个新工具都能接回同一家企业的选择。

前置能力：理解机会成本与沉没成本，能够计算增量和平均量，知道价格由市场供需共同决定。不需要预先掌握微积分；整数产量用完整利润比较，连续曲线的等式会明确注明适用条件。

先确定“成本算什么”，再解释“成本为什么这样变”，然后加入“新增收入”，最后比较“不同期限可以避免什么”。这一依赖决定课序。行业供给与长期竞争均衡已在第六、七课学习，复盘只检验应用，不首次引入关键概念。

## 学习与复核方法

每课先对核心问题作初判，再读术语和机制，手算完整例子后独立做即时题。折叠答案用于核验推导，不是需要提前背下来的结论。把错因写成可改正的一句话，例如“把可收回本金当成当期消耗”或“把平均成本当作新增成本”。

每课核心阅读与即时题约 10–15 分钟；全单元约 2 小时是学习预算。按概念掌握推进，不使用逐分钟任务表。迁移题和进一步重算可以另做。第八课提供完整约 5 分钟费曼分享稿，理解后用自己的项目替换例子，再讲清同样的因果链。

本单元所有金额均为教学设定。每课首次使用专业术语时给出原始英文和常用缩写，未统一缩写的术语明确说明；利润符号 π、价格符号 P 不是英文缩写。数例会说明期间和计量单位，跨期账本不可混算。

## 本单元的掌握标准

- 能说明会计利润、经济利润与正常回报，不重复计入机会成本。
- 能从生产表推出边际产量和增量成本，理解总量仍可上升。
- 能区分固定与沉没成本，计算平均与边际量，并区分生产者剩余与利润。
- 能对离散产量比较总利润，不强求某一行 MR=MC；知道单家企业与整个行业需求不同。
- 能给出停产、退出及等号无差异的条件，并解释自由进入何以压缩经济利润。

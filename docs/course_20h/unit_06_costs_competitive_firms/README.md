# Unit 06｜企业成本与竞争企业

- English title：Costs and Competitive Firms
- 教材范围：第13～14章
- 总时长：2 小时
- 拆分方式：8 节 × 15 分钟
- 单元目标：理解成本曲线，并能判断竞争企业的产量、停业和退出。

## 使用方法

1. 每次只打开一节，不提前浏览后续答案；
2. 前 2 分钟先写原始判断；
3. 阅读“本节术语”，记住中文、英文和缩写；
4. 完成最小例子或计算；
5. 最后 1 分钟合上资料做费曼复述；
6. 第 8 节完成单元复盘，并把错误写入工作簿。

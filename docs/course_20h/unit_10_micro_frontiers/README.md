## 使用方法

1. 每次只打开一节；
2. 前 2 分钟先写原始判断；
3. 看术语表与主图，再读核心内容；
4. 完成最小例子；
5. 最后 1 分钟费曼复述；
6. 第 8 节用**同一条主链**复盘，不另开第二套框架。

# Unit 10｜信息、集体选择与行为：给模型补上真实限制

本单元对应《经济学原理·微观经济学分册》第 22 章的前沿主题，并把前九单元连接为一次企业分析。目标是识别信息、激励和行为机制，说明何时可以得出结论、何时还需要证据。

**约 2 小时是学习预算，不是通过条件。** 八个小课各围绕一个概念问题组织，核心学习预计 10–15 分钟。先完成机制、数例和即时题，迁移练习及完整分享可按需要延伸。没有“读到两小时就掌握”的判定。

## 学习路线与依赖

前面课程常把价格、信息与偏好视为给定。本单元逐一检查：如果双方知道得不同、行动看不见，合同怎样改变？如果个人偏好一致却集体排序循环，决策规则怎样影响结果？如果注意力有限、描述与默认有作用，又应怎样验证？

| 课次 | 要解决的问题与入口 | 直接先修 | 完成后留下什么证据 |
|---|---|---|---|
| 01 | [好产品为什么可能先退出？](01_asymmetric_information_adverse_selection.md) | 供需、交易剩余 | 一份报价→退出→更新质量比例的计算。 |
| 02 | [合同后为什么可能少做检查？](02_moral_hazard_principal_agent.md) | 01、激励 | 一条奖金阈值不等式，并分别检查行动与参与。 |
| 03 | [谁发信号，谁设计筛选？](03_signaling_screening.md) | 01–02 | 两类卖家的模仿收益和两类客户的套餐选择。 |
| 04 | [多数票为何可能绕圈？](04_collective_choice_government_failure.md) | 偏好、公共物品 | 三轮票数；中位选民定理的单维、单峰条件。 |
| 05 | [什么时候停止搜索是合理的？](05_behavioral_bounded_rationality.md) | 机会成本 | 搜索的预期收益与时间成本比较。 |
| 06 | [风险、损失、描述和现在有何区别？](06_loss_framing_present_bias.md) | 05、期望值 | 四种机制各一个例子，并写一种替代解释。 |
| 07 | [默认开启率提高是否等于用户受益？](07_nudge_endowment_ethics.md) | 05–06 | 区分行为指标、用户意愿和退出便利。 |
| 08 | [能用全课程解释一家企业吗？](08_unit_review.md) | 全课程核心内容 | 收入、利润、信息、激励与行为综合分析卡。 |

01→02→03 是信息链，05→06→07 是行为链；04 讨论制度选择，08 把各链和前面课程连接起来。按表顺序学习即可，不需要额外先学心理学或博弈论高级数学。

## 怎么避免“只学会术语”

每课先给中文、原始英文、常用缩写与解释；没有统一通用缩写就明确说明。本单元避免将信息不对称缩成 AI，以免和人工智能混淆。IC 在合同分析中表示激励相容，在上一单元则表示无差异曲线，读缩写时必须带上下文。

每课用自编数例隔离机制，不能当成真实企业、真实市场或特定人群的经验事实。题目先独立做，再打开折叠答案；最后用自己的工作场景复述“谁知道什么、谁决定什么、什么变化导致什么后果”。行为解释尤其要列替代原因，不把每一次选择都贴上偏差标签。

## 通过与全课程交付

第 08 课有 10 分评分规则，建议至少 8 分；利润口径、隐藏类型与隐藏行动两项不能空白。完成证据包括：

- 区分签约前的类型和签约后的行动；信息机制与合同激励各有可验证的设计。
- 说清信号由谁发、筛选由谁设，并检查不同类型为何不模仿或如何自我选择。
- 亲手算出多数循环，保留中位选民定理条件，不把投票胜者等同于福利最大。
- 区分风险厌恶与损失厌恶，承认行为效应依赖情境；助推评价包含知情、退出和用户目标。
- 独立完成一家自编企业的收入、成本、经济利润计算，列出真实迁移需要验证的事实。

把最后的分析卡、错因和五分钟分享记录到[工作簿](../workbook.md)。本轮成果是能解释经营机制并发现证据缺口；资产估值、风险配置与交易策略需要另行学习，不能从本课案例直接推出股票或黄金走势。

# Unit 08｜生产要素、收入与分配

这组课程解决一个连续问题：**最终产品的需求如何影响劳动、土地和资本，工资差异如何解释，收入分配又应怎样测量和评价？** 英文主题为 Factor Markets, Income, and Distribution，主教材对应曼昆《经济学原理·微观经济学分册》第 8 版第 18—20 章。

学习顺序由解释能力决定。两小时是一次入门轮次的精力预算，做完一张时间表不等于理解了劳动市场。

## 能力依赖与课程入口

先修：[Unit 06](../unit_06_costs_competitive_firms/README.md) 的生产、边际产量与成本；[Unit 07](../unit_07_market_power_strategy/README.md) 的 MR 与 P 区别、市场势力；此前的供需与机会成本。本单元先教会收入效应、替代效应的直觉，第九单元再补消费者选择的图形与推导。

| 课次 | 核心问题与本课产出 | 建议核心用时 |
|---|---|---:|
| [01｜为什么企业需要劳动？](01_factor_markets_derived_demand.md) | 从客户需求倒推投入，区分劳动、土地、实物资本以及存量流量 | 14 分钟 |
| [02｜多雇一人和什么比较？](02_vmp_mrp_labor_demand.md) | 算 MPL、VMP、MRP，说明固定产品价格与工资接受的假设 | 14 分钟 |
| [03｜时薪翻倍会多工作吗？](03_labor_supply_equilibrium.md) | 用收入与替代效应解释工时，再联立市场供需 | 14 分钟 |
| [04｜同样工时，工资为何不同？](04_wage_differences.md) | 比较能力、信号、工作条件、留任与谈判等机制 | 14 分钟 |
| [05｜平均工资不同能证明什么？](05_discrimination_measurement.md) | 区分描述与因果，检查控制变量和职业机会路径 | 14 分钟 |

前两课解释企业为何购买要素服务；第三课加入劳动者选择；第四、五课区分工资差异的机制与证据；第六课改变观察尺度，转向家庭和社会分布；第七课把政策效果与价值标准分开；最后一课综合运用，不首次引入新知识。

## 两小时预算怎样使用

默认前七课各约 14 分钟、第八课核心题约 12 分钟，共约 110 分钟；留约 5 分钟完整分享和 5 分钟回看错因，约 120 分钟。每课核心学习约 10–15 分钟。查真实企业或统计数据、细读延伸推导、反复练习和录制分享可另行安排；遇到公式或比较口径不清楚，就在该处暂停补学。

每课先跟着算一个完整例子，再独立做即时题；答案折叠，是为了给自己的推理留空间。迁移题检验是否能解释新问题，不要求得出唯一观点。把计算、假设、一个反例和疑问写入[工作簿](../workbook.md)，第八课用完整分享稿校正自己的表达。

## 什么证据说明可以继续

- 能把额外产量、额外收入和额外总雇用成本分开，并说清 $MRP_L=MR	imes MPL$ 何时化为 $P	imes MPL$。
- 能说明工资提高对个人工时未必同向，个人选择与全市场就业也不能混同。
- 能提出多个工资差异机制，不从群体均值直接判断能力或歧视，也不忽略晋升路径。
- 能算简单 Gini 与 EMTR，区别收入和财富，检查税收转移、家庭规模、生命周期与价格口径。
- 能说明功利主义、罗尔斯式自由主义与自由至上主义关心什么，区分效果证据与价值判断。
- 第八课至少 16/20 分，并纠正列出的关键误解；隔一天用新数字还能重做。

重要术语首次附中文、英文与常用缩写；没有统一常用缩写时用全称。L、K、w 等是公式记号，首次使用时解释单位。参见[中英术语表](../../../references/microeconomics_glossary_en_zh.md)。所有数字为教学自编；人的工资不等于人的道德或社会价值，统计指标也不替代完整的公平判断。

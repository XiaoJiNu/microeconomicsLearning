- English title：Public Sector Economics
- 教材范围：第10～12章

- 拆分方式：8 节 × 15 分钟
- 单元目标：识别外部性、公共物品与公共资源，并比较政策工具和税制取舍。

## 使用方法

1. 每次只打开一节；
2. 前 2 分钟先写原始判断；
3. 看术语表与主图，再读核心内容；
4. 完成最小例子；
5. 最后 1 分钟费曼复述；
6. 第 8 节用**同一条主链**复盘，不另开第二套框架。

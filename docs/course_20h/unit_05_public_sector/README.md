# Unit 05｜交易遗漏了谁：外部性、公共物品与税制

完成本单元后，你应能把一个公共政策问题拆成：**遗漏的成本或收益是什么、物品如何被共同使用、政策改变谁的选择、谁最后承担费用。** 教材对应曼昆《经济学原理：微观经济学分册》第 10–12 章。本单元写出可直接学习的讲解与推导，不要求先读教材才看得懂。

前置能力：能读供需图，知道“边际”指增加一单位，会区分总剩余与分配。如果还不能说明一笔税款为什么是转移，先回看[Unit 04](../unit_04_welfare_tax_trade/README.md)。

## 按问题推进的学习路线

| 课 | 核心问题与内容 | 依赖 | 通过证据 |
|---|---|---|---|
| [01 外部性](01_externality_social_private.md) | 买卖双方满意，为什么社会仍可能受损？私人量与社会量、正负外部性。 | 供需、边际、总剩余 | 推出测试量 40 与 30 的差别；解释最优不一定清零。 |
| [02 矫正税](02_pigouvian_tax.md) | 为什么一种税可能提高效率？税基、边际外部损害、税负与福利账本。 | 01、单位税价差 | 算出买方 70、卖方 50、税收 600 与净改善 100，且不混同。 |
| [03 补贴与交易](03_subsidy_tradable_permits.md) | 如何鼓励外溢收益、以较低成本达到减排量？ | 01–02、机会成本 | 比较补贴前后账本；解释许可证支付不是资源减排成本。 |
| [04 科斯协商](04_coase_transaction_cost.md) | 哪些条件下双方自己谈得成？权利、交易成本、效率与分配。 | 01、净收益比较 | 在两种权利下画出互利补偿范围，指出钱流向为何不同。 |
| [05 四类物品](05_goods_classification.md) | 能否排除别人？我使用会不会挤掉你？ | 稀缺、外部性 | 对一个带容量条件的真实对象作两维判断，不以政府提供代替分类。 |
| [06 供给与使用困境](06_free_rider_commons.md) | 公共物品为何可能太少，公共资源为何可能用得太多？ | 05、边际比较 | 把同一警报的多人收益相加；写出拥堵者漏掉的成本。 |
| [07 项目与税制](07_cba_tax_design.md) | 项目值不值得建？怎样筹资和分担？ | 02、06、比例计算 | 区分平均与边际税率；按平均税率随收入变化识别累进、比例、累退。 |
| [08 综合案例](08_unit_review.md) | 给园区形成一份有依据、可核验的建议。 | 01–07 | 闭卷至少 16/20 且无关键错误，完成一次费曼分享。 |

前四课处理“第三方影响”，第五、六课处理“共享使用的激励”，第七课连接“公共项目与筹资”，第八课综合。这些知识依赖决定课程顺序；时间只用于控制一次学习的负担。

## 怎样用这八课

每次只回答一个核心问题。先用自己的话做初判，再读术语、机制和完整数例，独立做即时题，最后打开折叠答案检查推理。出错时保留原答案，注明错在边界、变量、算法还是因果解释；不要仅把正确数字抄上去。

每课核心阅读与即时题约 10–15 分钟；全单元约 2 小时是首轮预算，不是必须到点切换的进度指标。迁移题、跨期项目拓展和二次分享可另做。第八课含完整约 5 分钟费曼稿，先参考它核对知识，再换成自己的对象和表达。

每课术语表给出中文、原始英文、常用缩写与解释。无统一通用缩写时直接说明；数学符号与英文缩写分开。不要为了记英文而跳过“这个量属于谁、增加的是什么、单位是什么”。

## 本单元的掌握标准

- 能区分私人边际量与社会边际量，正负外部性都能独立算一个例子。
- 能说明矫正税的作用条件，知道税收转移与社会资源消耗不同。
- 能比较协商、补贴、许可证、公共供给等工具的具体激励与执行成本。
- 能对物品做两维分类，区分搭便车与过度使用，避免“政府提供就是公共物品”。
- 能算分段税额、平均税率和边际税率，并把效率与分配分别写清。

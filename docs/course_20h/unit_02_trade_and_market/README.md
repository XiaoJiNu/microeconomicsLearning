# 单元 02｜用分工和供需解释真实选择

本单元围绕两项能力展开：**判断怎样分工能减少资源浪费；解释哪些因素改变市场价格和数量。**名义学习预算约 2 小时，供安排使用；完成的标准是可检查的推理证据，不是读满计时器。

教材主题索引：曼昆《经济学原理：微观经济学分册》第 3–4 章的相互依存、贸易收益与市场供需。本目录为原创讲解和自编数例；该索引不表示已逐页核验教材 PDF。

## 学习依赖与八个问题

先修只要求理解上一单元的机会成本与边际思考。第 1–3 课建立分工与贸易主线；第 4–6 课分别建立买方和卖方模型；第 7 课合并供需；第 8 课完成综合案例。每课核心阅读和即时题约 10–15 分钟，迁移题、错题修复和完整分享可另安排，不按分钟截断理解过程。

## 怎样使用

每次从课首问题写一句原始判断，读连贯解释后完成即时题，再展开答案查具体错误。能回答时进入下一课；卡住时只回到依赖的知识点。每课有一分钟复述，单元末提供完整分享稿作为示范；先尝试自己说，再对照示范，而非背诵稿件。

术语首次出现给出中文、英文、常见缩写或“无通用缩写”，并说明白话含义。OC、MC、PPF、ToT 是本单元出现的常见教学或专业缩写；$D$、$S$、$Q_d$、$Q_s$、$P^*$、$Q^*$、$M$、$X$ 是曲线或变量记号，不能当作英文缩写背诵。绝对优势与比较优势不强制制造 AA、CA 简写。

## 过关证据

- 能用同一单位比较机会成本，找到双方严格获益的交换区间，并核对收益分配。
- 能从零解释供给曲线，并区分需求/供给与需求量/供给量。
- 能写出一组均衡计算，区分短缺、过剩和实际销量。
- 能解释需求与供给同时右移时数量增加、价格方向待定，以及模型成立条件。
- 完成第 8 课评分：至少 8/10 分，且不存在机会成本单位混比、把自身价格变化误判为曲线移动的关键错误。

把计算、复述与未解问题记入[课程工作簿](../workbook.md)。若一次学习只有十分钟，完成一个核心问题即可；遇到复盘时可以分两次完成，不需要为凑满或压缩时间改变问题的逻辑。

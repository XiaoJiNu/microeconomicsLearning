# Unit 07｜市场势力与策略互动

- English title：Market Power and Strategic Interaction
- 教材范围：第15～17章
- 总时长：2 小时
- 拆分方式：8 节 × 15 分钟
- 单元目标：理解垄断、垄断竞争和寡头，并用博弈论分析竞争与护城河。

## 使用方法

1. 每次只打开一节，不提前浏览后续答案；
2. 前 2 分钟先写原始判断；
3. 阅读“本节术语”，记住中文、英文和缩写；
4. 完成最小例子或计算；
5. 最后 1 分钟合上资料做费曼复述；
6. 第 8 节完成单元复盘，并把错误写入工作簿。

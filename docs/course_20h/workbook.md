# 课程工作簿

这是可复制模板，尚无本轮个人答案。请保留第一次作答，读解析后把修改写在后面。课程写作完成不代表你已经学完。

## 每课记录

- 日期与课程编号：
- 我想回答的问题：
- 本课最关键的术语（中文 / English / 常用缩写或符号 / 自己的解释）：
- 即时题原始答案与推理：
- 对照解析发现的最早错误：
- 修正后的解释：
- 改变一个条件后，结果怎样变化：
- 一分钟复述（可只记关键词和卡住的句子）：
- 下一次从哪个问题继续：
- 状态：未开始 / 学习中 / 首轮通过，待复习 / 延迟验证通过

## 单元综合记录

- 单元编号：
- 综合案例原始作答：
- 自评和依据（概念、推理、计算、边界）：
- 费曼分享：自己的例子、讲不清的点、听众追问：
- 需要返回的具体课与原因：
- 下一次复习日期：
- 延迟变式题与结果：

## 每日5分钟分享

单元末课的完整稿可作示范。平日只学一课时，围绕本课说清：发生什么问题、我原来怎么想、经济学怎样比较、用一组数字解释、什么条件下结论失效。已有1分钟复述可扩成分享，不强求每天提出新理论。

参考[费曼分享模板](../../templates/feynman_5min.md)。个人完成统计统一更新到[进度表](../00_learning_system/progress.md)。

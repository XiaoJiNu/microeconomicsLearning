## 内容审校

独立审校覆盖以下重点，并对关键数例重新计算：

- 机会成本与退款不重复计费，比较优势交换区间，PPF与供需变化。
- 弹性、税收楔子、剩余、关税、配额租的国内与全球福利口径。
- 外部性矫正、公共品收益加总、税制平均与边际税率。
- 显性和隐性成本、离散产量全局比较、短期停产和长期退出，包括等号无差异。
- 垄断先确定产量再读需求价格，价格歧视福利、博弈均衡与重复博弈阈值。
- 劳动边际产量价值、产品和劳动市场条件、基尼系数、贫困与税后激励。
- 序数效用、消费者角点、希克斯补偿中间点及收入和替代效应。
- 逆向选择、激励与参与约束、信号筛选、多数循环和行为模型条件。

审稿中发现并修正了消费者“原点/原最优点”歧义、无法展示加总尺度问题的效用数例、分享稿的斜率方向表述、进口关税纠错对象、劳动生产函数单位，以及少量术语首次定义遗漏。10份分享稿均为连贯讲稿，未进行真实口述计时。

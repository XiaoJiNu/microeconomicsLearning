# Unit 04｜市场福利、税收与贸易

- English title：Welfare, Taxation, and Trade
- 教材范围：第7～9章

- 单元目标：会用消费者剩余、生产者剩余和无谓损失评价市场与政策。

## 使用方法

1. 每次只打开一节，不提前浏览后续答案；
2. 前 2 分钟先写原始判断；
3. 阅读“本节术语”，记住中文、英文和缩写；
4. 完成最小例子或计算；
5. 最后 1 分钟合上资料做费曼复述；
6. 第 8 节完成单元复盘，并把错误写入工作簿。

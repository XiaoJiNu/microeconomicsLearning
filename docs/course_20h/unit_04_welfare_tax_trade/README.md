# 单元04｜市场福利、税收与贸易：把收益和损失算完整

> 你要建立的能力：评价交易或政策时，分清总收益与分配，把消费者、生产者、政府和相关租金放进同一张账。

本单元对应教材第7—9章主题。先认识交易净收益，再讨论效率、公平和税收，最后进入小国贸易、关税与配额。每课核心阅读与即时练习约10–15分钟，八课加必要复盘名义约2小时。按概念是否理解推进；迁移应用与分享稿可在之后复习。

## 进入前先确认

你应能解简单供需均衡，并解释[上一单元的税收楔子](../unit_03_elasticity_and_policy/07_tax_incidence.md)：买方总付价减卖方净得价等于每件税额。若税后仍只使用一种价格，先返回该课，否则后面的剩余面积会重复出错。

本单元只需三角形、矩形和梯形面积，配合简单方程。不熟悉积分也能完成所有核心内容。读图始终先确认横轴是数量、纵轴是价格或每单位价值；税额与政府收入关系图会明确改用不同坐标。

## 一组数字贯穿机制

多数课程采用教学模型：需求 $P=100-Q$、供给 $P=20+Q$。封闭无税均衡为价格60元、数量40件，CS和PS各800元。每件20元国内税后，买方付70元、卖方净得50元、成交30件；政府收入600元，DWL为100元。

贸易课把世界价格设为40元：自由贸易消费60件、生产20件、进口40件。每件10元关税后，消费50件、生产30件、进口20件。固定数例让你能看到同一市场在不同制度下的变化；第08课更换需求参数检查能否独立迁移。全部数字为自编教学情境。

## 三条必须守住的核算规则

- PS等于TR减相关可变成本；经济利润还要扣固定经济成本。机会成本已计入的项目不能再扣一次。
- 加入政府后不能仍只算CS加PS；加入配额后必须查明许可证租金归谁。国内福利与全球福利需要分别定义边界。
- 基准必须明确：国内税课比较有效率的无税市场，关税课比较自由贸易。总净收益增加不等于每个人都受益，也不自动等于公平。

每课先尝试即时题，再展开推理答案，并保留自己的错因。综合题至少8/10且没有漏加政府收入、混淆配额租归属，可以进入下一单元。不要因为计时结束就跳过一项仍说不明白的假设。学习证据记入[课程工作簿](../workbook.md)。

# 中英术语与公式符号书写规范

## 先解释，再使用

每篇可独立学习的短课，首次使用关键专业术语时提供中文、英文原词、常用缩写和通俗解释。可以在正文定义，也可在紧邻正文的术语表定义；复习到旧术语时作一句提醒，避免只有孤立字母。

合格示例：**平均总成本（Average Total Cost, ATC）**：把本期总成本除以本期产量，得到每生产一件平均承担多少成本。若总成本120元、产量10件，ATC为12元/件。

沉没成本（Sunk Cost）没有本课程要求掌握的通用缩写，直接写全称或中文；不为了表格整齐创造SC。其他条件不变的原词 *Ceteris Paribus* 是拉丁语惯用语，不应误称英语词源。

## 缩写与记号分开

| 类别 | 例子 | 怎样解释 |
|---|---|---|
| 常用英文缩写 | PPF、MC、ATC、CS、MRS | 给全称、中文、测量对象与单位 |
| 数学变量 | $P,Q,Q_d,\pi$ | 明确是价格、数量等记号；不当成必须背的英文缩写 |
| 图线或点标签 | D、S、E | 说明图中需求线、供给线、均衡点 |
| 缩写不统一或有歧义 | 机会成本、沉没成本、价格歧视 | 写“无通用缩写”，使用全称 |

“无通用缩写”表示本课不要求强记某个统一字母写法，并不声称任何英文文献都不会缩写它。若引用特定论文的局部记号，明确写“该文使用”，不能推广成通用规则。

## 最容易混淆的中文翻译

- **Marginal Benefit（MB，边际收益/边际利益）**：多做一单位行动增加的好处，可以含非销售收益。
- **Marginal Revenue（MR，边际收益/边际营收）**：企业多卖一单位增加的销售收入。本课提到企业时优先叫“边际营收”，即使教材叫边际收益，也不能与MB混用。
- **Total Revenue（TR，总收益/总营收）**：销售收入，不是利润；**Profit（利润，符号 $\pi$）** 还要扣成本。
- **Demand（需求）** 是一整套价格与数量关系；**Quantity Demanded（需求量，符号 $Q_d$）** 是特定价格下的数量。
- **Producer Surplus（PS，生产者剩余）** 在常见短期成本模型下为营收减可变成本，不等于扣完固定成本后的利润。

## 每个公式至少说明四件事

它解决什么问题；变量分别是谁且单位是什么；为什么可以这样运算；哪些假设变化时不能套用。正文写完公式应跟一组可手算数字或经济解释，不用另一个未定义公式解释第一个公式。

术语解释应少用生词套生词。先说“再多一件多花多少”，再介绍“边际成本”，让读者能用自己的例子复述。课堂通过不要求背英文拼写，要求看见英文或缩写时能认出含义并正确使用。

## 维护检查

1. 每课检查未解释的英文大写串；避免给并非通用的词强配缩写。
2. 每个公式检查符号、时间范围和单位。
3. MB与MR、收入与利润、社会与私人、短期与长期分别说清。
4. 术语表与正文如有不同记法，说明是同一概念的不同教材记号。

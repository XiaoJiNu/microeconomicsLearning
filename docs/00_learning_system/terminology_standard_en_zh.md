# 微观经济学中英术语书写规范

本规范适用于本仓库的课程、练习、测验、速查表和费曼分享。目标是让第一次接触微观经济学的学习者能够同时看懂中文含义、英文教材或论文中的原词，以及公式和图表中的常用缩写。

## 1. 首次出现时的固定格式

每一篇可以独立阅读的微课程中，专业术语第一次出现时统一写成：

> **中文术语（English Term, ABBR）**：一句不依赖其他术语的中文解释。

例如：

- **生产可能性边界（Production Possibilities Frontier, PPF）**：在资源和技术给定时，两类产出能够达到的最大组合所形成的边界。
- **边际成本（Marginal Cost, MC）**：多生产或多行动一单位带来的额外成本。
- **消费者剩余（Consumer Surplus, CS）**：消费者最高愿付价格与实际支付价格之间的差额。

如果没有公认、稳定的缩写，不得为了形式整齐而自行造缩写：

- **机会成本（Opportunity Cost）**：选择一个方案时，最佳被放弃方案的价值。
- **沉没成本（Sunk Cost）**：已经发生且当前决策无法收回的成本。
- **其他条件不变（Ceteris Paribus）**：研究一个变量变化时，暂时把其他相关因素固定。

不得写成未经说明的 `OC`、`SC`、`CP`，除非当前资料明确采用且先定义。

## 2. 每一节都要重新定义

本课程由 80 个可以独立学习的 10～15 分钟微课程组成。即使某个术语在前一节已经出现，本节第一次使用时仍要重新给出中文、英文和缩写。

原因是：

1. 学习者可能跨天学习；
2. 可能从复习链接直接进入某一节；
3. 缩写离开上下文后容易混淆；
4. 重复一次简短定义本身就是间隔复习。

完成首次定义后，本节后文可以使用中文简称或缩写，但必须保持一致。

## 3. 缩写使用规则

### 3.1 只使用行业或教材中常见的缩写

常用示例：

| 中文 | English | 缩写 |
|---|---|---|
| 生产可能性边界 | Production Possibilities Frontier | `PPF` |
| 边际收益 | Marginal Benefit | `MB` |
| 边际成本 | Marginal Cost | `MC` |
| 需求量 | Quantity Demanded | `Qd` 或 $Q_d$ |
| 供给量 | Quantity Supplied | `Qs` 或 $Q_s$ |
| 需求价格弹性 | Price Elasticity of Demand | `PED` |
| 供给价格弹性 | Price Elasticity of Supply | `PES` |
| 总收益 | Total Revenue | `TR` |
| 总成本 | Total Cost | `TC` |
| 消费者剩余 | Consumer Surplus | `CS` |
| 生产者剩余 | Producer Surplus | `PS` |
| 无谓损失 | Deadweight Loss | `DWL` |
| 平均总成本 | Average Total Cost | `ATC` |
| 平均可变成本 | Average Variable Cost | `AVC` |
| 边际收益 | Marginal Revenue | `MR` |
| 劳动边际产量 | Marginal Product of Labor | `MPL` |
| 边际替代率 | Marginal Rate of Substitution | `MRS` |
| 纳什均衡 | Nash Equilibrium | `NE` |

### 3.2 缩写冲突时优先写全称

例如 `PD` 既可能被用作价格歧视，也可能被理解为囚徒困境。课程中不要孤立使用 `PD`，应写：

- 价格歧视（Price Discrimination）；
- 囚徒困境（Prisoner's Dilemma）。

### 3.3 大小写和下标必须一致

- 价格使用 $P$；
- 数量使用 $Q$；
- 需求量使用 $Q_d$；
- 供给量使用 $Q_s$；
- 均衡价格使用 $P_e$；
- 均衡数量使用 $Q_e$；
- 利润使用 $\pi$。

同一节不能在 `Qd`、`QD`、`q_d` 之间随意切换。

## 4. 解释不能只是中文翻译

下面这种写法不合格：

> 边际收益（Marginal Benefit, MB）：边际的收益。

合格解释至少要回答“它测量什么”和“多一单位指什么”：

> **边际收益（Marginal Benefit, MB）**：把某项行动再增加一单位时得到的额外收益；这里的“一单位”可以是一件产品、一小时训练或一名员工。

每个解释优先包括：

1. 研究对象；
2. 变化的一单位；
3. 衡量方向；
4. 在决策中的作用；
5. 一个最小例子。

## 5. 容易混淆的术语必须成对解释

### 5.1 需求与需求量

- **需求（Demand, D）**：在各种可能价格下，消费者愿意且能够购买的数量关系，表现为整条需求曲线。
- **需求量（Quantity Demanded, $Q_d$）**：某一个具体价格下消费者愿意且能够购买的数量，是曲线上的一个点。

商品自身价格改变，通常导致沿需求曲线移动，即需求量改变；收入、偏好、相关商品价格等改变，才可能使整条需求曲线移动。

### 5.2 供给与供给量

- **供给（Supply, S）**：在各种可能价格下，生产者愿意且能够出售的数量关系。
- **供给量（Quantity Supplied, $Q_s$）**：某一个具体价格下生产者愿意且能够出售的数量。

### 5.3 会计利润与经济利润

- **会计利润（Accounting Profit）**：总收益减去显性成本。
- **经济利润（Economic Profit）**：总收益减去显性成本和隐性成本，包含机会成本。

### 5.4 短期与长期

- **短期（Short Run, SR）**：至少一种关键投入固定的分析期，并不等于固定的日历天数。
- **长期（Long Run, LR）**：所有相关投入都可以调整的分析期，也不等于“很多年以后”。

## 6. 公式旁必须给变量表

公式第一次出现时，不只给出等式，还要解释变量、单位和经济含义。

例如：

$$
\pi = TR - TC
$$

其中：

- $\pi$：利润（Profit），单位为元；
- $TR$：总收益（Total Revenue），单位为元；
- $TC$：总成本（Total Cost），单位为元。

随后说明：该式只是利润定义；若讨论经济利润，$TC$ 必须包括显性成本和隐性机会成本。

## 7. 图形旁必须给中英标签

图形首次出现时，应写：

- 纵轴：价格（Price, $P$）；
- 横轴：数量（Quantity, $Q$）；
- 需求曲线（Demand Curve, $D$）；
- 供给曲线（Supply Curve, $S$）；
- 均衡（Equilibrium, $E$）。

正文中必须解释曲线代表谁的行为、为什么移动、移动与沿曲线移动有什么不同。

## 8. 10～15 分钟微课程的术语区块

每一节建议在正文开头设置：

```markdown
## 本节专业术语

- **中文（English, ABBR）**：通俗解释。
- **中文（English）**：无公认缩写时不造缩写，并给出通俗解释。
```

一节最多引入 3～6 个新术语。超过这个数量时，应拆分课程或把次要术语放到“扩展阅读”。

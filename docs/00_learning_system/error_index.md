# 错误索引

错题本不只记录正确答案，而要记录错误怎样产生，以及用什么新证据证明自己已经修正。

## 错误类型

| 标签 | 典型表现 | 修正证据 |
|---|---|---|
| 概念混淆 | 把机会成本当作全部放弃项之和，或把“已支付”等同于“沉没” | 用新案例识别最佳替代方案和可收回部分 |
| 图形方向 | 混淆需求移动与需求量变化 | 闭卷画图并解释变化变量 |
| 计算单位 | 弹性、机会成本或利润的分子分母或单位不完整 | 保留单位完成第二道新题 |
| 忽略假设 | 直接套结论，不说明其他条件 | 写出假设、反例和适用边界 |
| 相关当因果 | 从共同变化直接推出因果 | 提出遗漏变量、反向因果和识别方法 |
| 实证规范混淆 | 把“应该”当作可由数据单独决定 | 分开事实后果与价值权衡 |
| 只给结论 | 没有主体、变量、机制和中间步骤 | 用“主体—约束—变量—机制—结果—边界”重答 |
| 应用越界 | 由几个经营现象直接证明持续垄断，或用微观模型直接推出股票值得买 | 补充竞争、财务、估值和风险证据 |

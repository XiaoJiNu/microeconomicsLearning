# 有效提示词记录

这份文件记录在与 AI 协作建设本仓库过程中**被验证有效**的提示词：凡是产出结果符合预期、或纠正了偏差方向的提示词，都登记在这里，持续跟踪、复用和迭代。

## 怎么用这份文件

1. 每次给 AI 下达重要任务后，把提示词要点登记到下表，并标注结果：有效 / 部分有效 / 需修正。
2. 对“部分有效”的提示词，写下修正版，下次直接用修正版。
3. 相似的重复要求（如“只改第 X 章”“保持 10–15 分钟”）提炼为**通用条款**，以后写提示词时直接引用，不必每次重写。

## 从日志里学到的写法

- **给验收标准比给做法更有效**：“不看原文也能掌握核心内容”比“写详细点”更能约束产出方向（P2 修正了 P1 的偏差）。
- **先小样本验证再批量**：要求“先 2 课看理解”避免了一次性返工 13 课（P2 中的 G4）。
- **明确否定项**：“其它章节的先不要”这类范围排除，能防止 AI 顺手改动无关内容（G1）。
- **风格要给参照物**：“参考某篇文章的图风格”比“做好看点”可执行（P1/P2）。

# AI学习协作协议

先读[进度](progress.md)及当前课程。已有诊断，不重复长诊断；课程已准备完成也不代表学习者已掌握。

## 教学

一次围绕当前课的核心问题。先给完整讲解和算例，学习者准备好后再做该课即时题。收到疑问时，定位最早没懂的一步，必要时用更小的数字和图补充，不把整个章节重新念一遍。

术语必须解释中文、原始英文、常用缩写；没有稳定缩写写明，不自行造词。公式说明变量、单位、条件和为何能这样写，不能把公式等式当作完整解释。参考[术语规范](terminology_standard_en_zh.md)。

可以类比模型训练、算力预算、产品开发，但要说清类比边界，不让工程术语遮住经济学问题。图形标轴、点和变化原因；标准图在[图形指南](../course_20h/visual_guide.md)。

可复制：

> 请读取本仓库的进度表和我指定的当前短课，先教完整讲解与算例，再让我做一道即时题。专业术语提供中文、英文、常用缩写和解释，数学符号单独定义。我有自动驾驶算法经验、经济学基础少。遇到我不懂的地方，找到最早断开的推理步骤，用一个更小的数例或图补充。不要重复全局诊断，也不要替我填写学习完成记录。

## 练习评审

先保存原始答案，再依次检查概念、假设、推理、计算和单位。指出已经成立的部分与最早错误，解释如何修正；给一道只改变一个条件的短题验证。不要连续增加题量，或因为一个错误清零整个单元。

答案已经折叠放在每课；学习者可自己展开。若用户选择闭卷评审，在其作答前不提前泄露答案。

## 费曼分享

单元末有完整示范稿，平时可使用[分享模板](../../templates/feynman_5min.md)。评审关注：一个具体问题、一条完整机制、一组可解释数字、一个条件边界。能用自己的话教会初学者，比记住所有英文拼写更重要。

## 证据与投资应用

AI可以帮助核算和寻找证据，但不能伪造学习者回答、真实企业数据或已完成分享。案例中的自编数字明确标为教学假设；现实分析须提供资料日期、统计口径及来源。

经营优势只是投资分析的一部分。评价企业需求、成本、竞争和激励后，应说明仍缺估值、现金流和市场预期等哪些信息，不直接由模型推出具体买卖建议。

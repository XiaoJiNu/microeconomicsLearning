# 学习与书写约定

## 一、结论必须标明性质

现实分析至少区分四层：

1. **事实**：可直接观察或由可靠数据支持；
2. **教材机制**：在明确假设下得到的模型结论；
3. **现实推断**：把模型迁移到具体案例后的判断；
4. **价值判断**：关于“应该怎样”的偏好或权衡。

不要把后面三层写成无条件事实。

## 二、图形规则

每张经济学图形必须包含：

- 横轴、纵轴名称及单位；
- 曲线名称；
- 初始均衡或初始选择；
- 发生变化的外生变量；
- 曲线移动方向，或沿曲线移动方向；
- 新结果与因果链；
- 至少一个保持不变的假设。

供求图默认价格 `P` 在纵轴、数量 `Q` 在横轴。使用其他约定时必须说明。

## 三、公式规则

每个公式必须同时解释：

- 变量代表什么；
- 数值单位；
- 计算方向；
- 隐含假设；
- 结果的经济含义；
- 一个极端情形检查。

不只写 `MB = MC`，还要说明这是判断下一单位是否值得的边际条件，并不要求总收益等于总成本。

## 四、案例分析规则

统一使用：

> 事实 → 决策主体 → 约束与激励 → 变化变量 → 适用模型 → 机制 → 结果 → 受益者/受损者 → 证据需求 → 适用边界

若说不清哪个变量改变了，暂时不要跳到结论。

## 五、AI 的角色

- **考官模式**：一次一题，只追问与评分，不提前讲答案；
- **教师模式**：围绕已暴露缺口讲解，不无边界扩展；
- **评审模式**：检查图形、计算、因果、假设和表达；
- **复习模式**：生成变式题并记录长期掌握证据。

详细指令见 [`ai_tutor_protocol.md`](ai_tutor_protocol.md)。

## 六、掌握证据

从弱到强依次为：

`看过 < 能复述 < 能画图/计算 < 能解释机制 < 能处理新案例 < 能指出边界 < 间隔后仍能完成`

“AI 已经解释过”不能替代自己的闭卷证据。

## 七、公开仓库边界

- 不上传教材 PDF 或大段教材正文；
- 只写自编总结、页码索引、个人推导和必要短引；
- 外部数据和案例记录来源、日期和口径；
- 不提交公司内部资料、未公开数据或敏感业务信息；
- 投资相关内容仅用于学习分析，不把单一模型写成确定性交易结论。

# 课程中的数学、图形与证据约定

## 读公式

先看研究对象、时间范围和单位，再代入数字。价格用每件多少元，数量用一段时期多少件，则价格乘数量得到这段时期的元数。公式记号不是英文缩写；每课会就地定义。

| 记号 | English | 含义 |
|---|---|---|
| $P,Q$ | Price, Quantity | 价格与数量 |
| $Q_d,Q_s$ | Quantity Demanded, Quantity Supplied | 在给定价格下的需求量与供给量 |
| $P_b,P_s,t$ | Buyer Price, Seller Net Price, Unit Tax | 买方价、卖方净价、每单位税额；$P_b-P_s=t$ |
| $P^*,Q^*$ 或 $P_e,Q_e$ | Equilibrium Price, Equilibrium Quantity | 均衡价格和数量；两种教材记法，单课内保持一致 |
| $\Delta$ | Change | “后值减前值”，例如 $\Delta Q=Q_2-Q_1$ |
| $\pi$ | Profit | 利润，明确会计或经济口径 |

边际成本（Marginal Cost, MC）是增量成本。离散产量用 $MC=\Delta TC/\Delta Q$；当每次增加一件时分母为1。连续可微模型才用导数。边际等式通常给候选最优点，仍要检查可行性、边界或总利润；课程不默认已会微积分。

需求价格弹性（Price Elasticity of Demand, PED）通常报告绝对值；收入和交叉价格弹性保留符号。中点法是区间口径，不直接当作任意幅度变化的精准预测。

## 读图

大多数供需图纵轴是价格、横轴是数量，这是经济学约定，不意味着横轴变量总是原因。先看一条曲线表示在其他条件固定时的关系，再区分沿曲线移动和整条曲线移动。

本仓库使用自编SVG精确图及数字表；[图形指南](../course_20h/visual_guide.md)给出方程和读图任务。图为机制示例，不是实际股票或黄金价格图。

公式使用 `$...$`、`$$...$$`。Markdown表格里的绝对值建议用 `\lvert...\rvert`，避免竖线破坏表格；优先保证Typora和常规Markdown阅读正常。

## 证据

区分四类句子：已观察到的事实、为分析暂设的假设、由模型推得的结果、带价值取向的评价。给真实数据写来源和日期；自编数字写“教学假设”，不把它包装成现实测量。

已经通过的诊断记录保留；课文、答案或示范稿的存在不构成学习完成证据。只有学习者本人作答后才能更新相应状态。

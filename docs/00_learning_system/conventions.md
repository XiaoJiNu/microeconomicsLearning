# 学习与书写约定

## 一、专业术语必须给出英文与缩写

每一篇可以独立学习的课程中，专业术语第一次出现时统一写成：

> **中文术语（English Term, ABBR）**：一句面向初学者的中文解释。

例如：

- **生产可能性边界（Production Possibilities Frontier, PPF）**：在资源和技术给定时，两类产出的最大可达组合形成的边界。
- **边际成本（Marginal Cost, MC）**：多生产或多行动一单位带来的额外成本。
- **需求量（Quantity Demanded, $Q_d$）**：某一具体价格下消费者愿意且能够购买的数量。

没有公认缩写时不得自行创造：

- **机会成本（Opportunity Cost）**：最佳被放弃方案的价值；
- **沉没成本（Sunk Cost）**：已经发生且当前无法收回的成本。

课程由可以独立打开的微课程组成，所以同一术语在每一节首次出现时都要重新定义。缩写不能在英文全称和中文解释之前出现。

详细规则见：

- [微观经济学中英术语书写规范](terminology_standard_en_zh.md)；
- [微观经济学中英术语表](../../references/microeconomics_glossary_en_zh.md)。

## 二、结论必须标明性质

现实分析至少区分四层：

1. **事实（Fact）**：可直接观察或由可靠数据支持；
2. **教材机制（Textbook Mechanism）**：在明确假设下得到的模型结论；
3. **现实推断（Real-World Inference）**：把模型迁移到具体案例后的判断；
4. **价值判断（Value Judgment）**：关于“应该怎样”的偏好或权衡。

不要把后面三层写成无条件事实。

## 三、图形规则

每张经济学图形必须包含：

- 横轴、纵轴的中文、英文、符号和单位；
- 曲线的中文、英文和符号；
- 初始均衡或初始选择；
- 发生变化的外生变量；
- 曲线移动方向，或沿曲线移动方向；
- 新结果与因果链；
- 至少一个保持不变的假设。

供求图默认：

- 纵轴为价格（Price, $P$）；
- 横轴为数量（Quantity, $Q$）；
- 需求曲线为 Demand Curve, $D$；
- 供给曲线为 Supply Curve, $S$。

使用其他约定时必须说明。

## 四、公式规则

每个公式必须同时解释：

- 变量的中文名称；
- 英文原词与常用缩写；
- 数值单位；
- 计算方向；
- 隐含假设；
- 结果的经济含义；
- 一个极端情形检查。

不能只写 `MB = MC`。应说明：

- `MB` 是边际收益（Marginal Benefit）；
- `MC` 是边际成本（Marginal Cost）；
- 这是判断下一单位是否值得的边际条件；
- 它不表示总收益必须等于总成本。

## 五、案例分析规则

统一使用：

> 事实 → 决策主体 → 目标 → 约束与激励 → 变化变量 → 适用模型 → 机制 → 结果 → 受益者／受损者 → 证据需求 → 适用边界

若说不清哪个变量改变了，暂时不要跳到结论。

## 六、10～15 分钟微课程规则

20 小时第一轮课程使用：

$$
10\text{ 个单元}\times8\text{ 节}\times15\text{ 分钟}=20\text{ 小时}
$$

每节只讲一个核心问题，并至少包含：

1. 本节专业术语；
2. 核心机制；
3. 一个最小例子、图形或计算；
4. 一个 2～3 分钟练习；
5. 一个常见误区；
6. 一句适用边界；
7. 一次 1 分钟无稿复述。

标准模板见 [`templates/micro_lesson_10_15min.md`](../../templates/micro_lesson_10_15min.md)。

## 七、AI 的角色

- **考官模式（Examiner Mode）**：一次一题，只追问与评分，不提前讲答案；
- **教师模式（Tutor Mode）**：围绕已暴露缺口讲解，不无边界扩展；
- **评审模式（Reviewer Mode）**：检查图形、计算、因果、假设和表达；
- **复习模式（Review Mode）**：生成变式题并记录长期掌握证据。

详细指令见 [`ai_tutor_protocol.md`](ai_tutor_protocol.md)。

## 八、掌握证据

从弱到强依次为：

```text
看过
< 能复述
< 能画图／计算
< 能解释机制
< 能处理新案例
< 能指出边界
< 间隔后仍能完成
```

“AI 已经解释过”不能替代自己的闭卷证据。

## 九、公开仓库边界

- 不上传教材 PDF 或大段教材正文；
- 只写自编总结、页码索引、个人推导和必要短引；
- 外部数据和案例记录来源、日期和口径；
- 不提交公司内部资料、未公开数据或敏感业务信息；
- 投资相关内容仅用于学习分析，不把单一模型写成确定性交易结论。

## 十、发布前检查

- [ ] 专业术语首次出现时给出英文原词；
- [ ] 公认缩写已经给出；
- [ ] 没有公认缩写时没有自行造词；
- [ ] 中文解释说明了术语“测量什么、用于什么”；
- [ ] 图形包含中英轴名、曲线名和单位；
- [ ] 公式包含变量、单位、假设和经济含义；
- [ ] 容易混淆的术语已成对区分；
- [ ] 现实推断没有被写成无条件事实；
- [ ] 学习者不查其他文件也能理解本节核心内容。

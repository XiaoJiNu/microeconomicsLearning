# 微观经济学学习系统

本目录保存诊断、路线、进度、复习和 AI 协作规则。普通学习者不需要在开始前通读这里的所有文件。

## 先判断你是否需要读本目录

- **还没有完成第一次诊断**：直接打开[诊断题](diagnostic_questions.md)，一次只做一题；
- **只想继续学当前单元**：直接进入[学习单元目录](../units/README.md)；
- **想知道当前做到哪里**：查看[学习进度表](progress.md)；
- **想安排延迟复习**：查看[间隔复习计划](review_schedule.md)；
- **想让 AI 按正确角色协作**：复制[AI 学习协作协议](ai_tutor_protocol.md)中的提示词；
- **想复用整套方法创建新课程**：阅读本页和[学习地图](learning_map.md)。

单元 `README.md` 会在需要时给出直接链接，不必提前理解整个目录。

## 最简方法：两层学习系统

### 第一层：开始整个领域时，做一次全局诊断

1. 定义希望形成的能力；
2. 闭卷回答跨模块诊断题；
3. 根据证据形成能力画像；
4. 调整单元顺序和练习强度；
5. 阶段结束后再做全局复诊。

全局诊断回答的是“先学什么”。它不是要求每个单元、每个小节都重新考试。

### 第二层：每个单元先完整学习，再集中验证

每个单元采用六步：

1. **开始**：打开单元主页，复制工作簿；
2. **完整学习**：连续学习 `lesson.md`，只记录理解和疑问；
3. **主线重建**：合上课程，用自己的话连接概念；
4. **独立练习**：完成图形、计算或推导；
5. **现实应用**：分析一个可观察的新案例；
6. **统一考核与归档**：最后闭卷终测、完成费曼输出并安排复习。

详细时间和文件对应关系见[两天／两小时单元学习流程](unit_workflow_2h.md)。

## 为什么不在每个小节后考试

第一次接触完整概念链时，频繁小测容易把注意力切碎。当前流程采用：

- 项目启动前进行一次全局诊断；
- 单元学习中允许提问、看例子和修正理解；
- 单元主要内容学完后，再集中完成练习、案例和终测；
- 延迟一段时间后，用新题验证保持与迁移。

这既保留主动回忆，也保证第一次学习的连续性。

## AI 与学习者分别做什么

| 阶段 | AI 的角色 | 学习者必须亲自完成 |
|---|---|---|
| 全局诊断 | 考官，只出题、追问和记录 | 原始答案、推理与信心判断 |
| 单元学习 | 教练，解释、画图、举例和回答疑问 | 阅读、复述、画图并提出具体问题 |
| 练习与应用 | 评审，指出第一处错误和排查顺序 | 计算、作图、案例判断和结果解释 |
| 单元终测 | 考官，按标准评分 | 闭卷答案和五分钟讲解 |
| 延迟复习 | 教练与评审，提供同机制新题 | 主动提取、迁移与修正 |

AI 生成的课程、答案和分享稿只能证明材料可用，不能证明学习者已经完成训练。

## 什么算学习证据

一个单元至少留下：

1. 主课程学习记录；
2. 一项独立图形、计算或推导；
3. 一个现实案例；
4. 一个变化条件、反例或错误案例；
5. 闭卷终测答案及评分；
6. 真实错误及修正；
7. 五分钟费曼输出；
8. 下一次复习日期。

最方便的保存方式，是复制单元的 `workbook.md` 到该单元的 `sessions/` 目录，在同一个文件中记录全过程。

## 状态只有四种

- `未开始`：还没有个人会话记录；
- `学习中`：已经开始，但课程、练习、案例或终测尚未完成；
- `待复习`：首次学习证据齐全并达到当天标准；
- `已掌握`：经过延迟复习、变化条件和综合任务验证。

“读完课程”“看过答案”或“当天得分合格”都不能单独标记为 `已掌握`。

## 最短学习路径

1. 完成一次全局诊断；
2. 查看[学习单元目录](../units/README.md)；
3. 打开当前单元 `README.md`；
4. 复制 `workbook.md`；
5. 连续学习 `lesson.md`；
6. 完成练习与现实案例；
7. 最后完成 `quiz.md`；
8. 提交后打开 `quiz_answers.md`；
9. 更新[学习进度](progress.md)并安排[间隔复习](review_schedule.md)。

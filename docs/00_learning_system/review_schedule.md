# 间隔复习计划

本页只回答“一个单元完成首次学习后，何时重新取证”。首次学习先按[两天／两小时单元学习流程](unit_workflow_2h.md)完成，复习结果回填[学习进度表](progress.md)。

复习的核心不是重读，而是先从记忆中提取。每次复习必须留下可观察结果：一句解释、一张图、一个计算、一个新案例或一次无稿讲解。

## 默认节奏

| 时间点 | 动作 | 建议用时 | 通过标准 |
|---|---|---:|---|
| D0 当天稍后 | 合上资料复述核心机制 | 3～5 分钟 | 能说出问题、变量、机制和边界 |
| D1 | 重做一项关键图形或计算 | 5～10 分钟 | 不依赖原例，过程与单位正确 |
| D3 | 改变一个条件重新分析 | 10 分钟 | 能先预测，再解释结果变化 |
| D7 | 完成同机制的新题或新案例 | 10～15 分钟 | 能迁移并指出假设 |
| D14 | 无稿讲解并接受追问 | 10 分钟 | 能修正追问，不只背定义 |
| D30 | 混合测验或综合案例 | 15～20 分钟 | 正确率不低于 80%，核心题正确 |

## 每次复习先打开什么

| 时间点 | 先做什么 | 完成自己的尝试后可以打开 |
|---|---|---|
| D0 | 合上所有资料，复述单元主线 | `cheatsheet.md` 核对遗漏 |
| D1 | 重做工作簿中的关键图形或计算 | `lesson.md` 对应小节、AI 评审 |
| D3 | 先写条件变化预测，再重新分析 | 历史工作簿和 `mistakes.md` |
| D7 | 使用 `quiz.md` 的延迟题或让 AI 生成变式题 | `quiz_answers.md`、错误索引 |
| D14 | 面向非专业听众无稿讲解 | `daily/` 中的参考稿 |
| D30 | 独立完成混合问题 | 速查表、历史会话和全局学习地图 |

复习开始时不要先打开答案、速查表或旧的正确结果。

## 复习规则

1. 先答题、画图或分析，后看参考材料；
2. 若失败，不把日期简单打勾，而是记录最早错误步骤；
3. D7 或更晚仍通过，才形成较强的长期保持证据；
4. 同一知识点连续两次失败，应增加新例子、反例或变化条件；
5. 分享稿可以用于完成后的核对，但不能在第一次回忆前先读稿；
6. 失败时只回补对应能力，不把整个单元清零。

## 状态怎样更新

- 首次学习证据齐全且达到当天阈值后，从 `学习中` 进入 `待复习`；
- 延迟复习失败时，记录失败能力并回到 `学习中`，只重做对应的最小任务；
- 完成 D1、D3、D7 主动复习，并在后续综合任务中正确迁移，且同一根因没有复发后，才可进入 `已掌握`；
- D14、D30 继续检查保持与迁移。

## 与全局诊断的关系

单元复习用于验证某一主题是否保持；全局诊断用于启动整个领域或阶段性重新评估整体能力。

完成第一轮十个单元后，再使用“相同能力、不同表面形式”的新题进行全局复诊，不用单次复习结果替代整体能力画像。

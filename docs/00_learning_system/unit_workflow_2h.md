# 每单元的学习节奏

每单元八课按知识依赖排列，整体可预留约2小时，十单元第一轮约20小时。这个文件保留旧链接，但不再规定两天各一分钟数表，也不要求先读完一个大lesson.md。

## 时间少：一次完成一个问题

核心阅读、跟算和一道即时题预计10–15分钟。某步没懂，记录卡点，下一次从这里继续。先完整读本课，再做本课题，不在每个段落后打断考试。

## 时间充足：连续几课，再分享

每天有60分钟时可连续学习3–4课，遇到困难适当减少；额外用5分钟分享今天最能讲清的一个机制。每天只有一课，也可以把自己的1分钟复述扩成分享，不需要为了“凑内容”提前读新理论。

## 单元末：把知识连起来

第八课提供综合案例、评分方法和完整费曼示范稿。先闭卷尝试，再看解释；稿子用来示范怎么讲，不要求背诵。第一次材料和证据齐全后记录“首轮通过/待复习”，安排之后的新题验证。

预计用时包括核心练习和复盘，但额外迁移题、分享打磨及延迟复习按需要增加。阅读速度不同不能改变过关标准，也不为了精确凑足20小时强行加作业。

# 学习地图与五级能力

当前完整材料是[10单元80课](../course_20h/README.md)，依次形成选择、市场、政策、企业与信息分析能力。精简诊断已完成；当前正式短课尚无个人完成证据，下一步从[01-01](../course_20h/unit_01_economic_thinking/01_scarcity_opportunity_cost.md)开始。

## 五级能力阶梯

| 等级 | 本阶段应具备的能力 | 最小过关证据 |
|---|---|---|
| 1：识别与复述 | 能用自己的话解释核心术语，并给出生活例子 | 闭卷解释，不照抄教材 |
| 2：图形与计算 | 能独立画基础模型、完成计算并写清单位 | PPF、供求图、成本图或完整计算过程 |
| 3：机制与应用 | 面对新事件能说明谁的约束改变、哪条关系变化、结果为何改变 | “变量—机制—结果—边界”的新案例 |
| 4：批判与诊断 | 能检查假设，区分相关与因果、实证与规范，并发现遗漏变量 | 一个反例、替代解释或政策副作用分析 |
| 5：综合决策 | 能组合多个模型比较不同方案对各主体和福利的影响 | 有图形、计算、证据需求和不确定性的分析报告 |

五级阶梯描述能力深度，十个单元描述学习内容和先后顺序。不能因为“看懂了”就自动升级。

## 学习顺序

先建立机会成本与模型语言，再学习贸易和供需。弹性解释反应程度，福利与公共部门分析政策；成本与市场势力解释企业决策，要素市场解释分配；最后用消费者、信息和行为理论加深对基础假设的认识。逐课链接和先修条件统一放在[课程地图](../course_20h/README.md)，避免维护相互矛盾的多份列表。

每课核心学习约10–15分钟，单元约2小时为投入参考。先完整学习当前课，再做一道即时题；单元末做综合应用与费曼分享。具体节奏见[学习流程](unit_workflow_2h.md)。

## 怎样推进

首次证据齐全后可以学习下一单元，同时安排[延迟复习](review_schedule.md)。发现缺口只返回对应课程，不把全部进度清零。说明原理、画图计算、迁移到新例子以及指出假设共同构成学习证据。见[工作簿](../course_20h/workbook.md)和[进度](progress.md)。

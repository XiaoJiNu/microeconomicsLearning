## 怎样更新本表

每次学习结束只更新当前一行：

1. 根据真实证据更新主课程、图形／计算、现实应用、终测、分享和复习状态；
2. 在“唯一下一步”中写一个 30 分钟内能开始的具体动作；
3. 首次学习证据齐全后，最多更新为 `待复习`；
4. 延迟复习使用[间隔复习计划](review_schedule.md)；
5. 个人产出链接到对应单元的 `sessions/` 或 `daily/`；
6. 不因为读完课程、复制答案或看过现成分享，就标记为完成。

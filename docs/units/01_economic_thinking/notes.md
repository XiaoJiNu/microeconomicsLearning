# 单元 01 压缩参考笔记

本页不是主课程。第一次学习请从[lesson.md](lesson.md)开始；只有课程某处仍不清楚，或完成独立练习后核对遗漏时，才使用本页。

## 一条主线

> 资源有限 → 必须选择 → 放弃最佳替代方案 → 比较下一单位收益与成本 → 激励改变行为 → PPF 表达约束 → 模型隔离机制 → 证据检验实证结论 → 价值判断决定规范取舍

## 核心概念

| 概念 | 最简解释 | 检查问题 |
|---|---|---|
| 稀缺性 | 有价值用途多于可同时使用的资源 | 哪种资源构成约束？ |
| 机会成本 | 最佳被放弃方案的价值 | 未选方案中谁排第一？ |
| 沉没成本 | 已发生且当前无法收回的成本 | 当前选择能改变它吗？ |
| 边际收益 | 再增加一单位带来的收益 | 下一单位得到什么？ |
| 边际成本 | 再增加一单位带来的成本 | 下一单位放弃什么？ |
| 激励 | 改变相对收益或成本的因素 | 谁会怎样适应规则？ |
| 模型 | 为特定问题保留关键机制的简化 | 忽略项会改变结论吗？ |

## 两个计算关系

边际决策：

$$
MB \ge MC
$$

生产一单位 $X$ 的机会成本：

$$
OC_X=\frac{|\Delta Y|}{|\Delta X|}
$$

计算后必须写单位。

## PPF 判断

- 边界上：在模型假设下有效率；
- 边界内：当前可达到但存在闲置或低效；
- 边界外：当前资源和技术下不可达到；
- 沿边界移动：重新配置既有资源；
- 整体外移：资源、技术或组织能力提高；
- 越来越陡：增加 $X$ 的机会成本递增。

## 循环流向

| 主体／市场 | 实物流 | 货币流 |
|---|---|---|
| 家庭与产品市场 | 获得商品和服务 | 支付消费支出 |
| 企业与产品市场 | 提供商品和服务 | 获得销售收入 |
| 家庭与要素市场 | 提供劳动、资本等 | 获得工资、租金、利润等 |
| 企业与要素市场 | 使用生产要素 | 支付要素收入 |

模型有意省略政府、金融、国际贸易和主体差异。

## 三组不要混淆

### 微观与宏观

- 微观：消费者、企业和具体市场；
- 宏观：总产出、失业、通胀和增长。

### 实证与规范

- 实证：原则上可以用证据判断真伪；
- 规范：包含“应该怎样”的价值权衡。

### 相关与因果

相关性出现时至少检查：

1. 遗漏变量；
2. 反向因果；
3. 选择偏差；
4. 指标和测量问题；
5. 共同趋势。

## 现实分析模板

> 事实 → 主体 → 目标 → 约束 → 方案 → 最佳替代 → 变化变量 → 机制 → 结果 → 证据 → 边界

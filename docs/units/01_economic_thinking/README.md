## 本单元要解决的核心问题

> 当资源有限而目标不止一个时，怎样识别真正的代价，用边际和模型分析选择，并把可检验的事实判断与价值判断分开？

## 完成后能够做到

1. 区分稀缺性、权衡、机会成本和沉没成本；
2. 用边际收益与边际成本判断“再多做一单位”是否值得；
3. 画出生产可能性边界，解释边界上、边界内、边界外和整体移动；
4. 用循环流向模型说明家庭、企业和市场之间的基本关系；
5. 解释为什么模型可以简化现实，以及简化何时会导致结论失效；
6. 区分实证与规范、相关与因果；
7. 用“主体—目标—约束—变量—机制—结果—证据—边界”分析新问题；
8. 完成两份可在约 5 分钟内讲完的费曼分享。

## 步骤 2：`lesson.md` 怎样学习

按顺序学习，不需要在目录之间来回跳：

| 知识块 | 课程部分 | 学完后应能回答 |
|---|---|---|
| A | 稀缺性、权衡与机会成本 | 为什么选择不可避免，机会成本为什么不是所有放弃项之和？ |
| B | 沉没成本、边际决策与激励 | 为什么过去投入不能决定当前选择，下一单位怎样判断？ |
| C | PPF、模型与循环流向 | 怎样用图形表达约束，模型为什么可以简化？ |
| D | 微观／宏观、实证／规范、相关／因果 | 哪些结论可以检验，哪些包含价值判断，因果需要什么证据？ |
| E | 综合分析模板 | 怎样把现实问题拆成主体、约束、变量、机制、结果和边界？ |

每完成一行，在工作簿中写：

- 一句话理解；
- 一个关键图形、公式或关系；
- 一个仍不清楚的问题。

这不是考试。遇到不明白的地方，应先要求生活化例子、二维图形或更小的数字例，再继续。

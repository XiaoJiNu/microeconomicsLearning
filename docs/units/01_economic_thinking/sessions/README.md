# 单元 01 个人学习证据

本目录保存学习者实际完成的课程记录、图形、计算、案例、终测和延迟复习。公共课程、参考答案和 AI 生成内容不能替代个人证据。

## 开始一次新会话

从仓库根目录执行：

```bash
cp docs/units/01_economic_thinking/workbook.md \
  docs/units/01_economic_thinking/sessions/YYYY-MM-DD_attempt-1.md
```

文件名建议：

```text
YYYY-MM-DD_attempt-N.md
```

例如：

```text
2026-08-25_attempt-1.md
2026-08-26_attempt-2.md
2026-09-01_D7-review.md
```

## 使用规则

1. 每次学习先建立新的工作簿副本；
2. 第一版回答、图形和计算只追加，不在看到答案后覆盖；
3. 修正时写清“第一处差异—根因—修正后结论”；
4. 终测题与答案分开打开；
5. 延迟复习使用新文件或新章节，避免把历史错误改得看不出来；
6. 只提交适合公开的个人学习内容。

## 不应提交

- 教材 PDF 或大段教材原文；
- 公司内部数据、业务指标、代码或文档；
- 真实客户、项目、账户和个人隐私；
- 无法确认授权的图表或资料；
- AI 生成但自己没有检查的答案。

## 最小证据

一次完整的第一轮会话至少包含：

- 主课程学习记录；
- 一条知识主线；
- 机会成本、边际决策和 PPF 的独立过程；
- 一个现实案例；
- 一个条件变化；
- 闭卷终测与评分；
- 两次五分钟费曼输出；
- 错误根因；
- D0、D1、D3、D7、D14、D30 复习日期。

仓库作者或其他学习者的勾选状态不会自动成为你的学习进度。

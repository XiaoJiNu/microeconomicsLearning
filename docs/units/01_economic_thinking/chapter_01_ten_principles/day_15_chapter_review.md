## 3 分钟：闭卷画三张地图

先不要看答案，尝试自己画出三组结构。

### 地图一：个人怎样决策

```text
资源稀缺
→ 面临权衡
→ 识别机会成本
→ 排除真正的沉没成本
→ 比较边际收益与边际成本
→ 预测人对激励的反应
```

### 地图二：人们怎样相互作用

```text
分工与贸易
→ 扩大可获得的成果
→ 价格传递信息与激励
→ 市场协调分散决策
→ 外部性和市场势力可能导致失灵
→ 政府有时可以改善结果
```

### 地图三：整体经济怎样运行

```text
生产率
→ 长期生活水平

货币增长长期快于真实产出
→ 通胀压力

总需求短期变化
→ 产出、就业和价格共同变化
→ 通胀与失业可能存在短期权衡
```

## 4 分钟：闭卷检查

用自己的话快速回答：

1. 稀缺性与机会成本有什么区别？
2. 为什么已经花掉的钱不一定全部是沉没成本？
3. 为什么要比较边际量？
4. 价格怎样协调消费者和生产者？
5. 为什么污染可能导致产量过高？
6. 为什么生产率不等于工作更久？
7. 为什么货币增加不等于真实财富增加？
8. 为什么通胀与失业必须强调短期？

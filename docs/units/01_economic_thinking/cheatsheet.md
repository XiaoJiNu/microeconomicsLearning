# 单元 01 一页速查表

本页只在完成主课程和首次独立练习后使用。它是复习卡，不是课程正文，也不能替代工作簿中的图形、计算和现实分析。

## 一条主线

> 稀缺性 → 选择 → 机会成本 → 边际决策 → 激励 → PPF → 模型 → 实证与规范 → 因果证据 → 适用边界

## 九个核心概念

| 概念 | 最简解释 | 常见误区 |
|---|---|---|
| 稀缺性 | 资源不足以同时满足所有有价值用途 | 等同于贫穷 |
| 权衡 | 得到更多一种目标通常要放弃另一种 | 只说“有得有失” |
| 机会成本 | 最佳被放弃方案的价值 | 把所有放弃项相加 |
| 沉没成本 | 已发生且当前无法收回的成本 | 因为投入多就继续 |
| 边际变化 | 再多一单位带来的变化 | 用总量代替新增量 |
| 激励 | 改变相对收益或成本的因素 | 忽略替代和规避行为 |
| 模型 | 为特定问题保留关键机制的简化 | 认为越复杂越好 |
| 实证 | 原则上可由证据检验 | 把预测与价值判断混在一起 |
| 规范 | 涉及应该怎样的价值权衡 | 认为数据能自动决定价值 |

## PPF 六问

1. 横轴和纵轴是什么，单位是什么？
2. 点在边界上、边界内还是边界外？
3. 这是沿边界移动还是整条边界移动？
4. 每增加一单位横轴产出放弃多少纵轴产出？
5. 机会成本是否递增？
6. 哪项资源、技术或制度假设改变了？

## 循环流向

- 家庭在产品市场购买商品，在要素市场提供劳动和资本；
- 企业在要素市场购买要素，在产品市场销售商品；
- 实物流与货币流方向相反；
- 政府、金融和国际贸易等是该简化模型的省略项。

## 因果检查五问

1. 是否有遗漏变量？
2. 是否可能反向因果？
3. 样本是否存在选择偏差？
4. 指标是否真正代表目标？
5. 有无随机、准实验或可信对照？

# 单元 01 一页速查表

> 只在完成首次闭卷测验后使用。

## 一条主线

> 资源有限 → 必须选择 → 选择会放弃最佳替代方案 → 比较下一单位收益与成本 → 激励变化会改变行为 → 模型帮助隔离机制 → 证据检验结论。

## 核心概念

| 概念 | 最简解释 | 常见误区 |
|---|---|---|
| 稀缺性 | 资源不足以同时满足所有有价值用途 | 等同于贫穷或绝对缺少 |
| 机会成本 | 最佳被放弃方案的价值 | 把所有放弃项相加；只看金钱 |
| 沉没成本 | 已发生且当前无法收回的成本 | 因为投入多就继续 |
| 边际变化 | 再多一单位带来的变化 | 用总量代替下一单位 |
| 激励 | 改变相对收益或成本的因素 | 假设行为不会适应规则 |
| 模型 | 为特定问题保留关键机制的简化 | 认为越复杂越好 |
| 实证 | 原则上可用证据检验 | 把预测当成价值判断 |
| 规范 | 涉及应该怎样的价值权衡 | 认为数据能自动决定价值 |
| 因果 | X 的变化导致 Y 的变化 | 把相关性当因果 |

## 两个公式

$$
MB \ge MC
$$

$$
OC_X = \frac{|\Delta Y|}{|\Delta X|}
$$

计算后必须写出单位。

## PPF 判断

- 边界上：有效率；
- 边界内：可达到但低效率；
- 边界外：当前不可达到；
- 沿边界移动：重新配置；
- 整体外移：资源、技术或制度改善；
- 越来越陡：生产 X 的机会成本递增。

## 因果检查四问

1. 是否有遗漏变量？
2. 是否可能反向因果？
3. 样本是否存在选择偏差？
4. 有无对照、随机变化或可信的准实验？

## 现实分析句式

> 对于主体 ______，约束 ______ 发生变化，使 ______ 的边际收益或成本改变，因此行为可能从 ______ 变为 ______。该结论依赖 ______，还需要 ______ 证据。

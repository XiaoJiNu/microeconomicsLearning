# 学习单元目录

本目录是普通学习者的主要入口。不要从头浏览所有文件；选择当前单元后，以该单元 `README.md` 的顺序为准。

## 30 秒开始一个单元

1. 打开当前单元 `README.md`；
2. 复制 `workbook.md` 到该单元的 `sessions/`；
3. 从头学习 `lesson.md`，课程完成前不打开终测；
4. 按工作簿完成图形、计算和现实案例；
5. 最后打开 `quiz.md`；
6. 保存完整答案后，再打开 `quiz_answers.md`；
7. 更新进度并安排延迟复习。

> 每个单元最常用的三个文件是 `README.md`、`lesson.md` 和 `workbook.md`。

通用方法见[学习系统说明](../00_learning_system/README.md)，两天时间安排见[两天／两小时流程](../00_learning_system/unit_workflow_2h.md)。

## 每个单元文件的固定职责

| 文件 | 用途 | 什么时候打开 |
|---|---|---|
| `README.md` | 单元导航、顺序和验收标准 | 每次开始或切换步骤时 |
| `lesson.md` | 第一次完整学习的主课程 | 建立工作簿后 |
| `workbook.md` | 保存个人全过程 | 开始时复制，全程填写 |
| `notes.md` | 压缩参考和补充解释 | 课程仍不清楚或复习时 |
| `practice.md` | 图形、计算和现实案例 | 主课程完成后 |
| `quiz.md` | 不含答案的闭卷终测 | 课程与练习完成后 |
| `quiz_answers.md` | 评分点和参考答案 | 已保存完整终测后 |
| `cheatsheet.md` | 一页速查 | 首次练习完成后 |
| `mistakes.md` | 真实错误和延迟复验 | 发生可复现错误时 |
| `sessions/` | 个人会话证据 | 开始建立，结束归档 |

不存在的可选文件可以省略，但 `README.md`、`lesson.md`、`workbook.md`、`quiz.md` 和分离的答案文件应尽量保留。

## 状态约定

- `未开始`：没有个人会话记录；
- `学习中`：课程、练习、案例或终测尚未完成；
- `待复习`：首次证据齐全并达到当天标准；
- `已掌握`：通过延迟复习、变化条件和综合任务。

程序运行成功、参考答案已阅读、现成分享稿已准备或当天终测通过，都不能单独把状态改成 `已掌握`。

## 一个单元什么时候可以推进

首次学习达到 `待复习` 后，可以安排好 D0、D1、D3、D7、D14、D30 复习，并开始下一单元。

不需要等待 30 天才进入下一单元，但必须保留复习计划。后续单元若暴露前置缺口，只回补对应能力。

## 如何使用微课程

每个普通学习日约 10 分钟：

1. 1 分钟回忆昨天的一句话；
2. 5～6 分钟阅读当天课程；
3. 2 分钟完成最小练习；
4. 1～2 分钟合上资料复述。

Day 07、Day 11、Day 15 是阶段复盘日，其中包含约 5 分钟的费曼分享。

## 状态约定

- `未开始`：没有个人学习记录；
- `学习中`：已经开始，但微课程、练习或复盘尚未完成；
- `待复习`：第一轮证据齐全，已安排延迟复习；
- `已掌握`：已经通过延迟复习、变化条件和后续迁移。

阅读现成课程、查看答案或完成一次当天练习，都不能单独标记为 `已掌握`。

# 精通之路

目标只有一个：你能把十大原理用在教科书情景上，并且知道哪三条只许停在边界上。

这不是「顺着一本书的目录读完」的课表。下面每一项是一个知识点。知识点里有四道硬门槛，顺序固定：

1. **认出**：看见情景，交到正确的原理或门上。
2. **讲清**：用自己的话把机制说完。概念类的精通靠这一步，不靠把选项背下来。
3. **用上**：面对一段情景，写出该进比较的量，把不该进的量留在外面。
4. **自核**：合上活书和答案，按必答点再讲一遍。

规则：

- 当前门槛没过，下一门槛的题不要做。
- 当前知识点的自核没过，下一个知识点不要开始。
- 活书可以先翻。翻过只表示材料读过，状态仍是「学习中」，不是「已精通」。
- 选择和判断必须与 [要点](ANSWER_KEY.md) 一致。简答要盖住每一个必答点。用课本以外的行业故事代替答案，不算过。

状态用三个词：未开始、学习中、已精通。

## 知识点 1 · 多要一边，少掉哪一边

- [ ] 认出
- [ ] 讲清
- [ ] 用上
- [ ] 自核

**认出过关：** [DT-01](PRACTICE.md#dt-01)、[DT-02](PRACTICE.md#dt-02) 都与要点一致。你能把冰淇淋与披萨、枪炮与黄油交到权衡上，并且不把枪炮与黄油说成效率对平等。

**讲清过关：** [DT-11](PRACTICE.md#dt-11) 的必答点都说到。你用自己的话分开三对：国防与消费品、清洁与收入、饼的大小与切法。你停在看清让步，不宣布赢家。

**用上过关：** [DT-21](PRACTICE.md#dt-21) 能写出少排污得到什么、收入可能在哪里让步，并说明这不是枪炮与黄油，本路也不据此取消环保。

**自核过关：** 合上书完成 [DT-31](PRACTICE.md#dt-31)。讲不出「先写少掉的一边」，这一项保持学习中。

## 知识点 2 · 成本只记下一最好

- [ ] 认出
- [ ] 讲清
- [ ] 用上
- [ ] 自核

**认出过关：** [DT-03](PRACTICE.md#dt-03)、[DT-04](PRACTICE.md#dt-04)。工资常常是最大的一块；食宿只算多出来的一截。

**讲清过关：** [DT-12](PRACTICE.md#dt-12)。显成本、隐成本、剔除的部分、只记最佳替代，四点都在。

**用上过关：** [DT-22](PRACTICE.md#dt-22)。最佳替代若不是工作，工资退出，换成那件事的价值。

**自核过关：** [DT-32](PRACTICE.md#dt-32)。合上书仍能把上大学的三栏讲完。

## 知识点 3 · 再多一单位值不值

- [ ] 认出
- [ ] 讲清
- [ ] 用上
- [ ] 自核

**认出过关：** [DT-05](PRACTICE.md#dt-05)、[DT-06](PRACTICE.md#dt-06)。下一张票比 300 美元和花生饮料；水的价格不因为「更不可少」就应当更高。

**讲清过关：** [DT-13](PRACTICE.md#dt-13)。500 美元、10 万美元、花生饮料、水和钻石，各回答什么，都说到。

**用上过关：** [DT-23](PRACTICE.md#dt-23)。写出卖这一张的理由，并给留在外面的总账一个名字：沉没成本。

**自核过关：** [DT-33](PRACTICE.md#dt-33)。能独立说出「边际收益大于边际成本才再做」，并用机票证明平均数不进房间。

- [ ] 自核

## 知识点 9 · 把情景交对

前八项的自核都过了，才打开这项。材料是 [实践页](books/ch01_ten_principles/pages/09_scenes.md)。

- [ ] 认出
- [ ] 讲清
- [ ] 用上
- [ ] 自核

**认出过关：** 实践页里的三道热身，你在不看答案时能交对。路径上再用 [DT-39](PRACTICE.md#dt-39) 把「这一路要碰到」和「这一路不展开」分开。

**讲清过关：** [DT-30](PRACTICE.md#dt-30)。学生的一小时上，权衡、机会成本、边际、激励四句接得上。

**用上过关：** [DT-41](PRACTICE.md#dt-41)。少排污至少拆成权衡、外部性、激励，并且不把它直接叫成货币问题。

**自核过关：** [DT-40](PRACTICE.md#dt-40)。合上所有页，写出十条，放进「决策、互动、整体经济」，并标明：决策四条要能用，贸易和价格要能讲机制，政府要能认门，整体经济只留边界句。三扇门的名字写在政府那一条旁边。

三项都过，这条精通之路才算走完。走完不等于宏观已经会，只等于第 1 章这些门口你能自己把守。

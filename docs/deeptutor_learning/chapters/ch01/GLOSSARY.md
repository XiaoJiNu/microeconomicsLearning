# 术语表 · 第 1 章

[学习台](README.md) · [掌握路径](MASTERY_PATH.md)

每条只写本包里的用法。英文写在括弧里，方便你以后对原书索引，不必背缩写。

| 术语 | 在本章里的意思 | 活页 | 不要和它叠成一件事 |
|---|---|---|---|
| 稀缺（scarcity） | 资源不够把想做的用途一起做完。 | [01](book/01_tradeoffs.md) | 标价高 |
| 权衡（trade-off） | 多得到一边，就少得到另一边。 | [01](book/01_tradeoffs.md) | 已经选边 |
| 效率（efficiency） | 把人们所看重的饼做大。 | [01](book/01_tradeoffs.md) | 枪炮与黄油这一对 |
| 平等（equality / equity） | 把饼和负担分得更匀。原书这一对常写作效率与平等。 | [01](book/01_tradeoffs.md) | 市场失灵的一扇门 |
| 机会成本（opportunity cost） | 为了得到某物而放弃的最佳替代的价值。 | [02](book/02_opportunity_cost.md) | 所有没做的事之和 |
| 最佳替代（next-best alternative） | 若不做现在这个选择，你下一步真正会去做的那一件。 | [02](book/02_opportunity_cost.md) | 任意一件没做的事 |
| 显成本（explicit cost） | 为了这个选择才另外付出的钱，例如学费和书本。 | [02](book/02_opportunity_cost.md) | 全部成本 |
| 隐成本（implicit cost） | 没有新账单，但自有的时间若改作最佳替代所能得到的，例如放弃的工资。 | [02](book/02_opportunity_cost.md) | 可以忽略的感觉 |
| 理性人（rational person） | 在办得到的范围内，按自己的目标比较得失的人。 | [03](book/03_marginal.md) | 道德评语 |
| 边际变动（marginal change） | 在现有计划边上做的小幅增减。 | [03](book/03_marginal.md) | 全有或全无 |
| 边际收益（marginal benefit） | 再增加一单位所多得到的收益。 | [03](book/03_marginal.md) | 总收益 |
| 边际成本（marginal cost） | 再增加一单位所多付出的成本。 | [03](book/03_marginal.md) | 平均成本 |
| 平均成本（average cost） | 到目前为止的总成本除以单位数。空位机票上是 500 美元。 | [03](book/03_marginal.md) | 下一张票的成本 |
| 沉没成本（sunk cost） | 已经发生、无法收回的成本。卖不卖下一张，它都不变。 | [03](book/03_marginal.md) | 机会成本 |
| 激励（incentive） | 会推动人行动的奖赏或惩罚。收益或代价一改，做法就改。 | [04](book/04_incentives.md) | 只看条文点名的那一列 |
| 非预期后果（unintended consequence） | 被点名的行为变了，人同时转向没被点名、因而相对变便宜的行为。安全带与车速是课本例子。 | [04](book/04_incentives.md) | 「政策一定失败」 |
| 贸易（trade） | 各方把自己相对更适合做的成果换给对方。 | [05](book/05_trade.md) | 零和比赛 |
| 专业化（specialization） | 把更多时间放在放弃得较少的那类任务上。 | [05](book/05_trade.md) | 样样自己做 |
| 贸易互利 | 交换之后可以好于单干。不保证平分。 | [05](book/05_trade.md) | 平等 |
| 比较优势（comparative advantage） | 放弃的比例不同，因而相对更适合做某件事。本章只记住这个名字，不算数值。 | [05](book/05_trade.md) | 谁做得更快 |
| 市场（market） | 许多交换汇在一起的安排，不必是一个摊位。 | [06](book/06_markets.md) | 总调度 |
| 市场经济（market economy） | 企业和家庭决定雇谁、生产什么、为谁工作、买什么。 | [06](book/06_markets.md) | 中央计划 |
| 价格（price） | 社会价值和生产成本被压成的一个数，也是激励。 | [04](book/04_incentives.md)、[06](book/06_markets.md) | 物价总体水平 |
| 看不见的手（invisible hand） | 人们各自关心自己，价格仍常常把决定引向对社会更好的结果。 | [06](book/06_markets.md) | 一位总调度 |
| 产权（property rights） | 人可以拥有并控制稀缺资源。市场前提。 | [07](book/07_government.md) | 再分配方案 |
| 市场失灵（market failure） | 市场自己达不到有效配置。 | [07](book/07_government.md) | 每一种政府行动 |
| 外部性（externality） | 旁观者承担了成本或得到了收益，当事人的边际比较里没有这一项。课本例子是工厂的烟。 | [07](book/07_government.md) | 一口井 |
| 市场势力（market power） | 单独一家或一小群人能把价格定到竞争较多时的水平之外。课本例子是镇上唯一一口井。 | [07](book/07_government.md) | 篮球与国际象棋的收入差 |
| 信息不完全（imperfect information） | 一方掌握另一方没有的关键事实。课本例子是出过事故的旧车。本章只认名。 | [07](book/07_government.md) | 已经算完的信息模型 |
| 再分配（redistribution） | 改变谁分到多少，例如所得税和福利。不是三扇门之一。 | [07](book/07_government.md) | 外部性 |
| 生产率（productivity） | 一小时劳动生产的物品与劳务。原理 8 的边界标签。 | [08](book/08_macro_boundary.md) | 更忙、工时更长 |
| 通胀（inflation） | 物价总体水平的上升。原理 9 的边界标签。 | [08](book/08_macro_boundary.md) | 一种物品的相对价格 |
| 短期权衡（short-run tradeoff） | 本章专指大约一两年里，通胀与失业被推向相反方向。原理 10 的边界标签。 | [08](book/08_macro_boundary.md) | 枪炮与黄油；也不是长期关系 |

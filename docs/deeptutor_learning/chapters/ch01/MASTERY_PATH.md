# 掌握路径 · 第 1 章

[学习台](README.md) · [练习](PRACTICE.md) · [要点](ANSWER_KEY.md)

四关按顺序走：**认出 → 讲清 → 用上 → 自核**。前一关过了，才做下一关的题。活页可以整章读完再过关，也可以读完一块就打该块的「认出」。

过关看的是要点，不是措辞是否和答案页一模一样。选择、判断必须和要点一致。简答要盖住该题列出的每一个必答点。漏一个，这一题不过，回到对应活页重读小测验。

本路径只用课本情景。合上书之后若愿意用自己的一小时再走一遍原理 1–4，那是迁移，不计入过关。

## 关卡 1 · 认出

**先读：** [01](book/01_tradeoffs.md) [02](book/02_opportunity_cost.md) [03](book/03_marginal.md) [04](book/04_incentives.md) [05](book/05_trade.md) [06](book/06_markets.md) [07](book/07_government.md) [08](book/08_macro_boundary.md)

**过关的样子**

- 看见课本例子，能说出它在服务第几条原理、落在三块中的哪一块。
- 冰淇淋与披萨、枪炮与黄油归原理 1。效率与平等是另一对权衡，不和枪炮与黄油写成同一对。
- 上大学放弃的工资归原理 2。空位机票、水和钻石归原理 3。安全带归原理 4。
- 种粮与养牛归原理 5。冰淇淋涨价、没有总调度，归原理 6。
- 污染、一口井、旧车分别是外部性、市场势力、信息不完全。再分配不在这三扇门里。
- 每小时的产出、德国报纸、大约一两年里的相反方向，分别贴在原理 8、9、10 上。

**做这些题：** [P-R01](PRACTICE.md#p-r01) 至 [P-R10](PRACTICE.md#p-r10)

**怎样算过：** P-R01 至 P-R08 的选择或判断与要点一致；P-R09 三扇门全部贴对；P-R10 三条边界全部贴对。

**过关后解锁：** 关卡 2，以及练习里的 P-E01 至 P-E08。没过的原理只重读对应的一页，不必把八页再通读一遍。

## 关卡 2 · 讲清

**过关的样子：** 能用自己的话把机制讲完，而不是只报原理编号。

- 权衡写完之后，成本还要收成最佳替代，不能把所有没做的事加总。
- 上大学的食宿只计入比两边都要付的那一截多出来的部分；放弃的工资是隐成本，常常是最大的一块。
- 再多一单位比边际收益和边际成本。平均成本和已经发生的飞行成本留在「卖不卖下一张」的外面。
- 安全带有点名的一侧，也有车速和行人那一侧。汽油税让开车变贵之后，人会改去课本里写过的那些做法。
- 即使一方两件事都更快，放弃的比例不同仍可能使双方都好于单干。互利不保证平分。
- 价格同时带着社会价值和生产成本。价格若不许调整，看不见的手就难起作用。
- 产权是前提。效率与平等是两条理由。三扇门各漏了不同的东西。把饼分匀不是第四扇门。
- 原理 8、9、10 各有一句边界，也各有一件本章明确不做的事。

**做这些题：** [P-E01](PRACTICE.md#p-e01) 至 [P-E08](PRACTICE.md#p-e08)

**怎样算过：** 每题的必答点都说到。

**过关后解锁：** 关卡 3，以及 P-A01 至 P-A08。

**过关的样子：** 面对一段课本情景，能把该进比较的量写出来，把不该进比较的量留在外面，并标上原理编号。这一关不计算比较优势，不画供需图，不给再分配方案打分。

**过关后解锁：** 关卡 4，以及 P-S01 至 P-S04。

## 关卡 4 · 自核

合上活页和答案，再打开练习的最后四题。

**过关的样子**

- 凭记忆写出十条短标题，放进三块，并标上「会用 / 直觉 / 认门 / 只标边界」。
- 用四句话收束：决策四条怎样接成一条链；贸易和价格各在做什么；三扇门各漏了什么、再分配为什么在门外；三条宏观边界各停在哪里。
- 用学生的一小时把原理 1–4 串完。
- 能把「本章要碰到」和「本章不展开」分开，包括比较优势计算、供需图、货币公式、通胀与失业的曲线。

**做这些题：** [P-S01](PRACTICE.md#p-s01) 至 [P-S04](PRACTICE.md#p-s04)

**怎样算过：** 四题必答点都说到。

**过关之后：** 本实验包的第 1 章走完一遍。这不表示宏观已经会，也不表示摘要课的清单可以勾完。接下来读原书第 1 章目录，用 [术语表](GLOSSARY.md) 核对名词，再按 [进一步阅读](FURTHER_READING.md) 决定后章。

## 最容易混的八对

讲清和自核之前，用自己的话各说一句。说错了就回到括弧里的页。

1. 枪炮与黄油，和效率与平等，是两对权衡。（[01](book/01_tradeoffs.md)）
2. 机会成本只记最佳替代。（[02](book/02_opportunity_cost.md)）
3. 下一张机票看花生和饮料，不看 500 美元的平均。（[03](book/03_marginal.md)）
4. 安全带减轻的是点名的伤亡，车速会另外滑动。（[04](book/04_incentives.md)）
5. 贸易带来的好处是相对单干而言的。（[05](book/05_trade.md)）
6. 个别物品涨价，不等于通胀。（[06](book/06_markets.md)、[08](book/08_macro_boundary.md)）
7. 再分配不是市场失灵的第四扇门。（[07](book/07_government.md)）
8. 原理 10 的相反方向是短期的。（[08](book/08_macro_boundary.md)）

## 教材依据

曼昆《经济学原理》微观分册第 8 版，第 1 章「十大经济学原理」。

| 原书的块 | 原理 | 本包怎么处理 |
|---|---|---|
| 人们如何做出决策 | 1–4 权衡、机会成本、边际、激励 | 活页练到能判断 |
| 人们如何相互影响 | 5 贸易；6 市场与看不见的手；7 政府 | 5–6 建立直觉；7 认产权、效率与平等、三扇门。信息不完全只认名 |
| 整体经济如何运行 | 8 生产率；9 货币与通胀；10 通胀与失业的短期权衡 | 只标边界。模型、公式、曲线留给宏观 |

课本例子：枪炮与黄油，冰淇淋与披萨，上大学，空位机票，水和钻石，苹果，汽油税，安全带，家庭自给，种粮与养牛，冰淇淋涨价，污染，镇上的一口井，出过事故的旧车，再分配，德国一份报纸的物价，生产率，以及短期里把支出和失业放在一起的那次争论。

## 三块表面怎么用

建议顺序：

1. 读完本页的地图。
2. 按 Book 从原理一读到原理八至十。每一页先读概念，再做页内小测验。小测验的要点折在当页，先答再展开。
3. 打开 [掌握路径](MASTERY_PATH.md)。四关是认出、讲清、用上、自核。每一关写明过关的样子，以及哪几道练习做完才解锁下一关。
4. 练习在 [PRACTICE.md](PRACTICE.md)，要点只在 [ANSWER_KEY.md](ANSWER_KEY.md)。做题时先不要打开答案。
5. 名词不顺，查 [术语表](GLOSSARY.md)。想知道后章读什么，看 [进一步阅读](FURTHER_READING.md)。想抽查，用 [抽认卡](FLASHCARDS.md)。

一页活页大约 8–12 分钟。八页读完大约一个半小时；四关练习再留大约一小时。可以分三次坐下来，每次读完一块再打该块的「认出」。

## 活页上的块

每一页用同一种块。在 GitHub 上它们会显示成提示条；换成纯文本阅读器时，仍是带标签的引用。

| 块 | 标签 | 你要做的事 |
|---|---|---|
| 概念讲解 | 正文 | 顺着读 |
| 标注 | `NOTE` | 把课本例子放回原理 |
| 注意 | `WARNING` | 看这一对最容易混的概念 |
| 关键术语 | `TIP` | 停下来，用自己的话讲这几个词 |
| 深度解析 | `IMPORTANT` | 可选。只加厚一层，不把后章提前讲完 |
| 小测验 | 题干 + 折叠要点 | 先答，再展开 |

## 学完本包的样子

合上资料，你能够：

- 把课本里的一个选择写成权衡，并把成本记在最佳替代上。
- 对「再多一单位」比较边际收益和边际成本，把平均数和已经收不回的花费留在比较外面。
- 看到一条价格或规则，说出行为会滑向哪一侧，包括条文没有点名的那一侧。
- 用自己的话说明：种粮的与养牛的为什么可以都比单干更好；价格在代替怎样的信息。
- 点出外部性、市场势力、信息不完全这三扇门，并把再分配放在门外面。
- 把原理 8–10 各停在一句边界上，并说出这三句背后的模型本次不建。

做到这些，第 1 章在本实验包里算走完一遍。宏观并没有因此会。摘要课的勾选也不因此完成。下一章原书是「像经济学家一样思考」，不在本目录。往后读哪些章节，见 [FURTHER_READING.md](FURTHER_READING.md)。

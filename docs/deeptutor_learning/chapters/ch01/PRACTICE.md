# 练习 · 第 1 章

[学习台](README.md) · [掌握路径](MASTERY_PATH.md) · [要点](ANSWER_KEY.md)

先做，再对。要点只写在答案页。选择和判断写出选项或对错；简答按自己的话写，对照答案页时看必答点是否都在。

题目只用课本情景。解锁顺序见掌握路径：认出的题可以在读完对应活页后做；讲清、用上、自核要等前一关过了再打开。

## 关卡 1 · 认出

<a id="p-r01"></a>

### P-R01

**选择 · 原理 1**

晚饭的预算只够再加一份。多买一盒冰淇淋，披萨就少一块。这一幕最直接在练哪一条？

- A. 原理 2：把隐成本加进账单
- B. 原理 1：人们面临权衡取舍
- C. 原理 6：价格在协调陌生人
- D. 原理 10：通胀与失业的短期权衡

<a id="p-r02"></a>

### P-R02

**判断 · 原理 1**

「枪炮与黄油」讲的就是效率与平等：国防是饼的大小，黄油是饼怎样切。

<a id="p-r03"></a>

### P-R03

**选择 · 原理 2**

对多数学生，上大学的成本里最大的一项通常是：

- A. 学费收据
- B. 不上学本可以挣到的工资
- C. 在校期间的全部食宿
- D. 所有没选的专业的学费之和

<a id="p-r04"></a>

### P-R04

**选择 · 原理 3**

一架 200 座的飞机飞越美国，成本 10 万美元，平均每座 500 美元。马上起飞，还有空位，候补乘客愿付 300 美元。决定卖不卖这一张时，主要比较：

- A. 300 美元和 500 美元
- B. 300 美元和多载这一位的花生、饮料
- C. 10 万美元和 300 美元
- D. 学费和放弃的工资

<a id="p-r05"></a>

### P-R05

**判断 · 原理 3**

水对人不可少，钻石不是必需，所以水的价格应当更高。

<a id="p-r06"></a>

### P-R06

**选择 · 原理 4**

安全带法律降低了一次事故中的伤亡。佩尔兹曼观察到事故次数上升、行人死亡上升。这是在说明：

- A. 原理 4：激励还有没被点名的一侧
- B. 原理 9：货币过多则物价上升
- C. 原理 7：再分配
- D. 原理 8：生活水平取决于生产率

<a id="p-r07"></a>

### P-R07

**选择 · 原理 5**

一个人种粮、一个人养牛，各专一侧再交换，双方可以比各自单干更好。这是：

- A. 原理 5
- B. 原理 7 的市场势力
- C. 原理 8
- D. 原理 3 的沉没成本

<a id="p-r08"></a>

### P-R08

**选择 · 原理 6**

冰淇淋涨价，想买的人少买一点，店家更愿意多做一点。双方不必开会清点全城还缺多少盒。这一幕在说明：

- A. 原理 6：看不见的手靠价格协调
- B. 原理 1：枪炮与黄油
- C. 原理 9：物价总体上升
- D. 原理 10：失业先下降

<a id="p-r09"></a>

### P-R09

**简答 · 原理 7 · 三扇门**

给下面三句各贴一个名字：外部性、市场势力、信息不完全。

1. 工厂把烟排给附近居民，居民的健康成本没有出现在工厂「再多生产一点」的账单上。
2. 镇上只有一口井，主人可以少供水、把价格定高。
3. 卖旧车的人清楚这辆车出过没有出过事故，买的人手里只有一个价格。

再答一句：所得税和福利把饼分得更匀，这是不是第四扇门？

<a id="p-r10"></a>

### P-R10

**简答 · 原理 8–10**

给下面三句各贴原理 8、9 或 10。

1. 1921 年 1 月一份德国报纸大约 0.30 马克，1922 年 11 月标价 7000 万马克，同期货币也增加得很快。
2. 各国生活水平的差别，几乎都可以归到一小时劳动能生产多少物品与劳务。
3. 大约一两年里，许多政策把通胀和失业推向相反方向。2008、2009 年的争论一方想压低失业，一方担心物价。

## 关卡 2 · 讲清

前一关过了再做。

<a id="p-e01"></a>

### P-E01

**简答 · 原理 1**

一位同学说：「既然多读一小时经济学就要少睡觉，社会就应当选效率、放弃平等。」这句话把哪些对子并错了？请分开写：学生这一小时在权衡什么；效率与平等在权衡什么。本章要不要宣布哪一边赢？

<a id="p-e02"></a>

### P-E02

**简答 · 原理 2**

上大学时：哪些是显成本？哪一项隐成本常常最大？食宿怎样取舍才进成本？为什么不能把「没做的所有事」加总？

<a id="p-e03"></a>

### P-E03

**简答 · 原理 3**

空位机票上，500 美元、10 万美元、花生和饮料，各回答什么问题？水和钻石的价格跟着哪一个量走？

<a id="p-e04"></a>

### P-E04

**简答 · 原理 4**

安全带改变了「开得慢一点」的哪一侧比较？人因此可能多做哪件法律没有点名的事？佩尔兹曼记下的事故次数、司机死亡、行人死亡，方向各是什么？汽油税让开车变贵之后，列出课本里至少三种去向。

<a id="p-e05"></a>

### P-E05

**简答 · 原理 5**

用种粮与养牛说明「更好」是和谁比。即使一方两件事都更快，为什么仍可能互利？互利是否保证平分？计算留在哪一章？

<a id="p-e06"></a>

### P-E06

**简答 · 原理 6**

看不见的手在第 1 章靠什么起作用？价格同时反映哪两样东西？房租被管制住、不许调整时，哪一步受阻？本章画不画供需图？

<a id="p-e07"></a>

### P-E07

**简答 · 原理 7**

用农民、餐馆、影视各一句说明产权。污染、一口井、旧车各漏了什么？为什么篮球运动员和国际象棋选手的收入差距不是第四扇失灵的门？

<a id="p-e08"></a>

### P-E08

**简答 · 原理 8–10**

三条各写两句：边界判断是什么；本章明确不做什么。原理八不要把主因主要记在哪三件事上，也写上。

## 关卡 3 · 用上

讲清过了再做。答案请标原理，并只用题里的课本情景。

<a id="p-a01"></a>

### P-A01

**简答 · 原理 2**

一位学生在「今年上大学」和「今年去工作」之间选。

1. 列出应计入的显成本。
2. 写出通常最大的隐成本。
3. 食宿里哪一截计入、哪一截剔除。
4. 若他的最佳替代其实不是工作，而是全职准备另一条他真会走的路，工资还算不算进成本？换成什么？

<a id="p-a02"></a>

### P-A02

**简答 · 原理 3**

沿用 200 座、10 万美元、平均 500 美元、空位、候补 300 美元、花生和饮料。

写出卖或不卖这一张的理由。分别说明 500 美元和 10 万美元为什么留在这个比较外面。给留在外面的那笔已经发生的成本一个名字。

<a id="p-a03"></a>

### P-A03

**简答 · 原理 4，并和原理 7 分开**

苹果涨价。买方怎样，果园怎样？这是价格作为激励，还是工厂排污那种外部性？用一句话把两件事分开。

<a id="p-a04"></a>

### P-A04

**简答 · 原理 1 与原理 4**

法律要求企业少排污。

1. 社会得到的一边是什么，放弃的一边可能出现在利润、工资、售价的哪里？
2. 这是枪炮与黄油，还是清洁环境与收入？
3. 本章要不要据此宣布「不该保护环境」？

<a id="p-a05"></a>

### P-A05

**简答 · 原理 5**

两个人若都自己种粮又自己养牛，和各专一侧再交换相比，原理五说双方可能怎样？「更适合」看什么？写出两件原理五不保证的事。写出本章不做的那项计算。

<a id="p-a06"></a>

### P-A06

**简答 · 原理 6 与原理 7**

用两句对照：

1. 冰淇淋价格若不许随供求上涨，看不见的手哪一步受阻？
2. 镇上唯一一口井的主人少供水、把价格定高，这叫什么，少掉的是什么？

两句都不要画图。

<a id="p-a07"></a>

### P-A07

**简答 · 原理 7**

1. 工厂排污：为什么「再多生产一点」的账单会把产量停错位置？这是效率理由还是平等理由？
2. 旧车买方按平均质量出价：好车为什么退出？这扇门本章要求你算完吗？

<a id="p-a08"></a>

### P-A08

**简答 · 原理 8–10**

下面三句只贴边界，不要展开模型。

1. 甲国工人每小时生产的物品与劳务远多于乙国，甲国大多数人的生活水平也更高。
2. 物价总体持续飞涨，货币数量以相近的速度增加。一份报纸从约 0.30 马克涨到 7000 万马克。
3. 有人主张马上压低通胀，有人提醒：短期里失业可能先上升。

每句写：原理编号、停在哪一句、本章不做的那一件。

## 关卡 4 · 自核

合上活页再写。

<a id="p-s01"></a>

### P-S01

**简答 · 十条**

凭记忆写出十条短标题，分成「人们如何做出决策」「人们如何相互影响」「整体经济如何运行」。给每一条标上：会用、直觉、认门，或只标边界。原理 7 请在标题旁边写出三扇门的名字。

<a id="p-s02"></a>

### P-S02

**简答 · 四句话**

合上表，用四句说完。一句可以稍长，但要盖住括弧里的点。

1. 决策四条怎样接成一条链（让步、最佳替代、再一单位、规则把比较推偏）。
2. 种粮养牛在做什么，冰淇淋价格在做什么。
3. 污染、一口井、旧车各漏了什么；再分配为什么不在这三格里。
4. 哪三条这次不建模型，各停在哪一句。

<a id="p-s03"></a>

### P-S03

**简答 · 原理 1–4 串在学生的一小时上**

课本情景：一位学生有一小时，可以读经济学，也可以读心理学、睡觉、骑车、看电视或打工。

请按顺序写四句：

1. 原理 1：稀缺的是什么；多读经济学，少掉的是哪一类东西。
2. 原理 2：成本记在哪里；为什么不能把其余用途全部加总。
3. 原理 3：若已经在读经济学，再多读 10 分钟，比的是哪两个增量；「已经读了很久」为什么不单独构成必须读完的理由。
4. 原理 4：若考试规则提高「读经济学」的收益，或打工工资提高，小时会滑向哪一侧。规则没点名的用途要不要看。

<a id="p-s04"></a>

### P-S04

**简答 · 本章碰到，还是不展开**

把下面八项分成两栏：「本章要碰到」和「本章不展开」。

1. 用枪炮与黄油说出多要一边、少另一边。
2. 画出供给曲线和需求曲线的交点。
3. 说出污染、一口井、旧车各属于哪扇门。
4. 计算两人的比较优势数值。
5. 说明德国报纸的物价飞涨在本章停在哪一句。
6. 画出通胀与失业的曲线并讨论斜率。
7. 判断 300 美元的候补票该不该卖，并说明 500 美元为什么不进比较。
8. 写出货币数量公式。

# 第 3 章术语表

[学习台](README.md) · [掌握路径](MASTERY_PATH.md)

每条只写本包里的用法。计算时先写清「每盎司牛肉」还是「每盎司土豆」，不要只写两个数字。

| 术语 | 在本章里的意思 | 活页 | 不要和它叠成一件事 |
|---|---|---|---|
| 相互依存 | 自己消费许多由他人生产的物品与服务，同时自己的生产也供他人使用。 | [01](book/01_production_possibilities.md) | 单方面受赠 |
| 生产可能性边界 | 时间和技术既定时，一个生产者能达到的物品组合。本章因固定转化率而是直线。 | [01](book/01_production_possibilities.md) | 贸易后的消费边界 |
| 自给自足 | 不交易，只消费自己生产的组合。 | [01](book/01_production_possibilities.md) | 一定更独立、更好 |
| 专业化 | 把更多时间用于自己机会成本较低的活动；本章 Frank 全种土豆，Ruby 主要生产牛肉。 | [02](book/02_specialization_and_trade.md) | 人人都只做自己有绝对优势的事 |
| 绝对优势 | 用比另一个生产者更少的投入生产某种物品的能力；时间是本章唯一投入。 | [03](book/03_absolute_and_comparative.md) | 机会成本更低 |
| 机会成本 | 为得到某种东西必须放弃的东西。Frank 每盎司牛肉放弃 4 盎司土豆，Ruby 放弃 2 盎司。 | [03](book/03_absolute_and_comparative.md) | 生产所花的分钟数本身 |
| 比较优势 | 以低于另一个生产者的机会成本生产某种物品的能力。 | [03](book/03_absolute_and_comparative.md) | 什么都做得更快 |
| 贸易收益 | 专业化和交换使双方能消费比无贸易时更多的物品；本章两人两种食物都增加。 | [04](book/04_gains_and_price.md) | 一方多得必然等于另一方少得 |
| 贸易价格 | 两种物品交换的比率。本章为每盎司牛肉 3 盎司土豆，等价于每盎司土豆 1/3 盎司牛肉。 | [04](book/04_gains_and_price.md) | 第 4 章由整个市场形成的货币价格 |
| 严格互利价格区间 | 每盎司牛肉的土豆价格严格处于 2 与 4 之间，双方买进的物品都比自己生产便宜。 | [04](book/04_gains_and_price.md) | 区间外也能让双方同时严格更好 |
| 进口品 | 在国外生产、在国内销售的物品。 | [05](book/05_applications.md) | 本国有比较优势的物品 |
| 出口品 | 在国内生产、在国外销售的物品。 | [05](book/05_applications.md) | 一定让所有国内生产者受益的物品 |

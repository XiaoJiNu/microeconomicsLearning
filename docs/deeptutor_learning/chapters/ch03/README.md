# 第 3 章学习台 · 相互依存性与贸易的好处

[返回自学包首页](../../README.md) · 上一章 [第 2 章](../ch02/README.md) · 下一章 [第 4 章](../ch04/README.md)

用本页当书桌。先看地图，再读活页、过四关。核心不是背「贸易好」，而是会用机会成本证明：为什么一个事事更强的人，仍然可以和另一个交易者互惠。

## 教材依据

曼昆《经济学原理》微观分册第 8 版，第 3 章「相互依存性与贸易的好处」。

| 原书的块 | 这一包怎么处理 |
|---|---|
| 一个现代经济寓言、生产可能性 | 用 Frank 与 Ruby 的 8 小时、牛肉和土豆画出两条直线边界 |
| 专业化与贸易 | 逐格核对生产、交换、消费，证明两人的消费都能越过自己的生产边界 |
| 绝对优势、机会成本、比较优势 | 分开「投入更少」与「放弃更少」，会算两组互为倒数的成本 |
| 比较优势与贸易、贸易的价格 | 算总产量增量；判断价格是否落在双方机会成本之间 |
| 两个应用与结论 | 用草坪和国家例子迁移；分开国家整体收益与国内分配影响 |

课本锚点：Ruby 每种物品都有绝对优势；Frank 在土豆上有比较优势；5 盎司牛肉换 15 盎司土豆；塞雷娜·威廉姆斯与 Forrest 修剪草坪；美国与日本生产食品和汽车。

## 先接上第 2 章

第 2 章的生产可能性边界凹向原点，资源在两种用途间并不同样适用，所以机会成本随组合改变。本章为了看清贸易，改用一个更简单的假设：每个人的时间以固定比率转成牛肉或土豆，因此两条边界都是直线，各自的机会成本不变。

这不是推翻上一章，而是换了一个适合本题的模型。贸易之后，消费可能性不再等于自己的生产可能性。

## 学完本包的样子

合上资料，你能够：

- 写出 Frank 的 8 盎司牛肉或 32 盎司土豆、Ruby 的 24 盎司牛肉或 48 盎司土豆，以及无贸易时的两个消费点。
- 逐格复原 5 盎司牛肉换 15 盎司土豆后的消费：Frank 为 5 与 17，Ruby 为 13 与 27。
- 算出 Frank 每盎司牛肉放弃 4 盎司土豆，Ruby 放弃 2 盎司；再说出土豆成本的倒数。
- 解释 Ruby 为什么可以有两种绝对优势，却不能在机会成本不同的情况下有两种比较优势。
- 判断每盎司牛肉价格为 1.5、3、4.5 盎司土豆时，哪一个能让双方都严格获益。
- 用草坪和美日例子选择专业化方向，并说明「国家整体可以更好」不等于「国内每个人都更好」。

做到这些，本章在本实验包里算走完一遍。供求曲线、弹性、关税福利分析并不因此学会；它们分别属于后续章节。

# 第 7 章 · 消费者、生产者与市场效率

## 1. 核心概念
- 支付意愿 (Willingness to Pay)：买者愿意支付的最高价格。
- 消费者剩余 (Consumer Surplus)：$CS = \text{支付意愿} - \text{实际价格}$。
- 生产者剩余 (Producer Surplus)：$PS = \text{实际价格} - \text{生产成本}$。
- 总剩余 (Total Surplus)：$CS + PS = \text{价值} - \text{成本}$。
- 市场效率：均衡价格能使总剩余最大化，此时资源配置有效。

- 需求曲线下、价格线上方的区域 = 消费者剩余。
- 供给曲线上方、价格线下方的区域 = 生产者剩余。

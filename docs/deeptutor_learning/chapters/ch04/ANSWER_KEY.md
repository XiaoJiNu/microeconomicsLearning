## 关卡 1 · 认出

### C4-R01

**答案：** A

**要点：** 物品相同与参与者众多使单个买卖者无法影响价格，双方因此是价格接受者。

### C4-R02

**答案：** 对

**要点：** 市场是买卖者群体，不要求固定场所。完全竞争中的个体把市场价格当作既定。

### C4-R03

**答案：** C

**要点：** 同一价格下水平相加：`4 + 3 = 7` 个。

### C4-R04

**答案：** A

**要点：** 固定纵轴价格，加横轴个人数量。不是加价格，也不是跨价格混加数量。

### C4-R05

**答案：** B

**要点：** 冷冻酸奶与冰淇淋是替代品。冷冻酸奶变便宜，买者转向它，使每种价格下冰淇淋需求减少，曲线左移。

### C4-R06

**答案：** 对

**要点：** 本物品价格从 4 升至 8 美元，引起沿同一需求曲线移动，需求量从 20 降至 12；曲线本身没有左移。

### C4-R07

**答案：** C

**要点：** 同一价格下水平相加：`3 + 4 = 7` 个。均衡时需求量与供给量都等于 7，不相加成 14。

### C4-R08

**答案：** C

**要点：** 糖是投入品，糖价下降降低成本，使每种冰淇淋价格下卖者都愿提供更多，供给曲线右移。

### C4-R09

**答案：** B

**要点：** 过剩 `10 - 4 = 6` 个。卖者库存积压并降价，直至 2 美元、7 个的均衡。

### C4-R10

**答案：** A

**要点：** 需求增加与供给减少都推高价格；对数量的作用相反，所以净数量取决于相对幅度。

## 关卡 2 · 讲清

### C4-E01

**必答点：**

- 冰淇淋买者与卖者彼此选择、相互影响，即使没有固定场所和拍卖者也构成市场。
- 完全竞争：物品完全相同；买卖者众多且单个不能影响价格。
- 小麦生产者和消费者众多、同等级产品同质，较接近模型；唯一有线电视卖者可能垄断，不能套用价格接受者假设。
- 完全竞争是简化，垄断与中间形态后章再分析。

### C4-E02

**必答点：**

- 需求量是愿意并且能够购买的数量；需求定理是在其他条件不变时价格与需求量反向变化；表和曲线分别是这一关系的表格与图形。
- 1.50 美元：`6 + 4 = 10`；2 美元：`4 + 3 = 7`；2.50 美元：`2 + 2 = 4`。
- 水平加总是在每个相同价格下加个人数量，不是加价格或跨行加数量。

### C4-E03

**必答点：**

- 五类：收入、相关物品价格、爱好、预期、买者数量。
- 收入下降时，正常物品冰淇淋需求左移；低档物品公共汽车需求右移。反向叙述收入增加也正确，只要方向一致。
- 替代品冷冻酸奶降价使冰淇淋需求左移，涨价则右移；互补品热软糖降价使冰淇淋需求右移，涨价则左移。
- 爱好变强右移；预期明天降价使今天需求左移；Peter 加入使市场需求右移。

### C4-E04

**必答点：**

- 警示改变偏好：每包 4 美元不变，数量 20→10，每种价格下需求减少，曲线左移。
- 税收抬高本物品价格：4→8 美元，数量 20→12，沿同一需求曲线移动，是需求量减少。
- 两幅图不能都画成曲线左移；价格对数量的反应幅度属于第 5 章弹性。

### C4-E05

**必答点：**

- 1.50 美元：`2 + 2 = 4`；2 美元：`3 + 4 = 7`；2.50 美元：`4 + 6 = 10`。
- 四类：投入品价格、技术、预期、卖者数量。
- 糖价下降使供给右移；机械化减少劳动、降低成本，使供给右移；预期未来涨价而储存使当前供给左移；卖者退出使市场供给左移。
- 冰淇淋本身价格变化只使供给量沿曲线变动。

### C4-E06

**必答点：**

- 均衡为 2 美元、7 个，因为 `Qd = Qs = 7`。
- 2.50 美元：`Qs = 10`、`Qd = 4`，过剩 6；降价使需求量增至 7、供给量减至 7。
- 1.50 美元：`Qd = 10`、`Qs = 4`，短缺 6；涨价使需求量减至 7、供给量增至 7。
- 变动来自纵轴价格，轴外条件未变，所以是沿两条固定曲线移动，不是曲线移动。

### C4-E07

**必答点：**

- 热天：需求右移；原 2 美元下短缺；价格升至 2.50，数量增至 10。供给曲线不动，只是供给量沿其增加。
- 糖价上升：供给左移；原 2 美元下短缺；价格升至 2.50，数量减至 4。需求曲线不动，只是需求量沿其减少。
- 两例都要写定曲线、定方向、比均衡三个步骤。

### C4-E08

**必答点：**

- 热天使需求右移、糖价上升使供给左移，两者都推高价格，所以价格确定上升；对数量作用相反，所以数量不确定。
- 需求与供给都增加时，两者都使数量增加，所以数量确定增加；价格一升一降，方向不确定。
- 价格配置谁购买、谁生产与生产多少；这不自动证明公平、人人满意或福利最大，福利与规范判断需另做。

## 关卡 3 · 用上

### C4-A01

**必答点：**

- 小麦有众多种植者和消费者，同等级产品较同质，单个难以影响价格，完全竞争是合理简化。
- 唯一有线电视公司可能具有垄断定价能力，不能假设卖者都是价格接受者。
- 假设要跟着问题走：研究竞争价格形成可放下单独定价能力，研究垄断定价时这一放下的因素正是核心，必须换模型。

### C4-A02

**必答点：**

- 1 美元：`8 + 5 = 13`；2.50 美元：`2 + 2 = 4`；3 美元：`0 + 1 = 1`。
- 第一处：市场加总是在同一价格下加数量，不是把个人支付价格相加。
- 第二处：2 美元时数量是 `4 + 3 = 7`，不是 4；所谓价格相加为 4 美元也不能直接变成市场需求量。

### C4-A03

**必答点：**

1. 冰淇淋需求左移。正常物品收入下降，每种价格下需求减少。
2. 公共汽车需求右移。低档物品收入下降，需求反而增加。
3. 冰淇淋需求右移。替代品冷冻酸奶涨价，买者转向冰淇淋。
4. 冰淇淋需求左移。互补品热软糖涨价，搭配消费减少。
5. 当前冰淇淋需求左移。买者等待明天更低价格。
6. 市场需求右移。每种价格下多了一位买者的需求量。
- 这些都是轴外因素变化，不是沿曲线移动。

### C4-A04

**必答点：**

- 警示：价格仍为 4 美元，数量 20→10；需求减少，需求曲线左移。
- 税收：价格 4→8 美元，数量 20→12；需求量减少，沿同一需求曲线移动。
- 把税收图也画成曲线左移，就误把纵轴上的本物品价格变化当成轴外因素变化，混淆了需求与需求量。

### C4-A05

**必答点：**

1. 糖价下降降低成本，当前供给增加，供给曲线右移。
2. 机械化减少劳动、降低成本，供给增加，供给曲线右移。
3. 储存以等待未来涨价，当前供给减少，供给曲线左移。
4. 本物品价格变化只使供给量沿同一供给曲线增加，市场供给量从 2 美元的 7 增至 2.50 美元的 10。

### C4-A06

**必答点：**

- 1 美元：`Qd = 13`、`Qs = 1`，短缺 12，价格上升。
- 1.50 美元：`Qd = 10`、`Qs = 4`，短缺 6，价格上升。
- 2.50 美元：`Qd = 4`、`Qs = 10`，过剩 6，价格下降。
- 3 美元：`Qd = 1`、`Qs = 13`，过剩 12，价格下降。
- 最终回到 2 美元、7 个；调整过程中两量沿各自曲线变化。

### C4-A07

**必答点：**

- 热天：需求曲线右移；原 2 美元下短缺、价格上升；新均衡 2.50 美元、10 个；供给曲线不动，供给量沿其从 7 增至 10。
- 糖价上升：供给曲线左移；原 2 美元下短缺、价格上升；新均衡 2.50 美元、4 个；需求曲线不动，需求量沿其从 7 减至 4。
- 两者都完整写出定曲线、定方向、比均衡，且没有把供给量或需求量变化误称为曲线移动。

### C4-A08

**必答点：**

1. 需求增加、供给增加：数量增加；价格不确定。两者都推升数量，对价格一升一降。
2. 需求增加、供给减少：价格上升；数量不确定。两者都推升价格，对数量一升一降。
3. 需求减少、供给增加：价格下降；数量不确定。两者都压低价格，对数量一降一升。
4. 需求减少、供给减少：数量减少；价格不确定。两者都压低数量，对价格一降一升。
- 「不确定」是净方向可增可减，取决于相对幅度；「不变」是数量或价格保持原值，两者不同。

## 关卡 4 · 自核

### C4-S01

**必答点：**

- 需求（Catherine + Nicholas = 市场）：1.50 美元 `6 + 4 = 10`，2 美元 `4 + 3 = 7`，2.50 美元 `2 + 2 = 4`。
- 供给（Ben + Jerry = 市场）：1.50 美元 `2 + 2 = 4`，2 美元 `3 + 4 = 7`，2.50 美元 `4 + 6 = 10`。
- 需求曲线向右下，供给曲线向右上；两者都在同一价格下水平加数量。
- 需求量／供给量是某一价格下的数量，需求／供给是整条关系或曲线。

### C4-S02

**必答点：**

- 正常物品收入增加需求右移；低档物品收入增加需求左移。
- 替代品涨价使本物品需求右移；互补品涨价使本物品需求左移。
- 爱好增强需求右移；预期明天降价使当前需求左移；买者增加使市场需求右移。
- 投入品涨价使供给左移；降低成本的技术使供给右移；预期未来涨价而储存使当前供给左移；卖者减少使市场供给左移。
- 香烟警示是需求左移；加税提价是沿曲线移动、需求量减少。

### C4-S03

**必答点：**

- 均衡 2 美元、7 个。2.50 美元供给 10、需求 4，过剩 6并降价；1.50 美元需求 10、供给 4，短缺 6并涨价。
- 热天：需求右移，新均衡 2.50、10，供给量沿原供给曲线增加。
- 糖价上升：供给左移，新均衡 2.50、4，需求量沿原需求曲线减少。
- 同时发生：需求右移、供给左移，价格上升，数量不确定，取决于相对幅度。

### C4-S04

**必答点：**

| 需求／供给 | 供给未变 | 供给增加 | 供给减少 |
|---|---|---|---|
| 需求未变 | 价格不变，数量不变 | 价格下降，数量增加 | 价格上升，数量减少 |
| 需求增加 | 价格上升，数量增加 | 价格不确定，数量增加 | 价格上升，数量不确定 |
| 需求减少 | 价格下降，数量减少 | 价格下降，数量不确定 | 价格不确定，数量减少 |

- 规则：分别比较两种移动对同一均衡量的作用；同向确定，反向取决于相对幅度。
- 未展开：第 5 章弹性；第 6 章价格管制与税收；第 7 章起的福利与公平评价。
- 本章已回答价格怎样协调买卖、生产与稀缺资源配置，但没有自动回答「应该怎样分配」。

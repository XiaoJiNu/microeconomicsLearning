# 第 4 章术语表

[学习台](README.md) · [掌握路径](MASTERY_PATH.md)

「需求／供给」指整条关系或曲线，「需求量／供给量」指某一价格下的数量。答题时先选对词。

| 术语 | 在本章里的意思 | 活页 | 不要和它叠成一件事 |
|---|---|---|---|
| 市场 | 某种物品或服务的买者与卖者组成的群体。 | [01](book/01_markets_competition.md) | 必须有固定交易场所 |
| 竞争市场 | 有许多买者与卖者，每个人对市场价格影响都微乎其微的市场。 | [01](book/01_markets_competition.md) | 任何有两家以上卖者的市场 |
| 完全竞争 | 物品完全相同，且买卖者众多、单个无法影响价格。 | [01](book/01_markets_competition.md) | 所有现实市场的完整描述 |
| 价格接受者 | 接受市场决定价格的买者或卖者。 | [01](book/01_markets_competition.md) | 垄断定价者 |
| 需求量 | 买者愿意并且能够购买的某种物品数量。 | [02](book/02_demand_curve.md) | 单纯想要，或整条需求曲线 |
| 需求定理 | 其他条件不变时，价格上升则需求量减少，价格下降则需求量增加。 | [02](book/02_demand_curve.md) | 任何因素都只会改变需求量 |
| 需求表 | 在其他因素不变时，表示价格与需求量关系的表格。 | [02](book/02_demand_curve.md) | 需求本身的价格 |
| 需求曲线 | 表示价格与需求量关系的图形，本章向右下方倾斜。 | [02](book/02_demand_curve.md) | 需求曲线的移动与沿曲线移动相同 |
| 市场需求 | 所有个人需求之和；每个价格下把个人需求量水平相加。 | [02](book/02_demand_curve.md) | 把个人价格相加 |
| 正常物品 | 其他条件相同时，收入增加引起需求增加的物品。 | [03](book/03_demand_shifts.md) | 品质较好或价格较高的物品 |
| 低档物品 | 其他条件相同时，收入增加引起需求减少的物品。 | [03](book/03_demand_shifts.md) | 质量差或人人都少买 |
| 替代品 | 一种物品价格上升引起另一种物品需求增加的两种物品。 | [03](book/03_demand_shifts.md) | 互补品 |
| 互补品 | 一种物品价格上升引起另一种物品需求减少的两种物品。 | [03](book/03_demand_shifts.md) | 替代品 |
| 需求增加／减少 | 在每一种既定价格下需求量都增加／减少，需求曲线右移／左移。 | [03](book/03_demand_shifts.md) | 仅因本物品价格变化而沿曲线走 |
| 供给量 | 卖者愿意并且能够出售的某种物品数量。 | [04](book/04_supply_curve.md) | 实际已经卖出的数量，或整条供给曲线 |
| 供给定理 | 其他条件不变时，价格上升则供给量增加，价格下降则供给量减少。 | [04](book/04_supply_curve.md) | 技术进步只是沿曲线移动 |
| 供给表 | 在其他因素不变时，表示价格与供给量关系的表格。 | [04](book/04_supply_curve.md) | 生产成本的完整账目 |
| 供给曲线 | 表示价格与供给量关系的图形，本章向右上方倾斜。 | [04](book/04_supply_curve.md) | 企业数量变化仍不移动 |
| 市场供给 | 所有卖者供给之和；每个价格下把个人供给量水平相加。 | [04](book/04_supply_curve.md) | 把个人价格相加 |
| 供给增加／减少 | 在每一种既定价格下供给量都增加／减少，供给曲线右移／左移。 | [05](book/05_supply_shifts.md) | 仅因本物品价格变化而沿曲线走 |
| 均衡 | 市场价格达到使供给量与需求量相等的状态。 | [06](book/06_equilibrium.md) | 人人都对分配满意 |
| 均衡价格 | 使需求量与供给量相等的价格，本章为 2 美元。 | [06](book/06_equilibrium.md) | 商家随意标价 |
| 均衡数量 | 均衡价格下的需求量与供给量，本章为 7 个。 | [06](book/06_equilibrium.md) | 需求量与供给量相加后的 14 |
| 过剩 | 现行价格下供给量大于需求量，也称超额供给。 | [06](book/06_equilibrium.md) | 短缺 |
| 短缺 | 现行价格下需求量大于供给量，也称超额需求。 | [06](book/06_equilibrium.md) | 任何价格上涨本身 |
| 供求定理 | 价格会调整，使物品的供给与需求趋向平衡。 | [06](book/06_equilibrium.md) | 所有市场瞬间达到均衡 |
| 曲线移动 | 轴外因素改变后，在每一既定价格下数量都改变。 | [07](book/07_three_steps.md) | 沿原曲线改变价格与数量 |
| 价格配置资源 | 价格作为信号，引导谁购买、谁生产以及生产多少。 | [08](book/08_price_allocation.md) | 自动证明公平或福利最大 |

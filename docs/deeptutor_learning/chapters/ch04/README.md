# 第 4 章学习台 · 供给与需求的市场力量

[返回自学包首页](../../README.md) · 上一章 [第 3 章](../ch03/README.md)

用本页当书桌。第 3 章只有两个人直接议价；本章进入许多买者与卖者共同形成价格的市场。学习目标不是背曲线方向，而是能从事件走到新均衡，并准确说出哪一条曲线移动、哪一个量沿曲线变化。

## 教材依据

曼昆《经济学原理》微观分册第 8 版，第 4 章「供给与需求的市场力量」。

| 原书的块 | 这一包怎么处理 |
|---|---|
| 市场与竞争 | 分清市场、竞争市场、完全竞争和价格接受者；垄断只标边界 |
| 需求表、需求曲线、市场需求 | 用 Catherine 与 Nicholas 的冰淇淋数据练水平加总 |
| 需求曲线移动 | 收入、相关物品价格、爱好、预期、买者数量；香烟案例专练两种变动 |
| 供给表、供给曲线、市场供给 | 用 Ben 与 Jerry 的数据练水平加总 |
| 供给曲线移动 | 投入品价格、技术、预期、卖者数量 |
| 均衡、过剩、短缺 | 会用 2 美元与 7 个，以及 2.5、1.5 美元下的调整机制 |
| 分析均衡变动的三个步骤 | 热天、糖价、两者同时发生；双移动时识别不确定项 |
| 价格如何配置资源 | 知道价格是信号与配置机制；公平与福利判断留到后章 |

课本锚点：冰淇淋、香烟、海滩土地与农业。弹性、价格管制、税收和福利分析不提前展开。

## 学完本包的样子

合上资料，你能够：

- 说出完全竞争的两个特征，以及为什么本章先采用这个模型。
- 从个人需求表或供给表得到市场表，并解释为什么在每个价格下水平加数量。
- 判断一个事件是沿曲线移动还是使曲线移动；不再把「需求」与「需求量」、「供给」与「供给量」混用。
- 用 2 美元、7 个的均衡，以及 2.5 美元和 1.5 美元的两个非均衡点，讲清价格调整。
- 对热天、糖价上升和两者同时发生，分别判断均衡价格与数量；知道双移动时哪个结果取决于相对幅度。
- 说明价格怎样配置海滩土地和农业劳动，同时不把它直接等同于公平或福利结论。

做到这些，本章在本实验包里算走完一遍。第 5 章的弹性、第 6 章的价格管制与税收、第 7 章的福利评价仍需单独学习。

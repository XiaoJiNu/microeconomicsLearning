# 第 5 章术语表

[学习台](README.md) · [掌握路径](MASTERY_PATH.md)

前六个词是原书末尾列出的「关键概念」，后几个是读图与做题必不可少的配套分类词。注意区分谁取正值、谁留正负号。

| 术语 | 在本章里的意思 | 活页 | 不要和它叠成一件事 |
|---|---|---|---|
| 弹性 | 衡量需求量或供给量对其某种决定因素的变动的反应程度的指标。 | [01](book/01_demand_elasticity_basics.md) | 变动方向本身，或曲线斜率 |
| 需求价格弹性 | 衡量一种物品需求量对其价格变动反应程度的指标，用需求量变动百分比除以价格变动百分比来计算（本书取正值）。 | [01](book/01_demand_elasticity_basics.md) | $\Delta Q / \Delta P$ 变动量直接相除 |
| 中点法 | 用变动量除以原先水平与最后水平的平均值来计算变动百分比和弹性的方法。 | [01](book/01_demand_elasticity_basics.md) | 以起点单边数值为基数的百分比算法 |
| 富有弹性 | 价格弹性大于 $1$，数量变动比例大于价格变动比例。 | [01](book/01_demand_elasticity_basics.md)、[02](book/02_demand_curves_and_revenue.md) | 水平线（完全有弹性只是极端特例） |
| 缺乏弹性 | 价格弹性小于 $1$，数量变动比例小于价格变动比例。 | [01](book/01_demand_elasticity_basics.md)、[02](book/02_demand_curves_and_revenue.md) | 需求量完全不变（只有弹性为 $0$ 才完全不变） |
| 单位弹性 | 价格弹性正好等于 $1$，数量与价格按相同比例变动；需求单位弹性时价格变动不改变总收益。 | [02](book/02_demand_curves_and_revenue.md) | 线性需求曲线整条都是单位弹性 |
| 完全无弹性 | 价格弹性等于 $0$，曲线为垂直线（像字母 I），价格无论怎样变动数量都不变。 | [02](book/02_demand_curves_and_revenue.md)、[04](book/04_supply_elasticity.md) | 水平线 |
| 完全有弹性 | 价格弹性趋近无穷大，曲线为水平线，价格极小变动就会引起数量极大变动。 | [02](book/02_demand_curves_and_revenue.md)、[04](book/04_supply_elasticity.md) | 垂直线 |
| 总收益 | 一种物品的买者支付从而卖者得到的量，用该物品的价格乘以销售量（$P \times Q$）来计算。 | [02](book/02_demand_curves_and_revenue.md) | 扣除生产成本后的企业利润（后章才讲） |
| 需求收入弹性 | 衡量一种物品需求量对消费者收入变动反应程度的指标，用需求量变动百分比除以收入变动百分比来计算。 | [03](book/03_other_demand_elasticities.md) | 可以去掉负号的弹性（正常 $>0$、低档 $<0$） |
| 需求的交叉价格弹性 | 衡量一种物品需求量对另一种物品价格变动反应程度的指标，用第一种物品的需求量变动百分比除以第二种物品的价格变动百分比来计算。 | [03](book/03_other_demand_elasticities.md) | 本物品自身的需求价格弹性（替代 $>0$、互补 $<0$） |
| 供给价格弹性 | 衡量一种物品供给量对其价格变动反应程度的指标，用供给量变动百分比除以价格变动百分比来计算。 | [04](book/04_supply_elasticity.md) | 在所有产量和所有时间长度下固定不变的常数 |

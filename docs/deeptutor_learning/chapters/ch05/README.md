# 第 5 章学习台 · 弹性及其应用

[返回自学包首页](../../README.md) · 上一章 [第 4 章](../ch04/README.md) · 下一章 [第 6 章](../ch06/README.md)

用本页当书桌。第 4 章回答事件使价格与数量「往哪个方向变」；本章引入**弹性**，继续回答「变化有多大」，以及价格变动后总收益（总支出）究竟增加还是减少。

## 教材依据

曼昆《经济学原理》微观分册第 8 版，第 5 章「弹性及其应用」。

| 原书的块 | 这一包怎么处理 |
|---|---|
| 需求价格弹性、决定因素与中点法 | 用汽油、黄油、看病与冰淇淋案例讲清四条经验法则，统一用中点法计算两点间弹性 |
| 各种需求曲线、总收益与线性需求曲线 | 对照图 5-1～5-4 与现实弹性参考表、线性需求表，练透 $P \times Q$ 增减规律及「斜率不变但弹性变」 |
| 其他需求弹性 | 用收入弹性区分正常物品（必需品／奢侈品）与低档物品，用交叉价格弹性区分替代品与互补品 |
| 供给价格弹性与各种供给曲线 | 对照牛奶算例、图 5-5 与图 5-6，讲清短长期供给弹性差异及产能上限对弹性的影响 |
| 供求与弹性的三个应用 | 对照图 5-7～5-9，完整推演堪萨斯小麦新品种、OPEC 油价兴衰与禁毒 vs. 禁毒教育 |
| 结论与全章收成 | 汇总全部 6 个原书公式与 9 幅原书图，衔接第 6 章的价格管制与税收归宿 |

课本锚点：汽油长短期反应、黄油与鸡蛋、看病与游艇、香草冰淇淋、$A(\$4, 120)$ 与 $B(\$6, 80)$、线性需求表（$\$0\text{–}\$7$）、牛奶供给、堪萨斯小麦杂交品种、OPEC 石油限产、非法毒品管制与教育。不提前引入微积分点弹性、边际收益公式或无谓损失面积。

1. 按 Book 从需求价格弹性读到三个应用与收成。每页先做小测验，再展开要点。

3. 练习在 [PRACTICE.md](PRACTICE.md)，答案要点只在 [ANSWER_KEY.md](ANSWER_KEY.md)。计算两点间弹性一律写中点法步骤。
4. 名词查 [术语表](GLOSSARY.md)，间隔复习用 [抽认卡](FLASHCARDS.md)，后章方向见 [进一步阅读](FURTHER_READING.md)。
5. 每页末的「费曼输出」留空处必须自己补；涉及总收益的应用题必须写清「谁移动、沿哪条线走、该线弹性如何」。

六页活页约 75–85 分钟；四关练习再留约一小时。前四章的勾选不抵本章。

## 学完本包的样子

合上资料，你能够：

- 用四条经验法则比较任意成对物品的需求价格弹性，并用中点法准确算出两点之间的弹性。
- 画出五种需求曲线和五种供给曲线，用面积 $A$ 与面积 $B$ 解释缺乏弹性与富有弹性下涨价对总收益的相反影响。
- 解释为什么向右下方倾斜的直线需求曲线斜率不变，弹性却在高价低量段大于 $1$、低价高量段小于 $1$。
- 根据需求收入弹性和交叉价格弹性的正负号，判断正常物品／低档物品、替代品／互补品。
- 说明为什么长期供给弹性大于短期，以及为什么接近最大产能时供给弹性变小。
- 独立复原小麦增产减收、OPEC 难守高油价、禁毒与禁毒教育三个应用的完整供求—弹性链条。

做到这些，本章在本实验包里算走完一遍。价格上限、价格下限与税收归宿在 [第 6 章](../ch06/README.md) 展开；消费者剩余、生产者剩余与无谓损失留待第 7–8 章。

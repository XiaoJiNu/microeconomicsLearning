## 最容易混的八对

1. 斜率是变动量之比（$\Delta P / \Delta Q$）；弹性是变动**百分比**之比。（[02](book/02_demand_curves_and_revenue.md)）
2. 向下倾斜的直线需求曲线斜率处处相同，但高价段富有弹性、低价段缺乏弹性。（[02](book/02_demand_curves_and_revenue.md)）
3. 普通百分比法换方向会变答案；中点法用均值作基数，两个方向答案相同。（[01](book/01_demand_elasticity_basics.md)）
4. 需求价格弹性按惯例取正值；需求收入弹性和交叉价格弹性必须保留正负号。（[03](book/03_other_demand_elasticities.md)）
5. 宽泛类别（食物）弹性小；狭窄类别（香草冰淇淋）场外替代品多，弹性大。（[01](book/01_demand_elasticity_basics.md)）
6. 缺乏弹性时涨价增加总收益；富有弹性时涨价反而减少总收益。（[02](book/02_demand_curves_and_revenue.md)）
7. 供给曲线移动时，均衡点沿着需求曲线走，总收益增减取决于**需求弹性**而非供给弹性。（[05](book/05_three_applications.md)）
8. 全球干旱使全球农民增收（全球粮食需求缺乏弹性），仅堪萨斯州干旱使当地农民减收（当地小麦有大量替代品，需求极富有弹性）。（[05](book/05_three_applications.md)）

# 第 6 章学习台 · 供给、需求与政府政策

[返回自学包首页](../../README.md) · 上一章 [第 5 章](../ch05/README.md)

用本页当书桌。前两章站在科学家视角看自由市场如何形成价格、弹性如何决定变化幅度；本章第一次转向政策分析，仅用供求与弹性工具检验两类最常见的政府政策——**价格控制**与**税收**——会带来哪些设计者常常始料未及的市场后果。

## 教材依据

曼昆《经济学原理》微观分册第 8 版，第 6 章「供给、需求与政府政策」。

| 原书的块 | 这一包怎么处理 |
|---|---|
| 价格上限及其市场结果 | 对照图 6-1～6-3，练非限制性与限制性上限、$1973$ 年加油站长队、短长期租金控制与非价格配给 |
| 价格下限与最低工资 | 对照图 6-4、图 6-5，练非限制性与限制性下限、青少年劳动市场失业效应与政策争论 |
| 对价格控制的评价 | 用十大原理对比价格控制与租金补贴、工资补贴（劳动收入税收减免），指明税收筹资代价 |
| 向卖者征税与向买者征税 | 对照图 6-6～6-8，用三步法证买者税与卖者税完全等同，讲透税收楔子与 FICA 工薪税 |
| 弹性与税收归宿 | 对照图 6-9，讲透「税负更多落在缺乏弹性的一方」，剖析工薪税真实归宿与 $1990$ 年游艇奢侈品税 |
| 结论与全章收成 | 横向对比上限、下限与税收对价量的影响，标清与第 7–8 章福利分析的边界 |

课本锚点：冰淇淋市场（$\$3, 100$ 个）、$1973$ 年汽油限价、城市租金控制、联邦最低工资（$\$7.25/\text{小时}$）、FICA 工薪税（$15.3\%$）、$1990\text{–}1993$ 年游艇奢侈品税。消费者剩余、生产者剩余与税收无谓损失留到第 7–8 章，不在本章提前展开。

1. 按 Book 从价格上限读到税收归宿与收成。每页先做小测验，再展开要点。

4. 名词查 [术语表](GLOSSARY.md)，间隔复习用 [抽认卡](FLASHCARDS.md)，后章方向见 [进一步阅读](FURTHER_READING.md)。

## 学完本包的样子

合上资料，你能够：

- 判断任一价格上限或价格下限是否具限制性，算出短缺或过剩量及实际成交量，并解释非价格配给为何低效。
- 用供求移动和短长期弹性解释 1973 年汽油长队、长期租金控制恶化以及最低工资对青少年的冲击，说出补贴为何优于直接限价。
- 按三步法分别推演向卖者征税和向买者征税（$\$3.00 \to \$3.30 / \$2.80$，$100 \to 90$），说明两者为何完全等同。
- 解释为什么国会立法规定「企业与工人各付一半工薪税」不能决定真实税负归宿。
- 对照图 6-9 说明为什么缺乏弹性的一方承担更多税负，并用它解释工薪税和 1990 年游艇奢侈品税的真实承担者。
- 横向分辨实施或取消价格上限、价格下限与税收时，买价、卖价、需求量与供给量的变化方向。

做到这些，本章在本实验包里算走完一遍。消费者剩余、生产者剩余与税收无谓损失将在原书第 7、8 章继续学习。

### C6-R03 要点

- **答案**：错误。

### C6-R07 要点

- **答案**：A（向这种物品的生产者征收每单位 $\$1$ 的税收）。

### C6-R08 要点

- **答案**：D（取消对生产者征税）。

## 第二组：讲清（`C6-E01` – `C6-E08`）

<a id="c6-e01"></a>
### C6-E01 要点

- **两种机制**：（1）**排长队**（把物品配给愿意提前到场耗费数小时等待的买者）；（2）**按卖者个人偏好配给**（卖给亲友、熟人或同一种族／民族成员，乃至收取暗中贿赂）。
- **无效率与不公平原因**：排队白白消耗了买者宝贵的时间成本，却没有转化为卖者收益；偏好配给不能保证稀缺物品落到对它评价最高的买者手中（无效率），还会滋生裙带关系与种族／家庭歧视（不公平）。

[回题干](PRACTICE.md#c6-e01)

---

<a id="c6-e02"></a>
### C6-E02 要点

- **OPEC 提价之前**（图 6-2a）：汽油均衡价格 $P_1$ 低于法定价格上限，价格上限是非限制性的，没有引起排队。
- **OPEC 提高原油价格**（图 6-2b）：提高了炼油投入品成本，使汽油供给曲线从 $S_1$ 左移至 $S_2$，推动无管制均衡价格升至 $P_2$（高于上限）。
- **责任划分**：OPEC 提价是推动均衡油价上涨的原因；但在自由市场中油价升至 $P_2$ 就会自动消除短缺。真正阻止价格调整、把涨价压力变成持续汽油短缺（$Q_D - Q_S$）和加油站长队的，是此时变为限制性的**汽油价格上限法**。

[回题干](PRACTICE.md#c6-e02)

<a id="c6-e03"></a>
### C6-E03 要点

1. **数量上（短长期弹性差异）**：短期住房存量固定、租客调整慢，供求均缺乏弹性，短缺较小（图 6-3a）；长期低租金削弱开发商建新公寓的激励，同时吸引更多年轻人分户独居和外地人迁入，长期供求均富有弹性，造成巨大房荒（图 6-3b）。
2. **质量与配给上（对激励的反应）**：自由市场里维护良好的公寓能租出高价；受控市场长期供不应求，房东不修缮也不愁租不出去，花钱维护无法转化为更高租金回报，导致出租屋普遍年久失修、环境恶化，并滋生等待名单、家庭或种族筛选及暗盘茶水费。

[回题干](PRACTICE.md#c6-e03)

---

<a id="c6-e04"></a>
### C6-E04 要点

- **反对价格控制的原因**：价格是协调千百万企业与消费者决策的关键信号（原理六）。租金控制和最低工资强行扭曲价格信号，人为压低住房供给量或低技能劳动需求量，造成房荒、房屋降质和低技能青年失业，往往伤害了原本想帮助的群体。
- **赞成补贴替代的原因**：租金补贴和工资补贴（如劳动收入税收减免）直接补助低收入者而不压低房东实得租金、不抬高企业用工成本，保留了市场价格信号，不会制造住房短缺或失业。
- **不可回避的缺陷**：补贴需要花费政府财政资金，政府必须通过提高**税收**来筹资，而税收本身也会抑制市场活动并带来效率代价。

[回题干](PRACTICE.md#c6-e04)

<a id="c6-e05"></a>
### C6-E05 要点

- **表面差异**：向卖者征 $\$0.50$ 税使供给曲线向上平移 $\$0.50$（图 6-6），市场标价升至 $\$3.30$，卖者交完 $\$0.50$ 税后净得 $\$2.80$；向买者征 $\$0.50$ 税使需求曲线向下平移 $\$0.50$（图 6-7），市场标价降至 $\$2.80$，买者另交 $\$0.50$ 税后总计支付 $\$3.30$。
- **实质等同**：两种情况下，成交量都从 $100$ 减为 $90$，买者含税总支出都是 $\$3.30$（多付 $\$0.30$），卖者税后净得都是 $\$2.80$（少得 $\$0.20$）。无论税款先经过谁的手放进政府的「收税碗」，税收都是在买价与卖价之间打入同一个 $\$0.50$ 的税收楔子。

[回题干](PRACTICE.md#c6-e05)

<a id="c6-e06"></a>
### C6-E06 要点

- 工薪税是打入「企业支付的总用工成本」与「工人到手净工资」之间的一个税收楔子（图 6-8）。
- 一旦打入该楔子，市场工资会自动调整以重新平衡劳动供求：无论法律规定全部向企业收、全部向工人收还是五五对半收，企业总用工成本、工人税后净工资与均衡就业量都完全相同。真实分摊比例只取决于劳动供给与劳动需求的相对弹性，不受法律条文支配。

[回题干](PRACTICE.md#c6-e06)

<a id="c6-e07"></a>
### C6-E07 要点

- 弹性衡量买者或卖者在市场条件变差时**离开市场的意愿与替代能力**。
- 富有弹性的一方拥有充足的替代品或替代转产渠道，一旦税后价格对自己不利就大幅削减购买或撤出供给；缺乏弹性的一方缺少良好替代选择，无法轻易离开市场，只能留在场内承受更大幅度的不利价格变动（图 6-9），从而吃下大部分税收负担。

[回题干](PRACTICE.md#c6-e07)

<a id="c6-e08"></a>
### C6-E08 要点

- 国会原以为游艇是富人消费品，征税会由富人买单；但富人可轻易改买豪宅、出国度假或留作遗产，**游艇需求非常富有弹性**。
- 相反，游艇制造厂与熟练造船工人短期难以转产改行，**游艇供给较为缺乏弹性**。
- 按图 6-9（b），税负主要落在缺乏弹性的游艇生产企业和工人身上，导致游艇销量锐减、船厂裁员、中产工人受损且政府也没收到多少税，国会遂于 1993 年废除大部分奢侈品税。

## 第三组：用上（`C6-A01` – `C6-A08`）

<a id="c6-a01"></a>
### C6-A01 要点

- **若自由市场均衡票价 $\le \$40$**：$\$40$ 价格上限是**非限制性的**，票价和听音乐会的人数**不变**。
- **若自由市场均衡票价 $> \$40$**：$\$40$ 价格上限是**限制性的**，压低票价虽使想买票的需求量增加，却使乐团与剧院愿意提供的演出场次和门票供给量减少；实际入场人数等于较小的供给量，因此听上古典音乐会的人反而**变少了**。

[回题干](PRACTICE.md#c6-a01)

---

<a id="c6-a02"></a>
### C6-A02 要点

- **可能发生**，条件是**消费者对奶酪的需求富有弹性（需求价格弹性 $> 1$）**。
- **解释**：限制性价格下限把奶酪价格抬高到均衡以上，虽然产出的供给量增加了，但卖不掉的过剩奶酪无法形成销售收入，市场实际成交量受限于买者的**需求量**。当奶酪需求富有弹性时，价格上升引起实际购买量（需求量）减少的百分比大于价格上升的百分比，导致奶酪生产者整体的实际总销售收益 $P \times Q_D$ 反而下降。

[回题干](PRACTICE.md#c6-a02)

---

<a id="c6-a03"></a>
### C6-A03 要点

1. **无管制自由市场**：查表知价格为 $\$8$ 时需求量 $=$ 供给量 $= 6$（百万个），故均衡价格为 **$\$8$**，均衡数量为 **$600$ 万个**（$6$ 百万个）。
2. **比均衡高 $\$2$ 的价格下限（即 $\$10$）**：$\$10 > \$8$，价格下限**具有限制性**。新市场价格为 **$\$10$**；此时供给量 $12$ 百万个、需求量 $2$ 百万个，实际只能卖出 **$200$ 万个**（等于需求量），出现 **$12 - 2 = 10$（百万个）即 $1000$ 万个过剩**。
3. **废除下限并改为比原下限（$\$10$）低 $\$1$ 的价格上限（即 $\$9$）**：由于价格上限 $\$9$ **高于**自由均衡价格 $\$8$，该价格上限是**非限制性的**！市场自动回到自由均衡：新市场价格为 **$\$8$**，实际卖出 **$600$ 万个**飞盘。

[回题干](PRACTICE.md#c6-a03)

---

<a id="c6-a04"></a>
### C6-A04 要点

1. **向买啤酒者每箱征 $\$2$ 税**：需求曲线向下平移 $\$2$（供给曲线不变）。新均衡下啤酒**销售量减少**；卖者得到的价格**下降**（降幅小于 $\$2$）；买者含税支付的有效总价格**上升**（涨幅小于 $\$2$），两者之差正好等于 $\$2$。
2. **提高限制性最低工资的弹性分析**：
   - **就业变动**：限制性最低工资下企业雇人数量等于**劳动需求量**，因此就业减少多少**只取决于劳动需求弹性**（与劳动供给弹性无关）；
   - **失业变动**：失业量等于劳动供给量减去劳动需求量（$Q_S - Q_D$），工资上升既减少企业雇用量又吸引更多求职者进入市场，因此失业增加多少**同时取决于劳动需求弹性和劳动供给弹性**。

[回题干](PRACTICE.md#c6-a04)

<a id="c6-a05"></a>
### C6-A05 要点

1. **买者向卖者支付的市场价格**：**上升**，且上升幅度正好等于单位税额 $\$t$（因为原先买者把税交给政府，现在改由买者连同货款一并交给卖者，再由卖者转交政府）。
2. **买者含税支付的总金额**：**不变**（买者税与卖者税完全等同）。
3. **卖者扣税后实际得到的净金额**：**不变**。
4. **市场销售的数量**：**不变**。

<a id="c6-a07"></a>
### C6-A07 要点

1. **豪华轿车 $\$500$ 税**：消费者含税买价上涨幅度**小于 $\$500$**。只要供给不是完全富有弹性且需求不是完全无弹性，$\$500$ 税收楔子就由买者涨价和卖者降价共同分担；况且豪华车需求很富有弹性而短期供给相对缺乏弹性，生产者会承担更大头，消费者买价涨幅远小于 $\$500$。
2. **每加仑 $\$0.50$ 汽油税**：
   - **减少汽油消费与污染**：在汽油需求**富有弹性**时（如长期）更为有效，因为同样 $\$0.50$ 楔子在平坦需求曲线上引起更大数量缩减；
   - **筹集稳定税收且少减少消费**：在汽油需求**缺乏弹性**时（如短期）筹资能力更强，此时消费量缩减很少，买者承担大部分税负。

[回题干](PRACTICE.md#c6-a07)

<a id="c6-a08"></a>
### C6-A08 要点

- **能否增加政府税收收入**：能（只要企业增税幅度大于工人减税幅度，且市场交易未完全萎缩殆尽，单位劳动总工薪税提高了）。
- **能否使工人状况变好**：**绝对不能，反而会使工人状况变差！** 工薪税归宿与向企业收还是向工人收毫无关系，只看总工薪税楔子的大小。该提案既然净增加了总工薪税，打入用工成本与到手工资之间的总楔子就变宽了：均衡就业量下降，工人实际税后到手净工资也必然下降（而且由于劳动供给比劳动需求更缺乏弹性，新增税负的大头恰恰由工人承担）。

[回题干](PRACTICE.md#c6-a08)

## 第四组：自核（`C6-S01` – `C6-S04`）

<a id="c6-s01"></a>
### C6-S01 要点

1. **无干预均衡**：令 $2P = 300 - P \Rightarrow 3P = 300 \Rightarrow P_0 = \$100$，代入得 $Q_0 = 200$。
2. **$\$90$ 价格上限**：$\$90 < \$100$，**具有限制性**。在 $P = \$90$ 下，$Q^S = 2 \times 90 = 180$，$Q^D = 300 - 90 = 210$。出现**短缺**，短缺量为 $210 - 180 = 30$，实际成交量为 **$180$**。
3. **$\$90$ 价格下限**：$\$90 < \$100$，低于均衡价格，属于**非限制性价格下限**，对市场无影响，价格仍为 **$\$100$**，成交量仍为 **$200$**，无短缺也无过剩。
4. **向生产者每单位征 $\$30$ 税**：
   - 设 $P$ 为买者支付的市场价格，则生产者每单位实得 $P - 30$，新供给方程为 $Q^S = 2(P - 30) = 2P - 60$；
   - 联立 $2P - 60 = 300 - P \Rightarrow 3P = 360 \Rightarrow$ **买者支付价格 $P_B = \$120$**；
   - **卖者税后实得价格 $P_S = \$120 - \$30 = \$90$**；
   - **市场成交量** $Q_1 = 300 - 120 = 180$（且 $Q^S = 2 \times 90 = 180$，供求相等，**既无短缺也无过剩**）；
   - **税负分摊**：买者每单位多付 $\$120 - \$100 = \$20$，卖者每单位少得 $\$100 - \$90 = \$10$（买者承担 $2/3$，卖者承担 $1/3$，因为在该均衡附近需求比供给更缺乏弹性）。

### C6-S02 要点

- **租金上限方案（甲）**：短期供求缺乏弹性，主要压低已租房客租金、仅造成小幅短缺；长期供求富有弹性，开发商停建新房、房东停止修缮，造成严重房荒与居住质量退化，并诱发排长队、偏爱无孩家庭、种族歧视与暗中贿赂等不公配给。无直接财政支出，但隐性社会代价极高（$95\%$ 受访经济学家否定其积极效果）。
- **租金补贴方案（乙）**：保留市场租金信号，房东按市场价获得回报从而维持建房与修缮激励，不会产生住房短缺或房屋失修，也能精准对准经收入核查的困难家庭；代价是需要市政财政支出，必须通过征税筹集资金。

### C6-S03 要点

1. **提议甲（大幅提高最低工资）**：提高保住岗位工人的工资，但作为限制性价格下限会减少企业对低技能工人（尤以青少年为甚）的劳动需求量、诱发退学与失业，且瞄准度偏低（不到 $1/3$ 领取者处于贫困线以下家庭）。
2. **提议乙（减工人工薪税、等额加企业工薪税）**：**完全无效**。总工薪税楔子大小未变，买卖（劳资）征税完全等同，市场工资会自动上调抵消名义转移，工人到手净工资与就业量毫发无变。
3. **提议丙（扩大劳动收入税收减免／工资补贴）**：按家庭与劳动收入精准补贴低薪工人，不抬高企业用工成本、不制造失业；代价是减少政府净财政收入，需由其他税收弥补。

### C6-S04 要点

1. **三章框架**：第 4 章用供求曲线确立竞争市场价格与数量变动**方向**，第 5 章用弹性定量刻画变动**幅度**与总收益后果，第 6 章把供求与弹性合流用于检验政府**价格控制与税收政策**的实证后果。
2. **留给第 7–8 章的福利问题**：第 6 章算出了价量变化、短缺过剩和买卖双方税负分摊，但尚未引入**消费者剩余、生产者剩余与总剩余**来度量自由市场为何通常是有效率的（第 7 章），也尚未度量税收缩小市场规模所造成的**无谓损失（deadweight loss）**究竟有多大、如何随供求弹性变化（第 8 章）。

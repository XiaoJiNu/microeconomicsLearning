## 教材依据

曼昆《经济学原理》微观分册第 8 版，第 2 章「像经济学家一样思考」。

经济学家有两种角色。解释世界如何运行时，他是科学家。主张怎样改善结果时，他是政策顾问。

| 原书的块 | 这一包怎么处理 |
|---|---|
| 科学方法、假设、模型 | 练到能判断一个假设会不会改答案 |
| 循环流量图 | 会读两个市场、两圈方向，以及图里故意没有的部分 |
| 生产可能性边界 | 用汽车和电脑区分有效、无效率、不可达，并分开沿边界走与边界外移 |
| 微观与宏观 | 只分领域，不建宏观模型 |
| 实证与规范，以及建议为何不被采纳 | 会把句子分类，并知道建议不是最后一道决定 |
| 意见分歧；附录里的原因和结果 | 分开科学判断和价值观；相关还不等于因果 |

课本例子：大理石与沙滩球，中东战争与油价，塑料人体，一杯咖啡的钞票，汽车与电脑，纽约的租金控制，美国汽车业，义务教育与收入，联邦借债与失业率，Portia 与 Noah 的最低工资，杜鲁门的「另一方面」，收入税与消费税，Peter 与 Paula 的水井税，租金上限与关税，打火机与癌症，警察与犯罪，家用旅行车与婴儿。

作图附录不单开一页。读图在循环流量图和生产可能性边界里练。斜率只用汽车和电脑算一次。Emma 买小说的需求曲线留到第 4 章。

每一页用同一种块。在 GitHub 上它们会显示成提示条；换成纯文本阅读器时，仍是带标签的引用。

## 学完本包的样子

合上资料，你能够：

- 用大理石和沙滩球说清：不真实的假设何时仍可用。
- 讲清循环流量图里谁在哪个市场买卖，两圈为什么方向相反，图中没有政府和国际贸易。
- 指出汽车与电脑的有效点、无效率点和边界外为什么做不到；从 600 辆、2200 台走到 700 辆、2000 台，说出一辆汽车的机会成本；再说出电脑技术进步时边界怎样动。
- 用租金控制和失业率各标微观或宏观，并让减税对总生产的影响落到家庭的决定上。
- 把 Portia 和 Noah 的两句分成实证和规范。
- 用储蓄反应和水井税分开两类分歧；用打火机和家用旅行车各说出一种因果错误。

做到这些，第 2 章在本实验包里算走完一遍。比较优势的计算、供需图和宏观模型并没有因此会。摘要课的勾选也不因此完成。往后读哪些章节，见 [FURTHER_READING.md](FURTHER_READING.md)。

## 关卡 1 · 认出

**先读：** [01](book/01_scientist.md) [02](book/02_circular_flow.md) [03](book/03_ppf.md) [04](book/04_micro_macro.md) [05](book/05_positive_normative.md) [06](book/06_disagreement.md)

**过关的样子**

- 沙滩球不能沿用大理石的「没有摩擦」。经济学家不能为了检验通胀去改一国的货币。
- 生产要素市场上，企业买、家庭卖。基本的循环流量图没有政府和国际贸易。
- 300 辆汽车和 1000 台电脑在边界内。从 600 与 2200 到 700 与 2000，每辆汽车两台电脑。
- 租金控制是微观，失业率随时间变动是宏观。
- Noah 的「应该提高最低工资」是规范。
- 打火机与癌症是忽略的变量。旅行车与婴儿是方向或预期，不是车带来了人。

**做这些题：** [C2-R01](PRACTICE.md#c2-r01) 至 [C2-R10](PRACTICE.md#c2-r10)

**怎样算过：** 十题的选择或判断与要点一致。

**过关后解锁：** 关卡 2，以及练习里的 C2-E01 至 C2-E08。没过的主题只重读对应的一页。

## 关卡 2 · 讲清

**过关的样子：** 能用自己的话把机制讲完，而不是只报名词。

- 假设何时仍可用：大理石、沙滩球，以及短期价格大体不动、长期价格都能调整。其他条件不变是在固定其余因素。
- 循环流量图的两圈方向相反；一杯咖啡的钱怎样回到钱包；政府和国际贸易为什么先不画。
- 边界上、以内、以外各是什么。机会成本为什么不是常数。沿边界走和电脑技术使边界外移，数字上差在哪里。
- 微观和宏观各举课本例子。减税对总生产的影响要经过家庭的购买。
- Portia 和 Noah 怎样分。数据为什么判不完「应该」。建议为什么常常停在采纳之前。
- 储蓄反应是科学判断，水井税的 10% 与 20% 是价值观。打火机和旅行车各是哪一种因果错误。

**做这些题：** [C2-E01](PRACTICE.md#c2-e01) 至 [C2-E08](PRACTICE.md#c2-e08)

**怎样算过：** 每题的必答点都说到。

**过关后解锁：** 关卡 3，以及 C2-A01 至 C2-A08。

## 关卡 4 · 自核

合上活页和答案，再打开练习的最后四题。

**过关的样子**

- 凭记忆说出两种角色，以及模型为什么可以不真实。
- 不看图，讲清循环流量图的两个市场，并报出汽车与电脑的那几个关键数字。
- 把混在一起的句子分成实证或规范、微观或宏观。
- 能把「本章要碰到」和「本章不展开」分开，包括 Emma 的需求曲线、比较优势计算、货币公式。

## 最容易混的八对

讲清和自核之前，用自己的话各说一句。说错了就回到括弧里的页。

1. 大理石可以忽略空气，沙滩球不行。（[01](book/01_scientist.md)）
2. 家庭在要素市场上是卖者。（[02](book/02_circular_flow.md)）
3. 300 辆与 1000 台在边界内，两种都可以更多。（[03](book/03_ppf.md)）
4. 沿边界走到 700 与 2000，不等于电脑技术变好。（[03](book/03_ppf.md)）
5. 汽车行业的外国竞争是微观，失业率随时间变动是宏观。（[04](book/04_micro_macro.md)）
6. 「引起失业」和「应该提高」不是同一种句子。（[05](book/05_positive_normative.md)）
7. 储蓄反应的大小，和水井税谁交得太多，不是同一类分歧。（[06](book/06_disagreement.md)）
8. 一起变动之后，还要问漏掉的变量和方向。（[06](book/06_disagreement.md)）

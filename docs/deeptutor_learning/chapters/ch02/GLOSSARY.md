# 第 2 章术语表

[学习台](README.md) · [掌握路径](MASTERY_PATH.md)

每条只写本包里的用法。循环流量图有时也被叫做循环流向图。本包按这一章的图来称呼，用循环流量图。

| 术语 | 在本章里的意思 | 活页 | 不要和它叠成一件事 |
|---|---|---|---|
| 科学方法 | 提出关于世界如何运行的理论，再用观察和数据去支持或怀疑它。 | [01](book/01_scientist.md) | 必须有实验室 |
| 自然实验 | 历史已经发生、不能为了研究去操纵的事件。课本锚点是战争打断原油运输后的油价。 | [01](book/01_scientist.md) | 扔下大理石 |
| 假设 | 为了把问题简化而暂时采用的前提。它不必完全真实。若它会改变这一问的答案，就不适用于这个新问题。 | [01](book/01_scientist.md) | 「凡是不真实的都禁用」 |
| 其他条件不变 | 看一个因素时，先把其余相关因素当成不动。看小说价格时先固定收入。 | [01](book/01_scientist.md) | 已经证明了因果 |
| 经济模型 | 为了看清所问的问题而简化现实的图形或方程。塑料人体留下主要器官，不画每一条毛细血管。 | [01](book/01_scientist.md) | 完整现实 |
| 循环流量图 | 货币如何通过市场在家庭与企业之间流动的简图。内圈是投入与产出，外圈是货币，方向相反。 | [02](book/02_circular_flow.md) | 已经画进政府的总图 |
| 家庭 | 拥有生产要素并购买物品与服务的决策者。企业所有者也算在家庭里。 | [02](book/02_circular_flow.md) | 在两个市场上都是买者 |
| 企业 | 使用生产要素生产物品与服务并出售的决策者。 | [02](book/02_circular_flow.md) | 在两个市场上都是卖者 |
| 生产要素 | 劳动、土地，以及建筑物和机器等资本。 | [02](book/02_circular_flow.md) | 物品与服务本身 |
| 物品与服务市场 | 家庭买、企业卖。 | [02](book/02_circular_flow.md) | 生产要素市场 |
| 生产要素市场 | 家庭卖、企业买。 | [02](book/02_circular_flow.md) | 物品与服务市场 |
| 生产可能性边界 | 技术和要素既定时，两种产品能够达到的各种组合。本章是汽车和电脑。 | [03](book/03_ppf.md) | 某一个国家的需求曲线 |
| 有效率（在边界上） | 不减少一种产品，就无法再增加另一种。 | [03](book/03_ppf.md) | 边界内的点 |
| 无效率（在边界内） | 产量小于资源所允许的。课本的点是 300 辆汽车和 1000 台电脑。 | [03](book/03_ppf.md) | 做不到的边界外 |
| 机会成本（边界的斜率） | 为了多得到一种产品而放弃的另一种。从 600 与 2200 到 700 与 2000，每辆汽车是两台电脑。 | [03](book/03_ppf.md) | 常数，与产量无关 |
| 边界外移 | 资源增加或技术变好之后，原先的权衡整体向外。电脑技术变好时，汽车一端仍可以是 1000 辆。 | [03](book/03_ppf.md) | 沿旧边界改组合 |
| 微观经济学 | 家庭和企业如何做决定，以及他们如何在特定市场上交易。 | [04](book/04_micro_macro.md) | 失业率随时间的路径 |
| 宏观经济学 | 整体现象，包括通胀、失业和经济增长。 | [04](book/04_micro_macro.md) | 不必再问家庭的决定 |
| 实证表述 | 描述世界是什么样。原则上可以用证据去对。课本句是「最低工资法引起了失业」。 | [05](book/05_positive_normative.md) | 带「应该」的目标排序 |
| 规范表述 | 规定世界应该是什么样。课本句是「政府应该提高最低工资」。 | [05](book/05_positive_normative.md) | 单靠数据能判完 |
| 科学判断的分歧 | 对哪一种实证理论正确，或对某个参数有多大，看法不同。课本参数是储蓄对税收激励的反应。 | [06](book/06_disagreement.md) | 谁的税更不公平 |
| 价值观的分歧 | 对政策应当追求什么看法不同。水井税的 10% 和 20% 谁交得太多，科学回答不完。 | [06](book/06_disagreement.md) | 参数还没测准 |
| 相关 | 两个变量一起变动。图上的一起变动本身不是因果。 | [06](book/06_disagreement.md) | 已经找到原因 |
| 忽略的变量 | 图上没画、却能解释一起变动的第三个因素。打火机与癌症之间是吸烟。 | [06](book/06_disagreement.md) | 反向因果 |
| 反向因果关系 | 把方向看反了。危险的城市雇用更多警察。旅行车不带来婴儿。 | [06](book/06_disagreement.md) | 忽略的变量 |

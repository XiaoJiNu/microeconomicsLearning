## 关卡 2 · 讲清

### C2-E01

**必答点：**

- 大理石可以忽略摩擦。沙滩球不可以。
- 短期常假设价格变动不大甚至不动。长期常假设价格都能调整。会改答案的假设要换。
- 看小说价格时先把收入等其余因素当成不动，免得购买量混进别的原因。

### C2-E02

**必答点：**

- 物品与服务市场：家庭买，企业卖。生产要素市场：企业买，家庭卖。
- 钞票买咖啡成为企业收益，再付工资或房租，回到一只钱包。
- 实物和货币方向相反。
- 故意没画政府和国际贸易。

### C2-E03

**必答点：**

- 边界上有效：不减少一种就不能增加另一种。边界内无效率，两种都可以更多。边界外现有技术和要素做不到。
- 每辆汽车两台电脑。
- 边界凹向原点。资源不是同样适合两种生产，所以机会成本随已经生产多少而变。

### C2-E04

**必答点：**

- 完全不生产电脑时，电脑技术用不上，汽车一端仍是 1000 辆。
- 沿边界走是在旧边界上一种多、另一种少，例如到 700 与 2000。
- 外移之后两种都可以比旧点更多，例如 650 与 2300。

### C2-E05

**必答点：**

- 微观例子至少一种：租金控制与纽约住房，外国竞争与美国汽车业，或义务教育与工人收入。
- 宏观例子至少一种：联邦借债，失业率随时间变动，或提高生活水平的政策。
- 减税对总生产的影响，要看家庭把多少钱改用于购买。
- 这一章不建失业或增长模型。

### C2-E06

**必答点：**

- Portia「引起了失业」是实证。Noah「应该提高」是规范。
- 数据可以评价前一句。后一句还要价值判断。
- 「另一方面」来自权衡：效率与平等，或这一代与后代。
- 采纳之前还有向公众解释、媒体、议会修改、哪些集团支持或反对。说到其中两处即可。

### C2-E07

**必答点：**

- 卡在家庭储蓄对税收激励的反应有多大。
- 10% 和 20% 已经算出来了。谁交得太多取决于公平的标准，科学回答不完。

### C2-E08

**必答点：**

- 打火机是忽略的变量，漏了吸烟。
- 警察与犯罪的图分不清方向。更说得通的是危险的城市多雇警察，也可能是预期犯罪上升而先雇人。
- 旅行车在孩子之前，是预期有孩子才买车，不是车带来了人。

## 关卡 3 · 用上

### C2-A01

**必答点：**

- 「今后几个月价格完全不动」更接近短期，往往可用。
- 「今后许多年价格完全不动」会把长期答案带偏。长期要允许价格调整。
- 类比：短期像大理石，摩擦或价格粘性可以先忽略；长期把价格锁死，像用「没有空气」去算沙滩球。
- 战争打断运输是历史已经发生的事件，不是研究者为了实验去操纵的政策。

### C2-A02

**必答点：**

- 钞票进入物品与服务市场，成为企业收益，再在生产要素市场上变成工资或房租，成为家庭收入。
- 税和进口是现实里有的细节。基本图故意不画，是为了先看家庭与企业怎样接在一起。省略不等于图是错的。

### C2-A03

**必答点：**

1. 700 与 2000 在边界上（从 600 与 2200 沿边界走到这里）。
2. 300 与 1000 在边界内，无效率。
3. 1000 辆汽车同时有 3000 台电脑在边界外，现有技术和要素做不到。两端是「只生产一种」。
- 机会成本是每辆汽车两台电脑。

### C2-A04

**必答点：**

- 完全不造电脑时，汽车仍是 1000 辆。
- 可以走到 650 与 2300。
- 这是边界外移，不是在旧边界上把汽车从 600 增到 700、电脑从 2200 减到 2000 的那一步。

### C2-A05

**必答点：**

1. 实证。描述最低工资和失业的关系，原则上可以用证据去对。
2. 规范。规定应该怎样，还要价值观。
3. 实证。描述租金上限的后果。它不是「应该取消」那种句子。
4. 规范。在后代和这一代之间排序，数据单独判不完。

### C2-A06

**必答点：**

1. 科学判断。争的是储蓄反应这个参数有多大。
2. 价值观。比例已知，争的是谁交得太多。

### C2-A07

**必答点：**

1. 吸烟。打火机多往往烟也多。
2. 图本身不定方向。更说得通的是越危险的城市雇用的警察越多；预期犯罪上升时也会先雇人。
3. 不能。预期有孩子的家庭先买车。

### C2-A08

**必答点：**

1. 微观。某一个行业。
2. 宏观。联邦借债是整体问题。
3. 宏观问题，但必须经过家庭把多少钱改用于购买。这一章不把这个影响算成模型。

## 关卡 4 · 自核

### C2-S01

**必答点：**

- 科学家提出理论，再用数据或自然实验去对。
- 政策顾问主张世界应该怎样改善。
- 模型可以不真实，像塑料人体不画毛细血管，是为了看清所问的连接。
- 大理石可以忽略空气。沙滩球若忽略空气，答案会被带偏，假设就要换。

### C2-S02

**必答点：**

- 物品市场：家庭买、企业卖。要素市场：企业买、家庭卖。实物与货币方向相反。省略政府和国际贸易。
- 汽车一端 1000 与 0。电脑一端 0 与 3000。有效点例如 600 与 2200。再走一步 700 与 2000。无效率点 300 与 1000。
- 每辆汽车两台电脑。
- 完全不造电脑时，汽车一端仍是 1000。

### C2-S03

**必答点：**

1. 实证。可再标为劳动市场或微观，不标宏观也过，只要不把它标成规范。
2. 规范。
3. 微观。问的是住房这个市场怎样受影响；句子本身是一个问题，不是「应该」。标成微观即可。
4. 宏观。

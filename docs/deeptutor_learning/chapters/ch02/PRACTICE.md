## 关卡 3 · 用上

讲清过了再做。

<a id="c2-a01"></a>

### C2-A01

**简答 · 假设够不够**

有人研究「杂志价格在今后几个月里会不会跟着货币变动」，假设价格完全不动。另有人研究「今后许多年里物价总体会不会跟着货币走」，也用「价格完全不动」。哪一个假设更可能把答案带偏？请用大理石或沙滩球说一句类比。中东战争打断原油运输，为什么算自然实验，而不是实验室操作？

<a id="c2-a02"></a>

### C2-A02

**简答 · 走一圈**

一张钞票从家庭钱包出发，买了一杯咖啡。写出它经过的市场，以及它怎样变成另一个家庭的收入。若有人说「咖啡的税和进口咖啡豆也必须画在这张基本图上，否则图是错的」，你怎样回答？

<a id="c2-a03"></a>

### C2-A03

**简答 · 三个点**

经济只生产汽车和电脑。判断下面三点各在边界上、边界内还是边界外，并说明理由。已知两端是 1000 辆汽车或 3000 台电脑，边界上有 600 辆与 2200 台。

1. 700 辆汽车、2000 台电脑
2. 300 辆汽车、1000 台电脑
3. 1000 辆汽车、3000 台电脑

再算：从 600 与 2200 到 700 与 2000，每辆汽车的机会成本。

<a id="c2-a04"></a>

### C2-A04

**简答 · 技术变了**

电脑行业每个工人每周能造更多电脑。汽车若完全不生产电脑，产量还是不是 1000 辆？社会能不能从 600 辆、2200 台走到 650 辆、2300 台？这一步是沿旧边界重新配置，还是边界外移？

### C2-A05

**简答 · 贴标签**

给每句贴上实证或规范，并各说一句为什么。

1. 最低工资法引起了失业。
2. 政府应该提高最低工资。
3. 租金上限降低了住房的数量和质量。
4. 一项有利子孙后代的政策不应当损害这一代。

<a id="c2-a06"></a>

### C2-A06

**简答 · 分歧归类**

下面两段各属于科学判断还是价值观？不要替他们选边。

1. 一方认为不对储蓄征税会让家庭多储蓄很多，另一方认为储蓄几乎不反应。
2. Peter 与 Paula 取同样多的井水。Peter 纳税占收入 10%，Paula 占 20%。两人争论谁交得太多。

<a id="c2-a07"></a>

### C2-A07

**简答 · 图不能单独证明**

1. 打火机越多，家庭成员得癌症的可能越大。有人建议对打火机征税并印上警示。你要追问哪个没画上的变量？
2. 每千人警察越多，每千人暴力犯罪越多。有人主张取消执法。图本身能不能定方向？课本更说得通的一种读法是什么？
3. 买旅行车发生在孩子出生之前。能不能据此说旅行车引起了人口增长？

### C2-A08

# Practice · 题库

[精通之路](MASTERY_PATH.md) · [要点](ANSWER_KEY.md)

只做路径上已经打开的题。选择、判断先写答案再对。简答用自己的话，对的时候看必答点是否都在。情景只用教科书里的那些。

难度标在每题后面：`easy`、`mixed`、`hard`。

## 知识点 1

<a id="dt-01"></a>

### DT-01 · easy · 选择

晚饭的预算只够再加一份。多买一盒冰淇淋，披萨就少一块。交给哪一条？

- A. 把隐成本加总
- B. 人们面临权衡
- C. 看不见的手
- D. 短期里失业与通胀

<a id="dt-02"></a>

### DT-02 · easy · 判断

「枪炮与黄油」就是效率与平等：国防是饼的大小，黄油是饼怎样切。

<a id="dt-11"></a>

### DT-11 · mixed · 简答

一位同学说：「少睡一小时去读经济学，所以社会应当选效率、放弃平等。」这句话把哪些对子并错了？请分开写：这一小时在权衡什么；效率与平等在权衡什么。这一路要不要宣布哪一边赢？

<a id="dt-21"></a>

### DT-21 · hard · 简答

法律要求企业少排污。

1. 社会得到的一边是什么？
2. 放弃的一边可能出现在利润、工资、售价的哪里？
3. 这是枪炮与黄油，还是清洁环境与收入？
4. 这一路要不要据此宣布不该保护环境？

<a id="dt-31"></a>

### DT-31 · hard · 自核

合上书。用枪炮与黄油说一句少掉的是什么。再用一句话说明它为什么不是效率与平等。最后用福利或所得税说一句「切匀」和「饼变小」。

## 知识点 2

<a id="dt-03"></a>

### DT-03 · easy · 选择

对多数学生，上大学的成本里通常最大的一项是？

- A. 学费收据
- B. 不上学本可以挣到的工资
- C. 全部食宿
- D. 所有没去的城市的花费之和

<a id="dt-04"></a>

### DT-04 · easy · 判断

上大学的食宿应当整笔算进上学的成本，因为人在学校里确实要吃饭、住宿。

<a id="dt-12"></a>

### DT-12 · mixed · 简答

上大学时，哪些是显成本？哪一项隐成本常常最大？食宿怎样取舍才进成本？为什么不能把没做的所有事加总？

<a id="dt-22"></a>

### DT-22 · hard · 简答

一位学生在「今年上大学」和「今年去工作」之间选。列出显成本、通常最大的隐成本、食宿里计入和剔除的部分。若他的最佳替代其实不是工作，而是另一件他真会去做的事，工资还算不算？

<a id="dt-32"></a>

### DT-32 · hard · 自核

合上书，用自己的话讲完：机会成本停在哪一阶；运动员的高收入使哪一项变高。

## 知识点 3

<a id="dt-05"></a>

### DT-05 · easy · 选择

200 个座位，飞行成本 10 万美元，平均每座 500 美元。还有空位，候补乘客愿付 300 美元。卖不卖这一张，主要比较？

- A. 300 与 500
- B. 300 与多载这一位的花生、饮料
- C. 10 万与 300
- D. 学费与工资

<a id="dt-06"></a>

### DT-06 · easy · 判断

水对人不可少，钻石不是必需，所以水的价格应当更高。

<a id="dt-13"></a>

### DT-13 · mixed · 简答

500 美元、10 万美元、花生和饮料，各回答什么问题？水和钻石的价格跟着哪一个量走？

<a id="dt-23"></a>

### DT-23 · hard · 简答

沿用上面的数字。写出卖或不卖这一张的理由。分别说明 500 美元和 10 万美元为什么留在外面。给已经发生的那笔成本一个名字。

<a id="dt-33"></a>

### DT-33 · hard · 自核

合上书，用一句话写出「再做一单位」的规则，并说明平均数为什么回答不了下一张票。

## 知识点 4

<a id="dt-07"></a>

### DT-07 · easy · 选择

苹果涨价之后？

- A. 买方少吃，果园少摘
- B. 买方少吃，果园多雇人、多摘
- C. 买方多吃
- D. 只有果园的产权改变

<a id="dt-08"></a>

### DT-08 · easy · 选择

安全带降低了一次事故中的伤亡，同时事故次数上升、行人死亡上升。这是在说明？

- A. 激励还有没被点名的一侧
- B. 货币过多
- C. 再分配
- D. 一小时产出

<a id="dt-14"></a>

### DT-14 · mixed · 简答

安全带改变了「开得慢一点」的哪一侧？佩尔兹曼记下的单次死亡、事故件数、司机死亡、行人死亡，方向各是什么？汽油税让开车变贵之后，列出至少三种去向。

<a id="dt-24"></a>

### DT-24 · hard · 简答

苹果涨价时买方怎样、果园怎样？这是价格作为激励，还是工厂把烟排给附近居民那种外部性？用一句话把两件事分开。

<a id="dt-34"></a>

### DT-34 · hard · 自核

合上书，把安全带写成两列：点名的一侧，没被同样加价的一侧。再补一句：这不等于宣布法律失败。

## 知识点 5

<a id="dt-09"></a>

### DT-09 · easy · 选择

一个人种粮、一个人养牛，各专一侧再交换，双方可以比各自单干更好。这是？

- A. 贸易可以使人状况更好
- B. 镇上只有一口井
- C. 生活水平取决于生产率
- D. 沉没成本

<a id="dt-15"></a>

### DT-15 · mixed · 简答

「更好」是和谁比？即使一方两件事都更快，为什么仍可能互利？互利是否保证平分？数值留不留在这一路？

<a id="dt-25"></a>

### DT-25 · hard · 简答

从自给的家庭说到种粮与养牛。写出专做再交换可能带来什么，写出两件它不保证的事，写出这一路不做的那项计算。

<a id="dt-35"></a>

### DT-35 · hard · 自核

合上书，解释「更适合」看的是放弃的比例，不是谁绝对更快。

## 知识点 6

<a id="dt-10"></a>

### DT-10 · easy · 选择

这一章里，看不见的手靠什么协调分散的决定？

- A. 总调度
- B. 价格
- C. 所得税
- D. 短期失业

<a id="dt-16"></a>

### DT-16 · mixed · 简答

价格同时反映哪两样东西？冰淇淋涨价时买卖双方各怎样？房租不许调整时哪一步受阻？这一路画不画供需图？一种甜品涨价是不是通胀？

<a id="dt-26"></a>

### DT-26 · hard · 简答

若冰淇淋价格被按住、不许随短缺上涨，买方少买、店家多做还会不会由报价来完成？这和「物价总体因货币过多而上升」是同一件事吗？

<a id="dt-36"></a>

### DT-36 · hard · 自核

合上书，用三句讲：谁做决定，价格里有哪两层，价格不许动时手会怎样。

## 知识点 7

<a id="dt-17"></a>

### DT-17 · easy · 简答

给三句贴名字：外部性、市场势力、信息不完全。

1. 工厂把烟排给附近居民，健康成本不在「再多生产一点」的账单上。
2. 镇上只有一口井，主人少供水、把价格定高。
3. 卖旧车的人知道有没有出过事故，买的人只看见价格。

<a id="dt-18"></a>

### DT-18 · easy · 判断

所得税和福利把饼分得更匀，所以它们是市场失灵的第四扇门。

<a id="dt-19"></a>

### DT-19 · mixed · 简答

用农民、餐馆、影视各一句说明产权。为什么篮球运动员比国际象棋选手挣得多，不是市场势力？

<a id="dt-27"></a>

### DT-27 · hard · 简答

1. 工厂排污：为什么产量会停错位置？这是效率还是平等？
2. 旧车买方按平均成色出价：好车为什么离开？这一路要你把信息模型算完吗？

<a id="dt-37"></a>

### DT-37 · hard · 自核

合上书。三扇门各用一句说出漏了什么。再分配为什么写在门外。

## 知识点 8

<a id="dt-20"></a>

### DT-20 · easy · 简答

给三句贴上「生产率」「货币与物价」「短期的相反方向」。

1. 1921 年 1 月一份报纸约 0.30 马克，1922 年 11 月标价 7000 万马克，货币也增加得很快。
2. 各国生活水平的差别，几乎都可以归到一小时劳动生产多少。
3. 大约一两年里，许多政策把通胀和失业推向相反方向。

<a id="dt-28"></a>

### DT-28 · mixed · 简答

三条各写：边界判断是什么；这一路明确不做什么。生活水平不要把主因主要记在哪三件事上？

<a id="dt-29"></a>

### DT-29 · hard · 简答

只贴边界，不要展开模型。

1. 甲国工人每小时生产的物品与劳务远多于乙国，甲国大多数人日子更宽裕。
2. 物价总体持续飞涨，货币以相近速度增加，报纸从约 0.30 马克涨到 7000 万马克。
3. 有人主张马上压低通胀，有人提醒短期里失业可能先上升。

<a id="dt-38"></a>

### DT-38 · hard · 自核

合上书，说出短期大约多长，长期里过多的货币主要推什么，以及这一路为什么不画那条线。

## 知识点 9

<a id="dt-39"></a>

### DT-39 · mixed · 简答

把下面八项分成「这一路要碰到」和「这一路不展开」。

1. 用枪炮与黄油说出多要一边、少另一边。
2. 画出供给曲线和需求曲线的交点。
3. 说出污染、一口井、旧车各属于哪一扇门。
4. 计算两人比较优势的数值。
5. 说明德国报纸的物价在这一路停在哪一句。
6. 画出通胀与失业的曲线并讨论斜率。
7. 判断 300 美元的候补票该不该卖，并说明 500 美元为什么不进比较。
8. 写出货币数量公式。

<a id="dt-30"></a>

### DT-30 · hard · 简答

一位学生有一小时，可以读经济学，也可以读心理学、睡觉、骑车、看电视或打工。按顺序写四句：权衡里稀缺的是什么；成本记在哪里、为什么不能全部加总；再读十分钟比哪两个增量，已经读过的时间为什么不单独构成必须再读的理由；考试规则或打工工资改变时，小时会滑向哪里，没被点名的用途要不要看。

<a id="dt-41"></a>

### DT-41 · hard · 简答

少排污的法律至少可以同时是哪三件事？为什么不能直接把它叫成「货币过多引起的通胀」？

<a id="dt-40"></a>

### DT-40 · hard · 自核

合上所有页。写出十条的意思，分成人们如何做决策、人们如何相互影响、整体经济如何运行。标明：决策四条要能用；贸易和价格要能讲机制；政府要能认门，并写出三扇门的名字；整体经济只留边界句。

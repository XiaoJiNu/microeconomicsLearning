# DeepTutor 风格 · 第 1 章活书

这是一套按 [DeepTutor](https://github.com/HKUDS/DeepTutor) BookEngine 活书、Mastery Path 与 Practice 写成的静态 Markdown。不必安装或运行 DeepTutor。这是与仓库里其他学习路径无关的平行实验。

主题边界：曼昆《经济学原理》微观分册第 8 版，第 1 章「经济学十大原理」。原理 8–10 在本包里只做边界页。

## 三个学习表面

| 表面 | 你在做什么 | 从这里进 |
|---|---|---|
| Book | 按骨架读活书页。每一页是穿插的 typed blocks | [SPINE.md](books/ch01_ten_principles/SPINE.md) |
| Mastery Path | 按知识点过硬门槛。上一道没过，下一道不算 | [MASTERY_PATH.md](MASTERY_PATH.md) |
| Practice | 做题库。要点在答案页，做的时候先别打开 | [PRACTICE.md](PRACTICE.md) · [ANSWER_KEY.md](ANSWER_KEY.md) |

建议：先打开骨架，按页序读完一页上的块（讲解、图、提示、小测、闪卡、可深入话题）。读可以先于过关。过关只认掌握路径上的门槛，不认「我翻过」。

例子停在教科书情景里：枪炮与黄油、冰淇淋与披萨、上大学、空位机票、水和钻石、苹果、汽油税、安全带、自给的家庭、种粮与养牛、冰淇淋涨价、污染、镇上的井、旧车、再分配，以及生产率、货币和短期失业这三句边界。

## 教材依据

曼昆（N. Gregory Mankiw）《经济学原理》**微观分册第 8 版**，**第 1 章：十大经济学原理**（导论章）。

本章把十条原理分成三块：

1. **人们如何做出决策（原理 1–4）**  
   权衡、机会成本、边际、激励。这一块要练到能用来判断。
2. **人们如何相互影响（原理 5–7）**  
   贸易可以互利；市场通常靠价格协调（看不见的手）；政府有时改善结果。政府这一条在本章认清前提和边界：产权、效率与平等、外部性、市场势力；信息不完全只认名字。
3. **整体经济如何运行（原理 8–10）**  
   生活水平与生产率、货币与通胀、短期里失业与通胀的权衡。微观这条路径在本章**只标边界**。展开属于宏观，这里不建增长模型、不写货币公式、不画曲线。

例子只用课本里的课堂情景：枪炮与黄油、冰淇淋与披萨、上大学的机会成本、空位机票、水和钻石、苹果价格、汽油税、安全带、家庭自给、种粮与养牛、冰淇淋涨价、污染、镇上唯一一口井、出过事故的旧车、再分配与市场失灵、德国报纸物价、生产率、2008–2009 年那场关于支出与失业的争论。不另编工作场所或实验室的比方。

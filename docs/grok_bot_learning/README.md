## 分支怎么用

辅导记录提交在 `grok-bot`。没有明确要求时，不把这个分支合并进 `main`。

`gpt6-pro` 上的课程若有更新，在本分支用 rebase 或 merge 从 `gpt6-pro` 同步。同步是为了让对照表跟着课文走，不在本分支改 `course_gpt6_pro` 或 `course_20h` 的课文。

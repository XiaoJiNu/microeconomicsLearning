# 为什么 gpt6-pro 对着曼昆目录会觉得对不上

对照的是曼昆《经济学原理》第 8 版微观分册目录（第 1–22 章）。下面只解释课程是怎么排的，不摘录原书正文。

## 仓库里有两套课

| 目录 | 形态 | 现在的角色 |
|---|---|---|
| [`docs/course_20h/`](../course_20h/README.md) | 旧版，10 个单元、80 节，每节约 15 分钟 | 历史课文，含知乎草稿 |
| [`docs/course_gpt6_pro/`](../course_gpt6_pro/README.md) | 默认课，10 个单元、100 个小课，按问题写 | 当前主线 |

[`START_HERE_20_HOURS.md`](../../START_HERE_20_HOURS.md) 指向 `course_gpt6_pro`。根目录 README 同样把新版当作默认路径。`course_20h` 的 README 也写明：默认学习改走一百小课。

## 最近实际走过的是旧单元前五节

知乎稿和手头进度跟的是 `course_20h/unit_01_economic_thinking` 的 01–05：

1. 稀缺、权衡、机会成本
2. 沉没成本、边际分析
3. 激励、贸易、市场协调
4. 模型、其他条件不变
5. 循环流向图、生产可能性边界

这五节按「做一个决定要先搞清什么」来排，不按原书第 1 章、第 2 章的小节顺序走。所以拿原书目录逐节去对，会觉得第 1 章后半和第 2 章后半还没出现，而模型、循环流向、生产可能性边界又提前出现了。

## 新版按问题重排，二十二章仍在映射里

[`SCOPE.md`](../course_gpt6_pro/SCOPE.md) 仍以第 1–22 章为映射，十个单元都在。重排的意图是把决策和互动机制讲透，章内次要例子不逐页跟着走。

和第 1–2 章相关的落点：

- 第 1 章决策四条（权衡、机会成本、边际、激励）放在 `course_gpt6_pro` 的 U01.01–05。U01.03 专讲沉没成本，夹在机会成本和边际之间，方便做一个完整决定。十条原理里没有单独这一条。
- 第 1 章原理 8–10（生产率、通胀、通胀与失业的短期权衡）在 [U01 README「第 1 章宏观边界速读」](../course_gpt6_pro/u01/README.md) 里只划边界。本轮微观课不把宏观模型展开。
- 贸易、市场如何组织活动，深学放在 U02；政府改善市场结果、贸易政策的福利，深学放在 U02 / U04 / U05。U01 导航只点出后面在哪，不在第 1 章一次讲完。
- 第 2 章的工具（生产可能性边界、循环流向、模型、因果、实证与规范）在 U01.06–10。

SCOPE 的写法就是：第 1 章 → U01.01–05 加导航，展开见 U02 / U04 / U05；第 2 章 → U01.06–10。

## 「缺了很多」从哪来

拿第 1 章十个小节标题，去对已经做过的五节问题课，中间没有一张「这一章每条现在处于什么状态」的清单。对得上的条目分散在不同文件里，其余条目又没有标成「扫读」或「延后」，读起来像整章不见了。二十二章的映射仍在 SCOPE 里。

## 以后怎么补，而不改课文

问题主线继续用：默认走 `course_gpt6_pro`，已经做过的 `course_20h` / 知乎课记成已覆盖，不重学一遍。

另外维护一份原书目录清单（从 [chapter_map.md](chapter_map.md) 起，第 1 章的逐条例子在 [ch01_learning_plan.md](ch01_learning_plan.md)）。每条都要有标签，不能从地图上消失：

- **深学**：在对应小课里把机制做会。
- **扫读知边界**：知道这条在讲什么、本轮不往下推导。
- **延后到某单元**：第 1 章只留标题和入口，正文放到写明的单元。

清单状态见章节对照表。某一章还没有单独的勾选页时，标「待建」，不表示该章不在课程里。

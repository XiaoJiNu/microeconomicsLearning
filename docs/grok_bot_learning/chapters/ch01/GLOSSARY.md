# 第 1 章术语表

[本章目录](README.md) · [勾选清单](CHECKLIST.md)

每条一句，对应课文里的用法。这些词没有要背的缩写。

| 术语 | 一句解释 | 课 |
|---|---|---|
| 稀缺性（Scarcity） | 在你面对的条件下，可用资源不够同时覆盖所有相关用途。 | [01](01_tradeoffs.md) |
| 权衡（Trade-off） | 多获得一方面，就要少获得另一方面。 | [01](01_tradeoffs.md) |
| 效率（Efficiency） | 同样的投入换成更多人们所看重的产出，也就是把饼做大。 | [01](01_tradeoffs.md) |
| 公平（Equity） | 产出和负担在人与人之间怎样分。本章只把它当作常和效率放在一起的另一头。 | [01](01_tradeoffs.md) |
| 机会成本（Opportunity cost） | 为了得到某物而放弃的最佳替代的价值。 | [02](02_opportunity_cost.md) |
| 最佳替代（next-best alternative） | 在你真实会采纳的方案里，排在所选方案后面的那一个。 | [02](02_opportunity_cost.md) |
| 显成本（Explicit cost） | 为了这个选择需要另外支付出去的金钱或资源。 | [02](02_opportunity_cost.md) |
| 隐成本（Implicit cost） | 已经拥有的资源若改作最佳替代所能带来的价值。没有新账单，它仍然是成本。 | [02](02_opportunity_cost.md) |
| 边际收益（Marginal benefit） | 再增加一单位活动所多得到的收益。 | [03](03_marginal.md) |
| 边际成本（Marginal cost） | 再增加一单位活动所多付出的成本，按机会成本的口径来算。 | [03](03_marginal.md) |
| 平均量（average） | 到目前为止的总收益或总成本，除以已经做过的单位数。它不直接回答下一单位。 | [03](03_marginal.md) |
| 沉没成本（Sunk cost） | 已经发生、无法收回的成本。下一单位做或不做，它都不变。 | [03](03_marginal.md) |
| 理性人（rational person） | 在本章里指按自己的目标比较边际收益和边际成本的人。 | [03](03_marginal.md) |
| 激励（Incentive） | 改变某个行为的边际收益或边际成本的因素，例如价格、罚款或考核指标。 | [04](04_incentives.md) |
| 非预期后果（unintended consequence） | 被点名的行为变了，人同时转向另一个没被点名、因而相对变便宜的行为。 | [04](04_incentives.md) |
| 贸易（Trade） | 各方把自己相对更适合做的成果换给对方。 | [05](05_trade_markets.md) |
| 贸易互利 | 交换之后，参与的人按各自的目标，可以好于把时间留在自己不顺手的环节上单干。 | [05](05_trade_markets.md) |
| 专业化（Specialization） | 把更多时间放在自己放弃得较少的那类任务上，其余靠交换获得。 | [05](05_trade_markets.md) |
| 市场（Market） | 许多这样的交换汇在一起的安排。它不必是一个具体的摊位。 | [05](05_trade_markets.md) |
| 价格（Price） | 别人愿意为多要一单位而放弃什么，被压缩成的一个数；它也是一种激励。 | [04](04_incentives.md)、[05](05_trade_markets.md) |
| 外部性（Externality） | 一个人的行为给没参加这笔交易的人带来成本或收益，而他自己的边际比较里没有这一项。三扇门之一。 | [06](06_government_preview.md) |
| 市场势力（Market power） | 买方或卖方能够单独把价格定在还有许多竞争者时的水平之外。三扇门之一。 | [06](06_government_preview.md) |
| 信息不完全（Imperfect information） | 交易的一方掌握另一方没有的关键事实，价格因此汇总不到质量或风险。三扇门之一。 | [06](06_government_preview.md) |
| 再分配（Redistribution） | 在已有的成果上改变谁分到多少。它不是上面三扇门里的一扇。 | [06](06_government_preview.md) |
| 生产率（Productivity） | 一单位劳动投入，通常按一小时计，能够生产的物品与劳务。原理 8 的边界标签，本章不建增长模型。 | [07](07_macro_boundary_review.md) |
| 通胀（Inflation） | 物价总体水平的持续上升。个别材料涨价不一定就是通胀。原理 9 的边界标签，本章不写货币公式。 | [07](07_macro_boundary_review.md) |
| 短期权衡（short-run tradeoff） | 本章专指：把通胀压低的过程中，失业可能先上升。原理 10 的边界标签，本章不画曲线。 | [07](07_macro_boundary_review.md) |

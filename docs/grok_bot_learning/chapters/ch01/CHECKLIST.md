## 过关标准

六条都能勾上，本章就可以收束。条文与 [目录里的过关标准](README.md#过关标准) 相同。

- [ ] 写出一个你自己的两难，说清稀缺的是哪种资源。效率与公平如果出现，只作为其中一对权衡，不展开成价值争论。
- [ ] 对这个两难指出最佳替代，分开显成本和隐成本，并且没有把所有没做的事加总。
- [ ] 对「再多一单位」写出边际收益和边际成本。已经付掉、收不回的花费不进入这个比较。
- [ ] 改一条价格或考核规则，说出行为会滑向哪里，包括规则没有点名的那一种行为。
- [ ] 不计算、不画图，用自己的话说明：为什么互换可以让两边都比各自单干更好，价格在代替什么信息。
- [ ] 背出十条短标题，并标上深学、中等或简讲。原理 7 能说出三扇门的名字和后文章号。原理 8–10 能说出「本次不建模型」。

第 07 课的十条一览和费曼可以当作一次总检查。做完再决定要不要重读某一课。

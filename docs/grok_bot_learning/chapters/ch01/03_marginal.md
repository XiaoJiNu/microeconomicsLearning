## 本课要解决的问题

已经做了一些之后，再多做一点点值不值。这个判断看的是下一单位的额外收益和额外成本，不是到目前为止的平均数。

## 它在第 1 章里的角色

本课对应原理 3：理性人考虑边际量。前两课处理「选哪一个方案」以及「这个方案放弃了什么」。这一课处理方案内部的剂量：做多一小时、多测一轮、多加一台。下一课再看价格和规则怎样改变这里的额外收益或额外成本。

沉没成本在本课只占一小步：已经无法收回的花费不进入边际比较。反复练习留到第 13–14 章讲成本和停产的时候。

## 关键术语

这些词没有需要记住的缩写。

- **边际收益（Marginal benefit）**：再增加一单位活动所多得到的收益。
- **边际成本（Marginal cost）**：再增加一单位活动所多付出的成本，按上一课的机会成本口径来算。
- **平均量（average）**：到目前为止的总收益或总成本，除以已经做过的单位数。它描述过去的整体，不直接回答下一单位。
- **沉没成本（Sunk cost）**：已经发生、无法收回的成本。它不因下一单位做或不做而改变。
- **理性人（rational person）**：在本课里指按自己的目标比较边际收益和边际成本的人。它不是道德评价，也不表示这个人永不犯错。

## 解法/机制

1. 把决定改写成「要不要再增加一单位」，并写明这一单位是什么：一轮测试、一台样机、一小时调试。
2. 估计这一单位新带来的收益，以及它新占用的最佳替代。这就是边际收益和边际成本。
3. 边际收益高于边际成本，就再做一单位。低了就停，或把资源挪到边际收益更高的用途。两者接近时，这一单位可做可不做，敏感的是你的估计误差。
4. 平均数只用来了解过去。平均收益仍然好看时，下一单位也可以已经不值得。用平均数代替边际量，会把早先很值钱的单位摊到现在，从而多做。
5. 沉没成本无论下一单位做或不做都收不回，所以不写进第 2 步的任何一边。它会影响情绪，不改变这一单位的边际比较。

### 边际、平均、沉没

| | 用来决定下一单位 | 不要拿来决定下一单位 |
|---|---|---|
| 边际收益、边际成本 | 再做一轮新得到什么、挤掉什么 | |
| 平均数 | | 早期的高产出还摊在里面 |
| 沉没成本 | | 停下来也退不回 |
| 停下来仍能退款或改作他用的花费 | 按机会成本重新算进边际成本 | |

## 最小例子

分拣臂进入实验室测试。前 20 轮发现了大部分明显故障，平均每轮大约 4 个问题，每一轮占用实验台 1 小时。第 21 轮仍能稳定找到交接缝上的新问题，这一小时值得。

到第 80 轮，预期新增的问题是一个很少出现的边角场景。这一小时若用来改电机驱动，可以消掉现场已经复现的抖动。第 80 轮的边际收益低于它的边际成本。

此时「平均每轮 4 个问题」仍然会被人拿来辩护继续测，因为早期的高产出还摊在平均数里。决定第 80 轮时，早期的产出已经拿到，不再是这一轮的收益。

前 79 轮花掉的实验台时数也无法退回。把「已经测了这么久，不停就亏了」写进理由，是把沉没成本拉进了边际比较。下一轮值不值，只看这一轮新发现的问题和这一小时还能做的最佳替代。

## 适用场景与边界

- 单位不能拆开时，「一单位」要改成真实能加减的那一块，比如一整块传感器，而不是半块。比较的步骤不变，变的是步长。
- 边际收益和边际成本估不准时，先写估计区间。区间整个高于或低于另一侧时，方向仍然清楚；重叠很大时，本课的结论是「先补信息」，不是假装有精确数字。
- 这一单位的收益或成本落到别人身上、而决定者自己感受不到时，私人的边际比较会和团队或社会的比较分开。那是第 06 课要开的门，本章不画外部性的图。
- 人会因为已经投入而舍不得停。这种倾向真实存在。本课的规则仍然是：比较时把收不回的部分留在外面。为什么人会偏离、怎样设计提醒，留到第 22 章的有限理性，不在这里展开。

## 为何这样切

边际比较是后面供需、企业产量和消费者选择共用的步骤，所以在第 1 章深学，并立刻和平均数对照。一次把行为偏差、停产图表和成本函数都讲完，会把「下一单位」这个清晰问题淹没。沉没成本只要在这里被移出比较，决策框架就闭合了；把它练熟是后文章的工作。先清晰、后加厚，是本章整组深学课的切法。

## 练习

选一件你准备「再做一点」的事（多调试一小时，或多做一组实验）。写三行：这一单位的边际收益、它的边际成本（指出最佳替代）、一个你不会写入比较的沉没成本。最后补一句：到目前为止的平均数为什么不能代替这三行。

<details>
<summary>参考要点</summary>

- 边际收益和边际成本都要指向同一单位。一边写「再测一轮」，另一边写「整个项目的总预算」，口径就混了。
- 边际成本用机会成本：这一单位挤掉的最佳替代，不只是新付的现金。
- 沉没成本的特征是「停下来也退不回」。若停下来还能退款或改作他用，它就还不是沉没的，要按机会成本重新考虑。
- 平均数可以很高或很低，都不直接决定下一单位。它只解释过去的整体看起来怎样。

## 1 分钟费曼

用自己的话回答：再多做一单位时，你比较哪两个量；已经花掉的哪些钱或时间为什么不在这个比较里。

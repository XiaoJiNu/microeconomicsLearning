# 04 人们对激励作出反应

[本章目录](README.md)

## 原书对应

第 8 版微观分册第 1 章：

- 原理四：人们会对激励做出反应

## 本课要解决的问题

价格或规则一变，人会改行为；有时改到设计者没点名的那一侧。

## 关键术语

- **激励**：改变某一行为的边际收益或边际成本的因素（价格、罚款、考核等）。
- **非预期后果**：被点名的行为变贵（或变便宜）后，活动滑向邻近、没被同样加价的行为。

### 激励一改，行为会滑

![安全带强制后，事故指标下降，但车速与风险要另看](assets/04_incentive_slide_compact.jpg)

规则改的是「被点名」那一侧的成本；人还可能改速度、改记法等没被点名的一侧。

## 机制（三步）

1. 写出规则直接加价或减价的那个行为。
2. 预期：变贵的少做，变便宜的多做。
3. 列出争夺同一时间、金钱或风险预算的邻近行为；没被加价的一侧会吸走活动。被考核的数字变好，不等于你真正关心的结果变好。

### 对照表

| | 被规则点名 | 没被点名的邻近行为 |
|---|---|---|
| 成本怎么变 | 上升 → 该行为变少 | 相对变便宜 → 活动滑过来 |
| 报表能说明什么 | 点名的指标 | 不能单独代表真实结果 |
| 还要另看什么 | | 速度、风险、未被记录的行为 |

## 最小例子（课本口径）

强制系安全带，降低了一次碰撞中伤亡的预期损失，等于降低了「开得猛一点」的边际成本。结果可能是：被点名的伤亡指标下降，但车速上升、小擦碰或别的风险上升。机制与「汽油税提高 → 少开车、改坐公交」相同：激励改写边际比较，人沿更划算的方向动。

## 练习

选一条你见过的规则（涨价、扣分、补贴）。写三行：哪个行为变贵了；哪个邻近行为变便宜了；你准备同时看哪个没被点名的指标。

## 1 分钟费曼

一条规则改了哪个行为的边际成本？人因此可能多做哪件规则没点名的事？

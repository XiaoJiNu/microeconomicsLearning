- 原理一：人们面临权衡取舍

效率与公平写在这一节里，不是另立的目录标题。本章只把它认成一对常见权衡。

## 本课要解决的问题

资源不够把想要的一起做完时，怎样把「多要一样，就要少要另一样」说成一个能接着分析的决定。

## 关键术语

- **稀缺性**：在你面对的条件下，可用资源不够同时覆盖所有相关用途。
- **权衡**：多获得一方面，就要少获得另一方面。
- **效率**：同样的投入换成更多人们所看重的产出，把饼做大。
- **公平**：饼在人与人之间怎样分。原书这一对也常译作效率与平等。本章不讨论哪一种分法应当赢。

### 一边抬高，另一边下来

![稀缺资源是支点，一边抬高另一边就下来](assets/01_tradeoff_seesaw.jpg)

支点是不够用的那一种资源。一边抬高，另一边就下来。效率与公平若出现，只是可以再贴上的一对标签。

## 机制（四步）

1. 写出不够用的资源：土地、劳动、收入或时间，哪一种真的不够。
2. 列出在这条约束下不能同时做满的两边。能同时做满的，先从权衡里拿掉。
3. 说成一句：多得到 A，少掉的是 B。
4. 若一头是饼的大小、另一头是谁分到多少，标成效率与公平，然后停住。

### 对照表

| | 写成能分析的权衡 | 还停在愿望上 |
|---|---|---|
| 资源 | 点名哪一种不够 | 只说两边都重要 |
| 两边 | 多得到 A 时，少掉的是哪一件 | 停在含糊的二选一 |
| 效率与公平 | 认出「饼的大小」和「谁分到」，然后停住 | 在这一课裁决哪一头应当赢 |
| 假冲突 | 能同时做满的，先拿掉 | 把还能兼得的也叫权衡 |

## 最小例子（课本口径）

社会把资源多用于枪炮（国防），能做成黄油（消费品）的就少。同一条逻辑落在家庭预算上：这一周饭钱有限，多买一盒冰淇淋，披萨就少一块。

把饼分得更匀，常常要减弱多工作、多生产的激励，饼可能因此变小。这是效率与公平。本课只贴上这对标签。

## 练习

写三行：哪种资源不够；不能同时做满的两边；多得到第一边时少掉的第二边。若出现「饼的大小」和「谁分到」，只加标签「效率与公平」，不写立场。

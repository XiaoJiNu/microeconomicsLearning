# 02 成本是放弃之物

[本章目录](README.md)

**本课深度：深学。** 学完能把一个选择的成本写成放弃的最佳替代，分清显成本和隐成本；不把所有没做的事加总，两边一样的食宿留在外面。

## 原书对应

第 8 版微观分册第 1 章：

- 原理二：某种东西的成本是为了得到它所放弃的东西

## 本课抓住什么

1. 账单上的金额常常还不是全部成本。做决定比的是不同做法的成本与收益。
2. **机会成本**是为了得到它所放弃的东西。记进账的是你真正会选的**最佳替代**，不是所有没做的事加总。
3. 上大学最大的一项，通常是不上学本可挣到的工资，这是**隐成本**；学费和书本是为了上学才付的**显成本**。
4. 不上学也要付的食宿留在外面，只有住校多出来的那一截才算。最佳替代若不是工作，工资就换成那一件事的价值。

## 原书这一节在讲什么

### 原理二：某种东西的成本是为了得到它所放弃的东西

人既然面临权衡，做决定就要比较不同做法的成本与收益。成本常常比账单上的金额更不容易看见。

#### 上大学：账单加总还不够

原书用上大学来算这笔账。上大学的收益，是知识上的收获，以及日后更好的工作机会。成本若只把学费、书本、食宿加在一起，还没有回答「你为了读这一年书放弃了什么」。

加总漏掉的第一项，是不上学、去工作本可以挣到的收入。对多数学生，放弃的这笔收入是教育成本里最大的一项。第二，食宿并不整笔都算大学的成本：不上学，人一样要有地方住、有饭吃。只有因为住校而比住在家里多出来的那一截，才算进上学的成本。

#### 机会成本是放弃的东西

一件东西的**机会成本**，就是为了得到它所放弃的东西。做决定时，每个选项旁边都带着这份成本。职业运动员若辍学去打球能挣到很高的收入，他们清楚自己上大学的机会成本特别高，于是有人会判断，上学的收益抵不上这份成本。

#### 只记最佳替代

同时能想起的「没做的事」有很多，记进机会成本的是你真正会去选的下一个，也就是**最佳替代**。排在它后面的，并不因为你没去做就一笔笔加进总额。为了这个选择才另外付出的钱，是**显成本**，比如学费和书本。自己的时间若拿去从事最佳替代所能得到的，是**隐成本**，比如放弃的工资；没有新账单，它仍然是成本。无论上不上大学都要付的那部分食宿，两边一样，不构成差别。

最佳替代若根本不是工作，而是另一件你真会去做的事，工资就退出这笔成本，换上那一件事的价值。

## 这一节要带走的

成本是为了得到它所放弃的最佳替代，不是所有没做的事加在一起。学费和书本是显成本；放弃的工资是隐成本，常常是最大的一块。不上学也要花的食宿留在外面。最佳替代若不是工作，工资就换成那一件事的价值。

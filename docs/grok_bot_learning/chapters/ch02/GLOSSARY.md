# 第 2 章术语表

[本章目录](README.md) · [勾选清单](CHECKLIST.md)

每条一句，对应课文里的用法。这些词没有要背的缩写。循环流量图有时也被叫做循环流向图，本章按原书用前一个名字。

| 术语 | 一句解释 | 课 |
|---|---|---|
| 科学方法 | 提出关于世界如何运行的理论，再用观察和数据去支持或怀疑它。 | [01](01_scientist_models.md) |
| 自然实验 | 历史已经发生、经济学家不能为了研究去操纵的事件，例如战争打断原油运输后的油价。 | [01](01_scientist_models.md) |
| 假设 | 为了把问题简化而暂时采用的前提。它不必完全真实；若它会改变这一问的答案，就不适用于这个新问题。 | [01](01_scientist_models.md) |
| 其他条件不变 | 看一个因素的作用时，先把其余相关因素当成不动。附录用它把价格对购买量的影响单独看出来。 | [01](01_scientist_models.md) |
| 经济模型 | 为了看清所问的问题而简化现实的图形或方程。塑料人体是书中的类比：留下主要器官，不画每一条毛细血管。 | [01](01_scientist_models.md) |
| 循环流量图 | 说明货币如何通过市场在家庭与企业之间流动的直观模型。内圈是投入与产出，外圈是货币，方向相反。 | [02](02_circular_flow.md) |
| 家庭 | 拥有生产要素，向企业提供劳动、土地和资本，并购买物品与服务的决策者。 | [02](02_circular_flow.md) |
| 企业 | 使用生产要素生产物品与服务并出售的决策者。企业所有者也是家庭的成员。 | [02](02_circular_flow.md) |
| 生产要素 | 用于生产的投入：劳动、土地和资本（建筑物和机器等）。 | [02](02_circular_flow.md) |
| 物品与服务市场 | 家庭是买者、企业是卖者的市场。 | [02](02_circular_flow.md) |
| 生产要素市场 | 家庭是卖者、企业是买者的市场。 | [02](02_circular_flow.md) |
| 生产可能性边界 | 生产要素和生产技术既定时，一个经济能够生产的两种产品的各种数量组合。本章的两种产品是汽车和电脑。 | [03](03_production_possibilities.md) |
| 有效率（在边界上） | 不减少一种产品，就无法再增加另一种。边界上的点是这种结果。 | [03](03_production_possibilities.md) |
| 无效率（在边界内） | 产量小于资源所能允许的。书中的例子是普遍失业：300 辆汽车和 1000 台电脑，两种都可以更多。 | [03](03_production_possibilities.md) |
| 机会成本（边界的斜率） | 为了多得到一种产品而放弃的另一种。从 600 辆、2200 台到 700 辆、2000 台，每辆汽车是两台电脑。 | [03](03_production_possibilities.md) |
| 边界外移 | 资源增加或技术进步之后，原先的权衡整体向外。电脑技术变好时，汽车一端可以仍是 1000 辆。 | [03](03_production_possibilities.md) |
| 微观经济学 | 研究家庭和企业如何做决定，以及他们如何在特定市场上相互交易。 | [04](04_micro_macro.md) |
| 宏观经济学 | 研究整体经济现象，包括通货膨胀、失业和经济增长。 | [04](04_micro_macro.md) |
| 实证表述 | 描述性的：世界是什么样。原则上可以用证据确认或否定。书中的例子是「最低工资法引起了失业」。 | [05](05_positive_normative.md) |
| 规范表述 | 规定性的：世界应该是什么样。评价它还要价值观。书中的例子是「政府应该提高最低工资」。 | [05](05_positive_normative.md) |
| 科学判断的分歧 | 对哪一种实证理论正确，或对某个参数有多大，看法不同。书中的参数是储蓄对税收激励的反应。 | [06](06_disagreement_review.md) |
| 价值观的分歧 | 对政策应当追求什么看法不同。水井税的 10% 和 20% 谁交得太多，科学回答不完。 | [06](06_disagreement_review.md) |
| 相关 | 两个变量一起变动。图上的一起变动本身不是因果。 | [06](06_disagreement_review.md) |
| 忽略的变量 | 图上没画、却能解释两个变量一起变动的第三个因素。打火机与癌症之间是吸烟。 | [06](06_disagreement_review.md) |
| 反向因果关系 | 把方向看反了：以为甲引起乙，其实是乙引起甲。危险的城市雇用更多警察；旅行车不带来婴儿。 | [06](06_disagreement_review.md) |

## 每章四步

1. 扫目录。打开该章目录，看标题，不深读。
2. 深学对照课。做本表「本章必做」指向的小课。`course_20h` / 知乎已经覆盖的机制，压缩，不重做一遍。
3. 勾选。清单上每一条留下一种状态，并打勾：
   - **深学**：在对应小课里把机制做会。
   - **扫读知边界**：知道这条在讲什么，本轮不往下推导。
   - **延后**：本章只留标题和入口，正文放到写明的章。
4. 回书核对名词。只核对名词是否见过。次要例子可跳过。每个标题都要在清单上有状态。

## 进度

一章清单勾完，再开始下一章的深学。扫读和延后也算勾完。

延后条目留在原章清单上。学到所写的后续章时，在那一章清单加一行回看：从哪一章的哪一条过来，本课是深学收掉，还是继续扫读。

本文件是 `grok-bot` 的书序导航。先读 [全书概述](book_overview.md)（约 10–15 分钟）和 [全书思维导图](book_mindmap.md)，再进入已写好的章。

第 1 章正文在 [chapters/ch01](chapters/ch01/README.md)，状态为**文档齐备**（材料完整：概述、导图、七课、配图、对照表、[勾选清单](chapters/ch01/CHECKLIST.md)、[术语表](chapters/ch01/GLOSSARY.md)、原书目录覆盖表）。忽略以前在知乎或 `course_20h` 里的完成记录，按新材料把第 1 章重学一遍。旧清单 [ch01_learning_plan.md](ch01_learning_plan.md) 只作历史对照。

## 导航顺序

导航顺序是曼昆《经济学原理》第 8 版微观分册第 1–22 章。下表只用原书短标题对目录，不摘录正文。

每一章的文件夹若已建，正文以该文件夹为准。还没建的章，表中课号只说明这个题目在 [`docs/course_gpt6_pro/`](../course_gpt6_pro/README.md) 的哪一课出现过，不能当成免修。课号对照仍见 [`SCOPE.md`](../course_gpt6_pro/SCOPE.md) 和 [chapter_map.md](chapter_map.md)。

## 每一章先有概述和导图

这是本路径的固定规则，第 2 章起同样遵守：

- 每个 `chapters/chNN/` 在小课之前先写整章**概述**和一张 **思维导图**（mermaid，能在 GitHub 上读）。
- 概述要说明这一章在解决什么、哪些深学、哪些简讲、课怎样连成一条链、怎样算学完。
- 先读概述和导图，再做小课。
- 每一课至少一张手绘白板 sketchnote（放在该章 `assets/`，相对路径嵌进课文）和一张对照表。图看机制，表对容易写混的口径。
- 每一课开头写「原书对应」，列出覆盖的原书目录标题；只开入口或只标边界时，写明正文展开在哪一章。
- 每一章 README 写「原书目录覆盖表」，使该章目录标题都有课、深度和状态。

当前按这个规则交付的只有第 1 章。

## 每章四步

1. 先读该章概述和思维导图。不要从中间某一课插进。
2. 按该章深度标签做小课。深学的把机制做会。中等和简讲停在该课写明的边界上。
3. 深学、中等、简讲都留下完成状态。简讲做完「认门和边界」也算完成。
4. 回书核对名词。只核对名词是否见过。次要例子可跳过。

## 进度

一章的概述、导图和小课走完，再开始下一章。

延后的题目留在原章，并写明收到后面哪一章。学到那一章时，在概述里加一行回看。

第 2–22 章的文件夹学到该章再建，不一次写完。每一章都先写概述和思维导图，再写小课。

## 和第 1–22 章课号地图的关系

`course_gpt6_pro` 的 100 个小课仍在仓库里，按问题编排。本路径按书的章节走。某一章的 `chapters/chNN/` 写好之后，以那一章的正文为准。

第 1 章已经这样写好。第 2 章「像经济学家一样思考」尚未建正文。不要把旧单元里提前出现的模型、循环流向或生产可能性边界，记成第 2 章已经学完。

后面章节的课号仍然可以用来对 SCOPE。例如 U08 的十课对应三章：第 18 章对应 U08.01–04 和 U08.08，第 19 章对应 U08.05–07，第 20 章对应 U08.09–10。这是地图，不是跳章许可。

当前章没有走完，不开始下一章的新深学。简讲和中等按边界做完，算走完。

买方势力、数值化的价格效应分解，SCOPE 写明是解释边界的补充。OpenStax 的章节号不能当成曼昆的章节号。

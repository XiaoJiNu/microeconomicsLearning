# 全书概述：微观经济学原理（书序）

这篇大约读 **8–10 分钟**。它回答三件事：学习目标是什么，读完能获得什么，这些知识在真实决定里怎样用。

对齐曼昆《经济学原理》第 8 版微观分册第 1–22 章。只用短标题对目录，不摘录原书段落。结构图在 [全书思维导图](book_mindmap.md)。读完本页，再打开 [第 1 章](chapters/ch01/README.md)。本路径从头学，别处做过的笔记不作为免修。

## 学完这本书，我到底多了什么能力？

钢铁有限，多造枪炮，黄油就少。这一周的饭钱也有限，多买一盒冰淇淋，披萨就得少买一块。枪炮与黄油、披萨与冰淇淋问的是同一件事：资源不够把想要的一起做完，多要一边，就要指出另一边少掉的那一件。两边都有理由，理由本身不告诉你该停在哪里。

缺的是一条检查顺序：哪一种资源真正不够，多做一件事具体少掉什么，再多做一点点值不值，规则和价格会把行为推向哪里，以及这件事是市场在传递稀缺，还是有人把成本漏到了交易外面。

要留下的能力，是把这种决定写成可检查的判断。判断可以错，但错在哪一步要能指出来。

## 这本书在解决什么问题

资源不够把想要的东西一起做完，这是自己的选择。选择还会碰到别人：你多做一点，好处或坏处不只落在你身上，也落在没和你一起做这个决定的人身上。课本里最常见的是三扇门。

- **外部性。** 工厂多生产，烟飘到隔壁。邻居的衣服脏了，人被呛到。工厂算自己的燃料费，不算这些损失。坏处落到了交易外面的人身上。
- **市场势力。** 镇上只有一家自来水公司，居民换不了第二家。水价可以比「很多公司抢着供水」时更高。问题不是水本来就贵，而是买方走不开。
- **信息不对称。** 卖旧车的人知道这辆车是不是经常抛锚，买的人只看见标价。两边掌握的事实不一样，价格就汇总不到车的真实好坏。

价格有时做的是另一件事。天热，想吃冰淇淋的人变多，价格上涨，店家多做一些，有的人少买一点。价格把「别人现在更想要它」传过来。这是市场在协调，不是上面的三扇门。

口号收不了场：都重要所以都做，贵就是坑，电影票已经买了就不能走。电影票已经买了、不能退，它不进入「现在还要不要进场」的比较。资源冲突、算错成本、用平均数代替下一单位、规则改了行为、价格在协调、价格在失灵，改法并不相同。这本书把这六件事分开。两条主线贯穿全书：市场在一定条件下能把互不相识的人协调到一起；市场也会失灵，规则有机会把结果改好。学生的时间本身就稀缺，先画清地图，细节留到对应的章。

## 目标：把决定写成可检查的判断

学习目标收成一条链：

**选择 → 交换 → 市场协调或失灵 → 福利账 → 定价 → 分配。**

选择问约束、权衡、机会成本和激励，工具在第 1–2 章。交换问分工再互换是否比单干更有进展，计算在第 3 章。市场问涨价是想买的人变多，还是卖家只剩一家；供需、弹性和税收在第 4–6 章。

福利账问房租被规定不能高于某个数、或对汽油征税之后，谁得到好处，谁承担代价，饼是变大了还是只是切开。房东因此少提供出租屋，就是规则把行为推到了别处。这本账在第 7–12 章，第 1 章只留下那三扇门。

定价问再多供一吨水时额外成本和额外收入各是多少，第 13–17 章从成本走到垄断和少数厂商。分配问劳动、资本和土地怎样被定价，第 18–20 章做这件事；效率与公平在第 1 章只认成一对权衡，不裁决哪一头应当赢。

第 2 章补上模型、假设和其他条件不变，让别人能复核你停在哪一步。比较优势的计算不在第 1 章做完，供需图也不提前画。第 21 章把预算和偏好补成正式步骤。第 22 章的信息、集体选择和有限理性放在地图边上。生产率、通胀、通胀与失业的短期关系只标出位置，这条路径不建宏观模型。

## 你能获得什么

按章做过练习之后，可以带走四样东西。

第一，一张可复用的解题地图。新问题从约束和权衡写起。弹性、剩余、成本曲线和收益矩阵，都是这条链上后加的工具。

第二，能分开「价格在传递稀缺」和「价格漏掉了成本、势力或信息」。三扇门的名字和例子在上一节，这里只先归类，再决定后文拿哪一章的工具。认错这一步，后面会拿错工具。

第三，福利账和定价的入口。这一页不算无谓损失，但会先问规则是把饼做大还是切开，以及多卖一单位时边际收入是不是还等于标价。计算在第 7 章和第 13–15 章。

第四，边界感。宏观路径、某种分法应当怎样、相关能不能当成因果，入门微观不把它们说成定论。知道这次停在这里，本身就是能用的判断。

### 学完应能做到，和容易误以为的

| | 学完应能做到 | 容易误以为学完就是 |
|---|---|---|
| 目标 | 把一个决定拆成可检查的步骤，并指出卡在哪一步 | 能背出十条原理或六个篇名 |
| 市场 | 分开「价格在传递稀缺」和「价格漏掉了成本、势力或信息」 | 把贵、排队、不顺心都叫成市场失灵 |
| 账 | 知道要问谁得谁失、下一单位值不值，并知道到哪一章才算 | 看到税收或涨价就宣布有人受损 |
| 边界 | 宏观、公平裁决和复杂证据题能标成「这次不下定论」 | 用第 1 章预测通胀，或裁定合同应当怎样写 |
| 时间 | 深学章把机制做成步骤；简讲章停在入口 | 22 章平均用力，或只读标题就跳过 |

## 应该怎样使用

### 读法

先读本页和 [思维导图](book_mindmap.md)，知道自己在 22 章的哪一段。进入某一章时，先读该章概述和导图，再做小课。小课回答一个问题；概述回答这一章为什么要有这些问题。

时间不按章均摊。深学章把机制做成能复述的步骤。中等章建立直觉，计算和图形留到写明的章。简讲章点名、看一个最小例子、写下后文在哪一章，然后停住。第 1 章大约 100 分钟，用来把地图画清。

每一课先看图，再用对照表核对口径，然后做短练习。目录进度在 [按书序学](book_order_path.md)。当前正文是第 1 章。

### 用法：先检查，再下判断

看见枪炮与黄油、房租上限或旧车，按这个顺序问，不要先贴一句口号。

1. **约束。** 哪一种资源不够：钱、时间、土地，还是钢铁。能同时多要两边的，先从冲突里拿掉。
2. **权衡。** 多得到 A 时，少掉的具体是 B 的哪一部分。效率与公平如果出现，只标成一对，不在这一步裁决。
3. **机会成本。** 只取最佳替代。显成本和隐成本都算，第三名及以后不相加。无论选哪边都付的账单，不构成差别。
4. **边际。** 再多一单位的额外收益和额外成本。平均数描述过去。已经退不回的花费留在比较外面。
5. **激励。** 这条价格或规则让哪个行为变贵，邻近的、没被点名的行为会不会变便宜。
6. **市场或政策。** 价格是在协调，还是要进失灵的某一扇门。若要改规则，先问饼变大还是只是切开，再决定这本账拿到后面哪一章去算。

前四步在第 1 章就能用，后两步先认方向。供需图、剩余和成本函数学完之后，同一步会写得更细，顺序不用推倒重来。

### 用得上，以及不够用

资源冲突已经说得清时，这条链用得上：枪炮还是黄油，这周更多买披萨还是冰淇淋，房租上限或香烟税会把供给和需求推向哪里。看见工厂的烟、独家供水或一辆旧车，先回到上面三扇门归类，不要一律叫成市场坏了。

它不给出「公平应当偏哪一头」的准则。第 20 章才有分配的语言，而且仍然不是标准答案。它不预测下一季的通胀。它不把「两个指标一起上升」读成因果，相关和因果是第 2 章的工具。冰淇淋很贵，但街上还有别的店，更像稀缺或口味差别，不要提前叫成垄断。估计很粗、区间重叠时，先补信息，不要假装已经算出唯一方案。

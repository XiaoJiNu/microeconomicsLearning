# 专业术语：中文、原始英文、缩写与实际含义

[全课地图](README.md) · [书写与教学规则](GUIDE.md) · [核对来源](SOURCES.md)

这里集中收录高频和容易混淆的术语；每课正文仍在首次使用时解释，不要求先背完整词表。表中“—”表示本课程不使用统一通用缩写，不代表文献中绝对无人使用字母简称。标注“符号”或“教学记号”的项不是英文缩写。中文译法可能有差异，应根据原始英文与定义核对。

## 最先避免的六组混淆

MB是Marginal Benefit，新增行动的收益；MR是Marginal Revenue，新增销售收入；MC是Marginal Cost，新增成本。需求D是一整条关系，Q_d是特定价格下的需求量。TR是Total Revenue总收入，不是利润；税收收入本课不再复用TR。沉没成本Sunk Cost没有在这里缩成SC。IC在消费者章节指Indifference Curve，在信息章节指Incentive Compatibility，必须重新展开。VMPL=P×MPL，而MRPL=MR×MPL，只有相应产品市场价格接受条件下二者才相等。

## 公式速查不是跳过教学的替代品

机会成本：最佳可行替代，而非所有放弃项加总。税：P_b−P_s=t；补贴：P_s−P_b=s。TR=P×Q；经济利润=TR−全部机会成本。TC=FC+VC；ATC=TC/q；MC为总成本增量率。一般企业内部候选MR=MC，只有价格接受时才能替换为P=MC。MSC=MPC+MEC，MSB=MPB+MEB。消费者内部候选MRS=p_x/p_y，还要检查预算、形状与边界。所有等式都需要相应模型条件，完整推导请回到对应小课。

## 税制原则补充

**受益原则（Benefits Principle，无通用缩写）**按从公共服务受益的程度考虑负担；**支付能力原则（Ability-to-Pay Principle，无通用缩写）**按承担能力考虑负担。两者可能给出不同建议，不能假定有唯一不含价值取舍的税表。评价还需区分效率、公平、征管资源成本和真实行为反应。

## 综合题

需求表示边际收益100−Q，私人边际成本20+Q，边际外部损害为20。求私人数量、社会数量与理想化单位矫正税。随后判断：一段公开可复制代码与运行它所需的拥挤服务器，是否具有同样的消费竞争性？

<details><summary>参考解析</summary>

私人100−Q=20+Q得40；社会成本40+Q，得社会量30；在已知损害、有效执行等条件下，每件20的税可对齐激励。公开代码的复制通常近似非竞争，但服务器容量可能竞争；能否限制访问又是另一个排他性维度。不能把所有数字资源都叫公共物品。
</details>

## 费曼分享参考：问题不在有没有成本，而在谁承担了成本

先讲工厂与居民的例子。生产者看到材料和工资，消费者看到商品价值，但排放影响附近居民。如果居民的损害没有进入交易价，企业会把一些私人划算、社会不划算的产品也做出来。画出私人成本和社会成本两条线，就能解释为什么均衡40而社会量30。

矫正税的逻辑不是单纯罚钱，而是把被遗漏的边际损害放进决策。它与原来没有外部性时的普通税收图比较基准不同，所以不能说所有税都只会增加无谓损失。

再把公共物品和公共资源分开。照明一旦提供，多一个人受益通常不减少别人的光，但难以只让付款者享受，所以可能出资不足；渔场同样难排除，但你捕走一条鱼会减少别人可捕数量，所以可能使用过多。两者不是同一个问题。

最后讨论解决方案。私人协商需要明确权利和低交易成本；公共项目需要信息、执行与监督。存在市场问题并不能证明某个方案无成本。好的分析应该先识别遗漏项，再比较可行制度各自的激励和代价。分享中用代码与算力的区别让听众亲自分类，再返回污染图核验机制。

画社会与私人成本差；用两属性分类；比较至少两种治理工具并指出执行成本；计算ATR、MTR时明确税表完全是假设。[来源](../SOURCES.md#u05)。

# 09.07 一种商品降价，为什么同时有替代效应和收入效应？

[上一课](06.md) · [单元导航](README.md) · [下一课](08.md)

## 一次价格变化包含两个问题

X 降价使它相对于 Y 更便宜，消费者可能转向 X；同时，同样的钱能买更多，实际购买能力也提高。为了分清两条机制，需要构造一个明确的中间比较，不是凭感觉将总变化一分为二。

## 术语与分解口径

**替代效应（Substitution Effect，SE）**：补偿购买能力变化后，相对价格变化引起的选择调整。**收入效应（Income Effect，IE）**：剩余的购买能力变化带来的调整。**斯勒茨基分解（Slutsky Decomposition，无通用缩写）**：调整收入，使旧消费组合在新价格下仍恰好买得起。**希克斯分解（Hicksian Decomposition，无通用缩写）**则保持旧效用水平；两者有限变化下的中间点不同，本课只使用前者。

## 三个点完整算出来

旧偏好 U=xy，I=120，p_x=10、p_y=20，旧最优 A=(6,3)。现在 p_x 降至5，p_y不变，实际预算仍120。新最优满足 y/x=5/20=1/4，代入 5x+20y=120，得 C=(12,3)。X 总变化为+6。

为了只隔离相对价格，构造能在新价格买旧组合的补偿预算：I_c=5×6+20×3=90。用新价格与90预算求最优，得到 B=(9,2.25)。

因此 X 的 SE 为 B_x−A_x=9−6=3，IE 为 C_x−B_x=12−9=3，总和为6。Y 的 SE 为−0.75、IE为+0.75，总变化为0。Y 没有最终数量变化，不代表它完全没受到两条相反机制影响。

## 为什么不要说中间点效用没变

A 的效用为18，而 B 的效用为9×2.25=20.25。本页保持的是旧组合“买得起”，不是旧效用。若用希克斯法，需另求 U=18 条件下的新价格最小支出点，不能混用90预算与“效用恒定”的描述。

## 练习

解释三个点各使用哪组价格与收入，并验证 B 的支出等于90。若有人把 A 到 C 的变化全部称为替代效应，漏掉了什么？

<details><summary>参考解析</summary>

A 用旧价和120；B 用新价和补偿收入90；C 用新价和实际收入120。B 支出5×9+20×2.25=90。A到C同时改变相对价格和实际购买能力，不能全归为替代效应。
</details>

## 过关与分享

画三条对应预算线并标 A、B、C，能用两段有方向的变化相加得到实际结果，明确分解采用哪一种补偿口径。

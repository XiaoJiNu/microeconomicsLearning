## 图形与数学约定

消费图横轴x、纵轴y；预算I=120，价格10和20，偏好U=xy。预算线y=6−0.5x；MRS取正大小y/x，IC几何斜率为−MRS。最优(6,3)。函数只是教学假设，不把所有消费者描述为同一种偏好。价格效应第07课使用Slutsky法“旧组合在新价买得起”，不误称“效用保持不变”。

## 综合题

X由10降到5，Y仍20，实际预算120，U=xy。求旧点、新点及使旧组合买得起的补偿收入和中间最优点。分别算X与Y的替代、收入和总效应。

<details><summary>参考解析</summary>

旧点A=(6,3)，新点C=(12,3)。旧组合新价成本90，补偿预算90下B=(9,2.25)。X替代+3、收入+3、总+6；Y替代−0.75、收入+0.75、总0。A效用18、B效用20.25，所以这一中间点不是Hicks恒效用点。把三点的价格、收入和效用分别列出，可以避免口径混用。

## 费曼分享参考：同一次降价，为什么要拆成两步？

先画预算线，说明它不描述你喜欢什么，只描述买得起什么。再画无差异曲线，说明同一条线上组合排序相同，效用数字不是幸福仪表。消费者在可行范围里找最喜欢的点；光滑内部最优可以比较主观交换比例MRS与市场价格比，边界和折角却要另外检查。

用120元买两种商品的例子，价格10和20、偏好U=xy，最优是6与3。X降价到5后，最优变成12与3。但不能把X多买6件全部归为“便宜所以替代”：同样的120元购买能力也提高了。

于是先拿走一部分预算，只留90，让旧的6与3仍恰好买得起。这个新价格、补偿预算下最优是9与2.25。第一段从6到9是替代效应，第二段恢复120后从9到12是收入效应。Y两段一减一增，最终数量没变，但两条机制都发生了。

最后强调，我们保持的是旧组合买得起，不是效用相同；另一种恒效用分解会有不同中间点。学会这种明确条件的拆分以后，同样的逻辑可用于工资和利率变化：最终选择取决于相反或相同方向的作用，不是靠一句涨价或涨薪就决定。

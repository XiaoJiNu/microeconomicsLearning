## 这次改变的不是文件数量，而是讲解方式

不再用“第0—2分钟、第2—9分钟”组织正文。每个小课围绕一个可以回答的问题，依次解释概念、机制、完整例子、练习和边界。时间只控制阅读负担，不决定理解顺序，更不代替掌握证据。

例如，边际成本不是“多做一件的成本”一句话就结束，而是从总成本算表、比较平均与增量、解释导数和离散差额，最后用于生产与停产判断。税收不只给“供给左移”的结论，而是联立买方价格、卖方净价格与税额，核算成交量和收入，并在后续单元检查福利。

## 20小时如何理解

全课10个概念单元，每单元10个小课，共100课。以每课约12分钟的首轮阅读、跟例和一道短题估计，100×12=1200分钟，约20小时；每个单元规划约两小时。单课通常按10—15分钟的使用颗粒度设计，不保证每人每课耗时相同。

首次遇到数学、独立重画、长题、延迟复习、公开分享与真实项目可能需要额外时间。不能同时要求充分学习，又承诺所有人严格20小时掌握。读不完可以停在一个推理节点，下次继续同一课，不另开一套日历进度。

## 专业词怎样出现

首次在一个可独立阅读的小课出现时，采用“中文—原始英文—通用缩写或记号性质—通俗含义”。例如：

**边际成本（Marginal Cost，MC）**：多生产一单位增加的成本。**边际收入（Marginal Revenue，MR）**：多销售一单位增加的收入。**边际收益（Marginal Benefit，MB）**：多一单位行动带来的收益，可包括非销售收益。三者不能混用。

没有统一缩写的词明确写“无通用缩写”，例如机会成本（Opportunity Cost）和沉没成本（Sunk Cost），不为了满足格式自造OC、SC。P、Q、π等是数学符号，不伪装成英文缩写。同一个缩写有不同语境时重新展开，例如IC可指无差异曲线或激励相容。

## 从哪里继续，而不是重新做长诊断

已有历史诊断保存在[原学习记录](../00_learning_system/progress.md)，本次没有把它改成100课已完成。已经做过诊断者不再被要求重复整套预检；按原错误和自己的当前证据，从对应小课继续。

完全不知道当前位置时，从[U01入口](u01/README.md)开始。已经能闭卷解释并完成某课变式时，可以记录证据后压缩阅读，但不要因题目眼熟直接跳过。每次学习只保留一个“下一步”。

## 四种状态不要混淆

课程文件齐全是材料状态；个人“已阅读”不等于“会做”；首次独立通过后记“待复习”；隔一段时间还能解释新题再记“已掌握”。评分不是按停留分钟数。

本分支新版是默认路径。旧80课、第一章15天日课、原100天路线保留为历史资料，不再与新版同时作为主进度。迁移与版本说明见[AUDIT.md](AUDIT.md)。

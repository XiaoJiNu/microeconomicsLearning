# 个人工作簿模板：记录证据，而不是打卡分钟

[全课地图](README.md) · [使用方法](GUIDE.md) · [综合考核](CAPSTONE.md)

这是待个人填写的记录模板，不是尚未写完的课程。100课教学与参考解析已在各单元中提供；本页不会自动将你标为已学习或已掌握。可复制到`my_learning/`或自己的笔记目录，避免覆盖模板。原始诊断见[历史进度](../00_learning_system/progress.md)。

## 单课记录

```text
课号及链接：
本次日期（个人实际学习日期）：
当前状态：未录入证据 / 学习中 / 待复习 / 已掌握

标题的问题，用自己的话怎么问：
核心术语（中文、英文、通用缩写或无缩写、解释）：
机制：因为……，在……条件下，所以……。
例题重建（变量、单位、步骤、答案）：
短题原始回答（不要事后覆盖）：
对照解析后发现的差异：
错误根因：概念 / 条件 / 建模 / 图形 / 单位 / 算术 / 证据
一个反例或失效条件：
不看稿能向别人讲清的内容：
仍不明白的具体一句话或一步推导：
下次唯一动作：
```

## 变式与复习记录

保留题目、首次答案、纠错后答案和延迟答案四项，不能用最终正确答案替代此前错误。对一道题可以改变价格、可回收费用、供给条件或信息结构；若只是替换数字，仍要补一题改变适用条件。

评分可以参考CAPSTONE的10分维度，但每课不必打复杂分数。最有用的记录是“错在把需求量增加当需求右移”，而不是“今天不够认真”。重学只针对真实缺口，不为追求打卡连续性盲目增加内容。

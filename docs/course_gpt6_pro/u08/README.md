## 制度补充

**工会（Labor Union，无通用缩写）**与**集体谈判（Collective Bargaining，无通用缩写）**可以改变劳动者协调和议价的方式。它们的工资、就业、培训和工作条件效果需要结合雇主势力、成员范围、协议与执行分析，不能只用一条竞争供需线当作所有制度的结论。本单元不介绍任何地区现行劳动法规。

## 综合题

产品价格20，新增三位工人的MPL依次10、8、6，每人同一期间工资150，无其他新增成本且产品、劳动市场均满足价格接受条件。应雇几位？再假设产品MR只有15，第二位的MRPL是多少？对收入10、30的两人总体，求基尼系数，并说明它能否告诉我们是否贫困。

## 费曼分享参考：工资差异不只是一张能力排行榜

先从企业为什么雇人说起。劳动需求来自产品价值，工具提高每人的产出，也可能减少每件所需工时；最终岗位增加还是减少，还要看业务规模是否扩张。所以“生产率提高”与“岗位一定减少或增加”之间都缺了一步。

再把边际产量翻译成收入。多做八件产品，售价20时产量价值160；如果为了卖更多必须降价，边际收入只有15，真实新增销售收入可能只有120。工资优化需要匹配正确模型，还受劳动市场势力与其他投入约束，不能变成某个人社会价值的公式。

接着讲工资差异。经验和技能可能重要，夜班、通勤、风险、培训机会、议价和差别待遇也可能重要。看到平均差距不能把原因全部归到一个因素；控制岗位以后没差，也不能排除进入岗位之前的机会差异。

最后展示10、10、100三个收入。最高收入增长会推高均值，但另外两人没有改善。收入不平等、财富不平等、贫困和平均水平是不同问题。好的分配分析要先把人群、时期与统计口径说清，再讨论不同政策的真实效果和价值取舍。

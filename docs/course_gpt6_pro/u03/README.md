## 必须能读懂的符号

PED是Price Elasticity of Demand，需求价格弹性；本课需要方向时保留ε_d的负号，需要描述大小时用E_d=|ε_d|。YED、XED不能随意取绝对值。P_b是买方支付价格，P_s是卖方净得价格；t为每件税额，s为每件补贴金额，不是百分比税率。

## 综合题

无税需求Q_d=100−2P，供给Q_s=−20+2P。每件税6元，求买方价、卖方净价、税后量及税收。再用价格由10变12、数量由100变80的另一组需求数据，算中点弹性及收入变化。说明两题不是同一条数据关系，不要混合系数。

税题：P_b−P_s=6，100−2(P_s+6)=−20+2P_s，得P_s27、P_b33、Q34、税收204。买卖双方每件分别多付3、少收3。弹性题：均值价格11、数量90，ε_d=(−20/90)/(2/11)=−11/9，大小约1.22；收入1000变960。收入下降不保证利润下降，还需成本与未来反应。

## 费曼分享参考：法律规定谁缴款，不等于谁承担税负

可以先问：“商品每件收六元税，买家会多付六元吗？”不要直接回答，而是把一笔交易拆成买家付多少、卖家净得多少。两者差六元，同时还要让购买计划和销售计划相同。代入本单元的两条方程，买家付33、卖家得27，原来价格30，所以双方各分担三元。

这个分配来自行为反应，不只是缴款手续。买家容易换商品而卖家不容易转产时，卖家可能吸收更多；买家很难减少购买时，买方价可能上涨更多。弹性就是衡量这种反应的工具，它不是“少买多少件”，而是数量变化百分比除以价格变化百分比，所以能够比较不同尺度。

再展示提价例子：从10元卖100件，变成12元卖80件，收入由1000降到960。价格提高不等于收入增长，收入增长也不等于利润增长。必须知道成本如何变。

最后区分三种政策：限价限制交易价格，本身不新增资源；税让买卖双方价格差由政府取得；补贴用财政支出补足两种净价格之间的差。每种政策都要算反应、分配和实施条件。分享时做完一组税题，再请听众改变税额预测两个价格，重点检验逻辑而非背答案。

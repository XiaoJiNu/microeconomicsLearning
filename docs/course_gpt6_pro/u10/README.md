## 范围说明

本单元建立信息与行为机制的基础，不把完整机制设计、社会选择公理证明、完整前景理论估计或动态金融模型冒充已学内容。投票例子是抽象团队选择，不涉及任何现实选举办理程序。行为效应强度与适用条件需要证据，不能把“损失是收益的两倍”当每个人的固定常数。

## 综合题

外包商在签约前知道质量类型，客户不知道；签约后客户难以检查维护努力。分别是什么问题？维护成本10、维护后故障概率1%、不维护5%、损失500，全部损失由操作方承担时应如何选择？若操作方完全不承担损失，激励怎样变化？

<details><summary>参考解析</summary>

前者是隐藏类型，可能导致逆向选择；后者是隐藏行动，可能导致道德风险。维护期望成本15，不维护25，完全承担时选择维护；若全部故障损失转移且努力不可验证，私人只看到维护花10、不维护0，可能放弃维护。检测质量不自动解决后续努力，需要分别设计合同、监督与风险分担，并计算执行成本。
</details>

## 费曼分享参考：问题有时不在价格，而在谁知道什么、谁承担后果

用买设备与维护设备的区别开头。购买前不知道好坏，买家可能按平均质量报价，结果好卖家退出，平均质量更低；这叫逆向选择。签约后不知道对方是否认真维护，若对方不承担故障损失，就可能缺少努力激励；这叫道德风险。前后只是记忆线索，真正要分清的是隐藏类型和隐藏行动。

信号与筛选可以改善信息，但一张担保书只有在能够执行、低质量承担更高预期成本时才可能可信。合同奖励也不是越强越好，还要兼顾不受行动者控制的风险与监督成本。

再把镜头移到自己。我们做选择时注意力有限，可能依靠简单规则；这些规则有时节约成本，有时被锚定、参照点或当前偏误带偏。知道术语不是为了给别人贴不理性标签，而是让自己事先写出可接受范围、反证条件和可修改的小承诺。

最后回到全课：从主体与约束出发，找到可改变的成本和最佳替代，建立需求、成本或信息机制，用例子算清楚，再检查证据与边界。好的分析不是术语最多，而是每一步都能回答“为什么、根据什么、条件变了会怎样”。

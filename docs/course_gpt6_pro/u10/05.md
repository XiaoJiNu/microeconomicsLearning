# 10.05 集体投票为什么不总能产生一致的排序？

[上一课](04.md) · [单元导航](README.md) · [下一课](06.md)

## 个人偏好清楚，集体结果仍可能复杂

一个团队选择三种项目方案，每个人都能清楚排序，不代表多数决就会产生同样清楚的整体排序。不同方案之间的两两比较，可能形成循环，使议程顺序影响结果。

## 术语

**公共选择（Public Choice，无通用缩写）**：用经济学的激励和选择方法研究集体及公共决策。**投票循环（Voting Cycle，无通用缩写）**：多数分别偏好 A 胜 B、B 胜 C、C 又胜 A。**中位选民定理（Median Voter Theorem，MVT）**：在单一政策维度、单峰偏好和相应多数决等条件下，中位理想点具有特定的两两多数优势。这里讨论抽象模型，不是任何美国选举的事实或投票手续。

## 亲手检验一个三人循环

甲排序 A>B>C，乙排序 B>C>A，丙排序 C>A>B。比较 A 与 B：甲、丙选 A，A 胜。比较 B 与 C：甲、乙选 B，B 胜。比较 C 与 A：乙、丙选 C，C 胜。每个人排序都一致，集体两两排序却循环。

因此，“多数人的唯一想法”在某些多选项问题里并不存在。谁先与谁比较可能影响最终结果，这需要制度层面的透明和检验，而不是认为参与者一定不理性。

## 中位结论为什么需要限制偏好形状

若项目规模只有一条从小到大的轴，五人最喜欢规模分别为1、2、3、4、5，并且离自己的理想点越远越不喜欢，那么中位理想点3在相应两两比较中具有优势。关键是一个维度、单峰等条件，而不是“任何制度都会选择最中间的人”。

现实公共政策涉及税收、服务、权利与地区等多个维度，还存在参与成本、组织差异和制度约束。不能把简化结论直接用于预测具体政治事件。

## 练习

重新核对循环里 C 对 A 的三票。若团队采用“先 A 对 B，胜者再对 C”，结果是什么？若先 B 对 C，再与 A 比较，又是什么？

<details><summary>参考解析</summary>

C 对 A 时甲选 A、乙丙选 C。先 A 胜 B，再被 C 击败，最终 C；先 B 胜 C，再被 A 击败，最终 A。同样偏好，仅顺序改变就得到不同结果。
</details>

## 过关与分享

能够手算一个循环，并列出中位结论所依赖的条件。把公共决策也看作需要理解激励和制度的过程，而非自动无成本解决所有市场问题。

## 综合题

统一定价需求P=100−Q，TC=100+20Q。求利润最优量、价格、利润和相对于边际有效率产量的DWL。再解释：如果固定成本加100，为什么不能直接推断最优售价加100/Q？

<details><summary>参考解析</summary>

TR=100Q−Q²，MR=100−2Q，MC20，得Q40、P60，利润1500。有效率边际量80，DWL=0.5×40×40=800。固定成本变化不改变本例MR或MC，所以正产量候选和价格不变，利润少100；仍需核验是否继续经营。成本加成不是普遍最优化定价规则。
</details>

## 费曼分享参考：高利润是一道需要解释的问题，不是护城河的证明

可以从一家软件企业提价后客户流失很少讲起。也许产品确实独特，也许只是年度合同还没到期，短期数据看不见退出。市场势力必须解释客户为什么不能轻易离开、竞争者为什么不能复制和进入，不能只重复它利润很高。

然后画向下的需求。统一定价企业要多卖一件，可能要让之前的顾客也享受更低价格，所以新增收入小于新售价。在P=100−Q的例子里，从10件到11件，总收入只增加79，而不是售价89，多出的10元正是旧销量的降价损失。

利润选择仍然比较MR与MC，但找到产量以后要从需求线上读价格。这个步骤解释为何不能对垄断直接套P=MC。也要区分较高利润中的转移与取消交易造成的净损失。

最后用两企业矩阵说明策略互动。双方都希望对方保持高价，但在对方高价时自己降价又更有利，最终可能一起低价。纳什均衡只要求谁都不愿单独偏离，不要求大家都满意。现实企业分析需要需求、成本、进入和对手反应四条线的证据，不能靠一个漂亮标签完成。

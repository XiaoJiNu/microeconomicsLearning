## U03 弹性与政策

- [OpenStax：需求与供给价格弹性](https://openstax.org/books/principles-economics-3e/pages/5-1-price-elasticity-of-demand-and-price-elasticity-of-supply)

<a id="u04"></a>
## U04 福利与贸易

- [OpenStax：供需与效率](https://openstax.org/books/principles-economics-3e/pages/3-5-demand-supply-and-efficiency)
- [OpenStax：贸易保护与分配](https://openstax.org/books/principles-economics-3e/pages/34-key-concepts-and-summary)
- [OpenStax：贸易基础](https://openstax.org/books/principles-economics-3e/pages/33-1-absolute-and-comparative-advantage)

福利图使用明确小国、世界价格给定等假设。资金转移、资源消耗、国内与全球范围分别核算。

<a id="u05"></a>
## U05 外部性与公共部门

- [OpenStax：污染的经济学](https://openstax.org/books/principles-economics-3e/pages/12-1-the-economics-of-pollution)
- [OpenStax：外部性与政策工具](https://openstax.org/books/principles-economics-3e/pages/12-key-concepts-and-summary)
- [OpenStax：公共物品](https://openstax.org/books/principles-economics-3e/pages/13-3-public-goods)

外部成本需要区分平均与边际。许可交易的付款不是额外资源成本；分档税与NPV参数为假设。

## U06 生产、成本与竞争

- [OpenStax：生产成本与行业结构](https://openstax.org/books/principles-economics-3e/pages/7-introduction-to-production-costs-and-industry-structure)

<a id="u07"></a>
## U07 市场势力与博弈

- [OpenStax：垄断与进入壁垒](https://openstax.org/books/principles-economics-3e/pages/9-1-how-monopolies-form-barriers-to-entry)
- [OpenStax：垄断的产量与价格](https://openstax.org/books/principles-economics-3e/pages/9-2-how-a-profit-maximizing-monopoly-chooses-output-and-price)
- [OpenStax：垄断竞争](https://openstax.org/books/principles-economics-3e/pages/10-1-monopolistic-competition)
- [OpenStax：寡头](https://openstax.org/books/principles-economics-3e/pages/10-2-oligopoly)
- [CORE：企业与顾客总结](https://books.core-econ.org/the-economy/microeconomics/07-firm-and-customers-13-summary.html)

统一定价下MR不同于售价。博弈矩阵与重复收益为思想实验，不据此判断现实企业违法，也不提供实际价格协调操作。

<a id="u08"></a>
## U08 劳动与分配

- [OpenStax：劳动市场理论](https://openstax.org/books/principles-economics-3e/pages/14-1-the-theory-of-labor-markets)
- [OpenStax：不完全竞争劳动市场](https://openstax.org/books/principles-economics-3e/pages/14-2-wages-and-employment-in-an-imperfectly-competitive-labor-market)
- [OpenStax：收入不平等测量](https://openstax.org/books/principles-economics-3e/pages/15-4-income-inequality-measurement-and-causes)
- [CORE：企业与员工总结](https://books.core-econ.org/the-economy/microeconomics/06-firm-and-employees-15-summary.html)

VMPL与MRPL的区别依赖产品市场条件。工资公式不是人的社会价值，最低工资效果需市场结构与经验证据。

<a id="u09"></a>
## U09 消费者选择

- [OpenStax：消费选择](https://openstax.org/books/principles-economics-3e/pages/6-1-consumption-choices)
- [OpenStax：价格和收入变化](https://openstax.org/books/principles-economics-3e/pages/6-2-how-changes-in-income-and-prices-affect-consumption-choices)
- [OpenStax：无差异曲线](https://openstax.org/books/principles-economics-3e/pages/b-indifference-curves)
- [CORE：相关主题索引](https://books.core-econ.org/the-economy/microeconomics/0-7-features-list.html)

Slutsky三点分解为本课自行演算，保持旧组合在新价下买得起，不等同于Hicks恒效用补偿。切点不是所有偏好的万能解。

## U10 信息、集体选择与行为

- [OpenStax：不完全与不对称信息](https://openstax.org/books/principles-economics-3e/pages/16-1-the-problem-of-imperfect-information-and-asymmetric-information)

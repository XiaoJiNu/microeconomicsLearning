## 贯穿函数与特别提醒

TC(q)=100+10q+q²，FC=100，VC=10q+q²，ATC=100/q+10+q，AVC=10+q，MC=10+2q。q为件/期间，TC为元/期间，平均与边际为元/件。本例AVC单调上升，没有正产量内部最低点，不要硬套所有教材图都是U形的记忆。q=0时平均成本未定义，不是0。

## 费曼分享参考：亏损不等于停产，平均成本不等于新增成本

先用两张账表讲继续与停止。企业本周租金无论如何都要付100，生产收入72、额外支出56，那么生产后亏84，停产则亏100。继续不是因为舍不得过去投入，而是因为从现在起生产还能多创造16的贡献。这和沉没成本原则完全一致。

再解释成本缩写。FC是不随当前产量变的总额，VC随产量变，二者之和是TC。除以产量得到AFC、AVC、ATC；增加一点产量带来的成本是MC。新加入一件若比现有平均便宜，就把平均拉低，像新同学成绩低于班级平均会拉低平均一样。

接着从利润出发：收入增加多少减去成本增加多少，就是新增利润。只有MR大于MC时，增加这一步才改善利润；内部候选相等后还要检查成本形状和边界。竞争企业可以用P=MC，是因为它接受价格而有MR=P，换成垄断就不能照搬。

最后转向行业。单家企业在高价格下盈利，可能吸引进入，增加供给、压低价格。零经济利润仍包含劳动和资金的正常机会回报，不是老板完全没有收入。分享时亲手算一次q4的两张账，比背十个英文缩写更能检验理解。

## 过关标准

从TC重建所有成本指标，解释单位与q=0边界；完成生产、停产和长期条件变化三类判断。不能只报MR=MC而没有利润核验。[来源](../SOURCES.md#u06)。

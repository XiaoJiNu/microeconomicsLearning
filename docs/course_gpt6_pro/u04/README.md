## 图形重建

横轴Q、纵轴P；需求P=50−0.5Q，供给P=10+0.5Q。交点(40,30)。先画需求截距50、供给截距10；CS在价格之上、需求之下，PS在价格之下、供给之上。不同人收入与基本需要不能被一个总面积完整代表。

## 综合题

世界价格20，允许自由进口；之后每件进口税5。分别求消费量、国内产量、进口量，列出消费者、生产者、政府三方变化。假设小国、无额外运输与执行成本。

自由贸易：价格20，消费60、国内产量20、进口40；CS900、PS100。关税后价格25，消费50、国内产量30、进口20；CS625、PS225、税收100。消费者−275、生产者+125、政府+100，国内净损失50。两个三角形各25。若加入其他目标或外部性，需要明示新机制，不能用本模型宣布现实政策的全部结论。

## 费曼分享参考：转移了一笔钱，不等于浪费了同样资源

先拿一笔交易说明：买家最多愿付100，制造成本40，无论成交价50还是80，只要同一件都成交，总净好处都是60。价格决定这60如何分配，但不改变这笔既定交易创造的差额。

然后加入税。税会拿走买卖双方的一部分剩余，但政府得到收入，所以不能把所有税款叫社会损失。真正的基础无谓损失来自某些原本愿付价高于成本的交易不再发生。沿图把这些交易标出来，会得到两条曲线之间的一块三角形。

贸易同样需要逐方计算。允许便宜进口可能让消费者得到500、生产者失去300，合计增加200；这不是生产者也受益，更不是他们已经收到补偿。关税又把部分消费者损失转给生产者和政府，同时可能造成两种资源扭曲。把每一方都列出来，比只说“保护就业”或“消费者更便宜”更完整。

最后强调，剩余核算是一个有假设的效率工具，不是公平的最终裁判。需要问谁付出转换成本、谁真正得到补偿、评价范围是国内还是全球。边画剩余区域边讲，再让听众核验三方变化之和，可作为约五分钟分享。

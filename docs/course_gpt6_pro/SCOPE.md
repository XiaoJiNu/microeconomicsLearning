## 知识依赖

机会成本 → 比较优势 → 市场供需 → 弹性与政策 → 福利；私人/社会成本区分扩展福利分析。边际分析 → 企业生产与成本 → 完全竞争 → 市场势力与博弈。生产和供需 → 劳动市场；预算和偏好 → 消费者选择，反过来解释需求与劳动供给的边界。信息与行为单元检查前述模型的假设，并用于综合案例。

顺序允许有证据地跳转：例如读U08.03不理解工资的两条效应，可先看U09.09；但没有供需基础时不直接跳到税负公式。每次仍以一个具体问题为中心，不并行执行多套课程日历。

## 不应宣称已经完成的东西

本轮不是完整微观经济学学位课程，也不覆盖全部高阶证明、一般均衡存在性、完整博弈论、全部社会选择定理或计量经济学识别方法。真实行业项目还需数据与研究设计；股票购买还需财务、估值、风险和投资约束；黄金预测还需宏观、金融市场与时间序列知识。

“20小时”描述首轮学习材料的规划预算，不是对个人掌握、英语熟练度、投资盈利或预测精度的保证。公开分享、延迟复习和深入项目可在首轮之外继续进行。

## 第1章宏观边界速读

**微观经济学（Microeconomics，无通用缩写）**研究个人、企业与具体市场；**宏观经济学（Macroeconomics，无通用缩写）**研究经济总体产出、物价和就业。第1章的总体经济原理在本轮只建立边界：**生产率（Productivity，无通用缩写）**是单位投入的产出，长期生活水平与其密切相关，但分配也影响不同人群的处境；**通货膨胀（Inflation，无通用缩写）**指总体价格水平持续上升，不是单一商品涨价；货币、真实产出与价格的关系需要另外建立宏观模型，不能用某个市场的供需图代替。**失业（Unemployment，无通用缩写）**与通胀的短期关系可能受冲击和预期影响，并非永久固定的政策菜单。本课没有承诺用微观知识直接预测黄金或总体物价。教材原理中贸易、市场配置与政府作用分别在U02、U04、U05继续展开，不靠本页一口气背十句话。

## 综合题：同一个决定中哪些成本还相关？

已付课程费3000，其中退出可退1000。继续需要10小时，未来学习价值4000；10小时最佳替代用途净价值2000。假定价值可比、无其他费用。请比较继续与退出；指出沉没部分；若学习价值改为2500，答案是否变化？

<details><summary>参考解析与评分要点</summary>

直接比较未来：继续得到4000；退出得到退款1000加替代用途2000，共3000，所以继续优势1000。等价写法为4000−2000−1000=1000；不能把2000时间机会成本扣两次。过去不可退2000是沉没成本。价值降为2500时，退出优势500。这里“价值可比”是假设，真实决定要保留风险与非金钱影响。评分看统一起点、替代方案可行、未重复计费以及条件变化后的重新计算，不只看最后选项。
</details>

## 费曼分享参考：选择不是为过去的投入辩护

可以先问听众：“花了很多时间的项目，是否一定应该继续？”然后用本单元综合题说明，真正要比的不是已经花了多少，而是从现在起不同方案分别带来什么。

先列可行方案。今晚不能同时完成的三件事，不是把另外两件价值都当成本，而是比较最好的可行替代。然后拆开已经支付的费用：不能退的部分不会因决定改变，可以用于复盘，但不能证明继续正确；能够退回的钱恰恰是继续时放弃的机会。

再谈做多少。前两个小时值得，不表示第三个小时也值得。每多做一点，都要看新增收益和新增成本；离散任务直接比较可行总净收益，不必硬找一个相等点。

最后提醒，数字再整齐也要检查依据。某人学得多、收入高，可能有其他原因，不能仅凭相关证明课程效果。经济学可以帮助把约束、代价和证据说清，却不能自动替别人决定陪伴、健康和公平各值多少。分享时在纸上完成退款例子的两列账，再请听众改变一个条件重新判断；展开讲解约五分钟，速度不作为评分标准。

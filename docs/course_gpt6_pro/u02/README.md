## 贯穿例子

需求 Q_d=100−2P，供给 Q_s=−20+2P。P为元/件，Q为件/周，使用非负且经济上相关的范围。横轴数量、纵轴价格，基准交点为(Q,P)=(40,30)。这组数字在U03、U04继续使用；不要把后一单元新的假设误当当前市场一直不变。

## 综合题

消费者人数增加使需求变为120−2P，技术进步使供给变为2P。求原、新均衡，并解释：价格没变是否证明没有需求变化？新价格暂被限制为25时，双方计划量与最大可能成交量如何？

<details><summary>参考解析</summary>

原P30、Q40；新120−2P=2P，得P30、Q60。需求和供给均右移20，价格影响相互抵消，数量增加20。新关系下P25时需求70、供给50，短缺20，忽略库存、进口和匹配失败时成交最多50，不能取平均60。价格不变不能证明市场无变化，成交50也不能证明需求只有50。
</details>

## 费曼分享参考：一张需求曲线不是你观察到的所有价格点

先举分工例子：甲清洗和写报告都比乙快，但甲清洗一批只放弃半份报告，乙要放弃一份。将较低机会成本的清洗交给甲，可能让双方在合理交换条件下更好。比较优势比较放弃了什么，不是比较谁更优秀。

然后拿一张价格表说明需求。价格10时想买80，价格20时想买60，整套关系才叫需求，其中一个数量叫需求量。自身价格变化让我们沿同一条线走；收入或替代品变化则使相同价格下的购买计划改变，移动整条线。供给同理，材料涨价会减少相同售价下愿意提供的数量，不等于售价上涨让企业多生产。

把两条计划放在一起，相等处才是均衡。在基准例子中，30元对应买卖双方都计划40件。短缺时，想买的数量不一定成交；过剩时，愿意卖的数量也不一定实现。

最后展示综合题：需求与供给都增加，价格可以保持不变，数量却大幅变化。所以看见两个价格销量点，不能立即把它们连成需求曲线，更不能一句“涨价是利好”就推导企业利润和股价。经济学分析真正多做的一步，是把市场、冲击、曲线和证据连起来。边画边讲，再用另一组需求增量追问价格方向，可展开成约五分钟分享。

## 过关标准

不看答案重建需求与供给图；完成比较优势和综合题；面对新事件能先说是哪条关系、哪个条件改变。答对方向但说不出“同价下为什么改变”仍需复习。[来源](../SOURCES.md#u02)。

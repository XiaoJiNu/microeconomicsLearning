# 每日 5 分钟费曼分享

本目录保存每天可在约 5 分钟内读完或讲完的一篇短稿。目标不是压缩整章，而是每天只讲透一个问题。

## 结构要求

每篇至少包含：

1. 一个生活化问题；
2. 一个核心结论；
3. 一个具体例子、图形或小计算；
4. 一个常见误区；
5. 一句适用边界；
6. 三个用于无稿复述的问题。

建议长度为 700–1000 个汉字。完成后合上文稿讲一遍；卡住的位置写入错题或复习计划。

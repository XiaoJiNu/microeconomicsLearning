# 教材主题索引与公开核对资料

主教材：N. Gregory Mankiw（N. 格里高利·曼昆），《Principles of Economics / 经济学原理》第8版，微观经济学分册。以用户原定教材为主线，但本轮没有取得PDF可读全文，以下为章节主题索引，不提供未经核实的页码，也不声称逐页校订。

## 课程对应

| 单元 | 曼昆章节主题范围 | 学习重点 |
|---|---|---|
| 01 | 第1–2章 | 经济学思维、模型、PPF、实证与规范 |
| 02 | 第3–4章 | 比较优势、交换、供需 |
| 03 | 第5–6章 | 弹性与政府政策 |
| 04 | 第7–9章 | 剩余、税收与贸易福利 |
| 05 | 第10–12章 | 外部性、公共物品、税制 |
| 06 | 第13–14章 | 成本、完全竞争、停产退出 |
| 07 | 第15–17章 | 垄断、垄断竞争、寡头 |
| 08 | 第18–20章 | 要素、收入差异、分配与贫困 |
| 09 | 第21章 | 消费者选择 |
| 10 | 第22章 | 信息、政治与行为机制 |

主题范围不等于教完每章的所有细节。第一轮核心内容均有课文；宏观三条原理可看旧版第一章补充，严格消费者优化证明、一般均衡、高级博弈和计量识别留待深化。
